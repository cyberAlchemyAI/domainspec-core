# Creator Pack Marketplace Transferable NFT Custody Hypothesis Contradiction

This Inventory contradiction preserves a material research correction. It is a
non-authority read model and does not approve a replacement architecture.

## Earlier Hypothesis

The 15 July candidate synthesis proposed that a CardNFT/physical-backed NFT
could represent the redemption claim and left public transfer as an open design
boundary. That page remains useful for its allocated-custody and digital-proof
research, but the token default did not include a complete consumer/payment
reversal witness.

## Contradicting Evidence

The accepted 16 July legal/payment findings identify the zeroing case: the
original payer can obtain a mandatory refund, reversal, or chargeback after an
external token transfer while another holder still presents the token for the
physical card. No evidenced owner-controlled transition prevents both outcomes
without improperly treating token finality as superior to consumer/payment
remedies.

The accepted custodian RFP findings independently reach the same result. An
authoritative transferable ERC-721 is `KILL v1`; a locked/opaque ERC status
witness is `DEFER`; the v1 RFP baseline is a personal non-transferable claim in
a centralized registry with signed custodian attestations and an append-only
log.

## Current Read Model

- Preserve exact-card professional allocated custody.
- Use one personal, recoverable, non-transferable claim per allocated card.
- Keep title, custody, grade, authenticity, value, insurance, payment remedy,
  and delivery as separate evidence domains.
- Treat an optional public-chain Merkle root as tamper-evidence for inclusion,
  ordering, consistency, and non-deletion only.
- Never let blockchain availability or token state gate a lawful refund,
  reversal, redemption, return, or loss remedy.

The earlier NFT design is therefore historical hypothesis evidence, not the
current v1 baseline. Reopening it requires a new exact end-to-end transfer,
refund, chargeback, account-recovery, redemption, and insolvency witness plus
fresh legal, PSP, custody, and security review.
