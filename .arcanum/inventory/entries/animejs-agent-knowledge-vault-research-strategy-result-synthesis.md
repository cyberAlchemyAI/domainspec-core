# Anime.js Agent Knowledge Vault Research Strategy Result

This is a non-authority Inventory read model of a confirmation-ready research
strategy. It does not confirm, register, or execute the dispatch; create the
Anime.js ontology; copy or republish the official documentation; validate any
operational lesson; or authorize promotion, publication, release, deployment,
or production use.

## P1 Trigger Decision

Synthesis, context protection, isolation, and parallelism all hold. The work
must combine the complete live Anime.js documentation and official repository,
several recent locally created ontology models, and a distinct agent-work
lesson/query model. The raw evidence is too broad for the parent context and
needs independent coverage and semantic attacks.

## Intended Result

The accepted research may feed a private candidate-local package at
`projects/animejs/ontology/agent-knowledge-vault/`. Full documentation coverage
means a source manifest, canonical URLs, exact selectors, hashes, structured
facts, and concise paraphrases—not a verbatim mirror.

The planned package includes API and documentation nodes, typed relations,
version and migration boundaries, task recipes, pitfalls and repairs, an
append-only WorkEpisode-to-Lesson evidence model, agent queries, populated
views, deterministic validators, fail-closed fixtures, drift checks, and
digest-bound receipts.

## Dependency Flow

The three explorers run in parallel, then the synthesizer. Three reviewers run
in parallel with one bounded synthesis zig-zag and one eligible missing-source
feedback route. A ready exact-binding closure unlocks the writer, then the
auditor. The parent remains final approver. Only an accepted audit may unlock a
parent-owned Ontology Vault build in the isolated Anime.js package path.
