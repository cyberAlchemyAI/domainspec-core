# Augmentor User Understanding, Knowledge Graph, and Reasoning Research Strategy

This is the current non-authority Inventory read model of revised research
dispatch `2026-07-28-authority-memory-augmentor-integration`. It supersedes the
unconfirmed first strategy draft. It inventories a proposal; it does not promote
an Arcanum candidate package, create durable user state, install a graph service,
change ResonantOS, or authorize a reasoning-engine implementation.

## Direct Strategy

Augmentor should consume a small host-composed reasoning context, not a second
memory system or an always-loaded ontology:

`protected user handles + existing memory -> rebuildable typed graph projection
-> bounded subgraph -> deterministic checks plus model synthesis -> useful
answer or abstention -> visible correction or forget proposal`.

The first slice should reuse current ResonantOS storage and prompt-composition
owners. It should use compact typed records, incremental graph deltas, direct
scan or a small adjacency index, strict hop/node/token/latency budgets, and
progressive disclosure of why context affected an answer. A graph database is
not a prerequisite.

## P1 Trigger Decision

P1 passes on synthesis, context protection, isolation, and parallelism. The
question combines the candidate User/Translate/Guide family, CAV2 ontology and
candidate-graph precedents, bounded semantic reasoning, IDE knowledge-reference
ergonomics, and current ResonantOS Augmentor/memory behavior.

## Lanes, Groups, and Subagents

- **Explorers, parallel:** Ahrens owns protected user understanding and adaptive
  explanation; Turing owns incremental graph schema, deltas, queries, and
  overhead; Hewitt owns bounded graph-plus-model reasoning; Simon owns current
  Augmentor experience and ResonantOS integration.
- **Synthesizer:** Shannon reconciles the four returns into one cited-synthesis
  product architecture.
- **Reviewers, parallel plus robot-talks:** Lakatos attacks duplication; Gödel
  attacks non-vacuity and user-visible benefit; Quine attacks collapse among
  identity, preference, memory, graph, retrieval, reasoning, and action.
- **Writer:** van Lamsweerde writes a compact implementation blueprint after
  cited-synthesis evidence closure.
- **Auditor:** Brandenburg performs a narrow usefulness/economy check; the
  parent remains final approver.

The explorer anti-bias axis combines methodology and source corpus. The reviewer
axis is attack vector. Every unordered pair is represented in the exact sheet.

## Dependency Flow

`explorers -> synthesizer <-> reviewers -> writer -> auditor -> parent`, with
one bounded `synthesizer -> explorers` evidence-repair route and one bounded
`auditor -> writer` revision route.
