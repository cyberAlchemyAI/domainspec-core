coverage auditor may request one writer revision. Whole-sequence `max_loops` is
one.

## Concrete Audit Boundary

The Body War scenario tests the current all-node black box, control purpose,
bounded context home, cluster portal cards, Path behavior, category icons,
Back/focus recovery, and one stable color per exact edge `sourcePredicate`
rather than per edge instance. `presentationRelation` remains a redundant line
pattern and exact predicate/direction text remains recoverable.

Browser evidence stays split into deterministic hard gates, conservative soft
flags, screenshot review, human-study residue, and not-automatable owner
judgments. There is no universal UX score.

known-good, known-bad, domain, and false-positive fixtures pass; only then may
