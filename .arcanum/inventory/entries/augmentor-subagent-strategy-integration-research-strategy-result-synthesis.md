# Augmentor Subagent Strategy Integration Research Strategy

This is a non-authority Inventory read model of a confirmation-ready but
unconfirmed research proposal. It does not authorize the dispatch, register
agents, implement Augmentor, promote the public Subagent Strategy package,
import DomainSpec private authority, or change ResonantOS.

## Direct strategy

The candidate integration is a public-neutral adapter:

```text
ordinary user request
  -> preview-only StrategyProposal
  -> immutable RouteDecision
  -> explicit owner confirmation
  -> validated Dispatch Spec
  -> Orchestrate native actions and joins
  -> host Run projections referencing current execution owners
  -> independently controllable results or blockers
```

The reject condition is a second scheduler, registry, session store, job
owner, workspace owner, artifact authority, memory authority, or copy of the
private DomainSpec ledger.

## P1 trigger decision

Dispatch is required by synthesis, context protection, isolation, and
parallelism. The research must reconcile the public Arcanum lifecycle, private
adapter precedent, accepted Augmentor routing/session result, current
ResonantOS owners, IDE Ergonomics, and primary external protocol evidence. The
live type is `research`; the admitted sheet uses schema `0.8.0`.

## Dependency flow

`explorers -> synthesizer <-> reviewers -> evidence closure -> writer ->
auditor -> parent`

The route permits one bounded synthesizer-to-explorer evidence repair, two
synthesizer/reviewer exchanges, and one bounded auditor-to-writer revision.
Every agent must be joined and closed. The strategist mechanically assembles
`research.md` from verbatim explorer returns; the writer does not.
