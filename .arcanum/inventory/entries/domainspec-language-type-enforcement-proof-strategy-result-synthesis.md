## P1 Trigger Decision

Dispatch was justified by synthesis, context protection, isolation, and
parallelism. The question crossed three distinct systems and proof postures:
Framework Unification's designed contract/schema/iteration language, current
DomainSpec v2 graph authority and executable validators, and imported Lean plus
minted/derivation translation surfaces. Independent formal, empirical, and
cross-layer exploration was needed to prevent designed notation, a passing
validator, or a zero-sorry snapshot from being inflated into an operative
language or end-to-end proof chain.

## Accepted Result

Current DomainSpec v2 provides **bounded, sampled post-parse endpoint
rejection** driven by a live 30-signature authority, plus observed trace
artifacts across bounded translation machinery. That is real enforcement, but
it is not a general type system and does not prove parse completeness,
profile admission, all authority fields, implementation conformance, runtime
behavior, or semantic correctness.

Framework Unification supplies a candidate document-language design separating
contract, schema, and iteration, but no operative parser or unified language
bridge was found. The imported Lean snapshot contains useful relative
metatheorems and witnesses, but it is non-authority, 29-edge-era, stale, and not
built locally; it is precedent rather than current proof. Minted-project and
derivation outputs show trace retention, not judgment or semantic preservation.

The research therefore keeps three systems explicit:

1. designed contract/schema/iteration document language;
2. active DS-D1/DS-D2/DS-D8 graph authority plus endpoint checker; and
3. minted/derivation translators and their evidence artifacts.

The accepted candidate repair orders distinct judgments as
`Declared -> ParsedCompletely -> ShapeValid -> ProfileAdmitted ->
EndpointAdmissible`, treats `Skipped` as fail-closed, treats `Escaped` as
degraded residue rather than strict well-typedness, separates provenance edges
from domain edges, generates executable and Lean projections from the same
canonical authority, and requires exact-cause positive/negative discriminators
plus preserve/drop contracts.

## Assurance Boundary

- Narrow current PASS: sampled, exact-cause post-parse endpoint-admissibility
  discrimination.
- Observed only: selected trace retention in translation artifacts.
- Precedent only: imported relative Lean metatheory.
- KILL/open: current complete parse/shape coverage, proof that the stale
  metatheory certifies live authority, judgment or semantic preservation,
  implementation conformance, runtime correctness, and satisfaction of domain
  meaning or obligations.

No intrinsically typed AST, unified surface syntax, full category/functor laws,
implementation equivalence, runtime verification, or semantic correctness is
claimed or required by the minimum repair.
