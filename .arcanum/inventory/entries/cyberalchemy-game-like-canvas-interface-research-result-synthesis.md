# CyberAlchemy Game-Like Canvas Interface Research Result

## Decision

The closed research route selects a build-from-owned, dependency-free L0 spike: keep the existing semantic DOM as the evidence and control plane and add one native SVG `WorldRenderer` as a disposable spatial projection. No game engine is selected or authorized.

## Finite Prototype Contract

The candidate must demonstrate observable bounded avatar displacement, deterministic replay, clamping and wall rejection, real SVG geometry hit testing with positive and negative controls, byte-identical semantic rollback, keyboard and single-pointer parity, reduced-motion and pause behavior, zero external or non-GET requests, and explicit frame/input/idle instrumentation. Decorative avatar state is not worker execution, and renderer events have `authority_effect: none`.

## Engine Boundary

Phaser is a fallback only after a measured multi-scene, tilemap, camera, or collision trigger. PixiJS, Excalibur, and Canvas are deferred. Phaser v4.2.1 identity is not combined with v3.90 API documentation; Excalibur license evidence remains unverified for adoption. Any later dependency requires a pinned artifact and hash, exact license, version-coherent capability evidence, bundle/module/CSP/offline proof, and measurement.

## Claim Boundary

The dispatch, one feedback loop, writer, and auditor closed successfully on exact research bytes. This entry is a non-authority Inventory read-model projection. It does not authorize product mutation or dependencies, prove accessibility conformance or human benefit, or establish publication, release, deployment, production readiness, promotion, or authority.

## Next Gate

A separate owner-authorized implementation plan may define the candidate-local L0 SVG spike and its exact files/tests. Until that gate, the current product remains unchanged.
