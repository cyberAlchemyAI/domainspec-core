# DomainSpec research-strategy context-footprint strategy result

This is a non-authority Inventory read model of a confirmation-ready research
strategy. It records the proposed measurement topology and current static
accounting; it does not prove runtime token use, five-minute completion, Luna
and Sol quality parity, or H200 serving capacity.

## P1 trigger decision

Dispatch is justified by synthesis, context protection, isolation, and
parallelism. The question requires static artifact accounting, native runtime
accounting, and H200 serving analysis, followed by independent precedent,
non-vacuity, and definitional attacks.

## Lanes, groups, and subagents

- `explorers` runs three agents in parallel, matching the current three-child
  concurrency ceiling: Shannon performs deterministic prompt/budget/edge
  accounting with Luna; Hewitt audits native context inheritance and receipts
  with Sol; Simon translates the ranges into a Qwen3.8/H200 serving hypothesis
  with Luna.
- `synthesizer`: Noether uses Luna to reconcile visible payload, hidden
  overhead, peak context, aggregate processed tokens, KV demand, and wall time.
- `skeptics` runs three agents in parallel: Lakatos attacks precedent with
  Luna, Russell recomputes concrete witnesses with Sol, and Wittgenstein attacks
  category collapse with Luna.
- `writer`: Baez uses Luna to write `findings.md` only after evidence closure.
- `auditor`: Brandenburg uses Sol to audit the final findings; final approval
  remains with the parent.

The proposal therefore schedules nine unique research agents while never
claiming that more than three child agents execute concurrently.

## Dependency flow

The spine is `explorers -> synthesizer <-> skeptics -> writer -> auditor`.
There is one bounded synthesizer-to-explorers missing-evidence feedback edge
and one bounded auditor-to-writer revision edge. `max_loops` is one.

## Inventory preflight

Lookup readiness is `ready`. The selected current v0.10.0 Define model-stack
strategy provides an exact static fixture; the high-attention result requires
visible context and usable context to remain distinct. Augmentor integration
entries were excluded because they do not account tokens. The concrete design
consequence is a three-agent parallel ceiling, Luna/Sol controls, and separate
columns for exact, observed, estimated, declared, and unknown values.

## Preliminary static accounting

The proposed sheet contains nine agents, 5,539 initial-prompt characters, and
14,600 declared output tokens. A character-divided-by-four proxy estimates
about 1,385 tokens across the recorded initial prompts, but this is
tokenizer-dependent and excludes system, developer, AGENTS, tool-schema,
retrieval, upstream-return, cached-input, and reasoning overhead. Declared
output budgets are targets rather than enforced or observed usage.

The existing nine-agent Define strategy declares 20,000 output tokens per full
pass. Both totals are output-side ceilings only; downstream rereads and repair
edges make aggregate processed context larger.
