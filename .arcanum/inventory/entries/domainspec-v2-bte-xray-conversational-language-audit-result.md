# DomainSpec v2 BTE X-Ray conversational-language audit result

This entry is a non-authority Inventory read model. The accepted review and its
Whisper application improve an explanatory surface; they do not change the BTE
Design, implement machine contracts, admit a catalogue, or prove a release.

## P1 trigger and dispatch shape

P1 passed on synthesis, parallelism, and isolation. Three independent explorer
lanes attacked cold-reader task flow, Design-term fidelity, and cross-surface
information structure. One synthesizer reconciled them; two skeptics attacked
retellability and scope/authority drift; one writer persisted the verified
change requests.

- Flow: three explorers -> one synthesizer -> two skeptics -> one writer.
- Anti-bias: reader-facing clarity under semantic and authority preservation.
- Gate: checker PASS, reviewer PASS, then explicit human confirmation.
- Closeout: seven agents, one reconciliation loop, `resolved`.
- Inventory preflight: the older readability review was used only as a stale
  regression checklist; the Whisper maintenance result supplied the
  one-job-per-block check; the plain-language guide supplied first-use bridges.
  Simple-ontology and EVF results were excluded as transport or implementation
  mismatches. No Evidence Card or EvidenceSet was selected.

## Accepted audit result

The accepted C1-C8 findings correct contract drift as well as voice:

1. The versioned replacement is designed and frozen for Plan; machine schemas,
   implementation, replay evidence, and admissions remain open.
2. Runs now, Design contract, Build next, and Owner gate remain separate;
   lifecycle, implementation, evidence, and admission are separate machine
   axes, while `external` is topology.
3. The exact instance catalogue IDs are
   `node-instance-conformance@1`,
   `relationship-family-causality@1`, and
   `edge-instance-conformance@1`.
4. Every catalogue shares implementation, replay, applicable admission, and
   terminal-inclusion gates in addition to its catalogue-specific gate.
5. Consumer flow is green core aggregate handle -> consumer raw evidence plus
   non-authoritative receipt -> BTE-owned ReplayResult -> aggregate over exact
   fresh replay handles.
6. Contracts, admissions, authored inputs, derived graphs, evidence,
   aggregates, and lifecycle decisions retain separate roles.
7. Mutation is one declared semantic edit in a fresh child build whose expected
   kill is a named failure or removed causal effect.
8. Coverage key, blocking diff, typed residue, denominator, and core aggregate
   receive short first-use bridges without renaming load-bearing records.

The accepted E1-E4 findings remove the immediate retell, replace direct-address
coaching with named actors, compress the process-tab orientation, move
renderer/mode and the exact FPR decision identifier into provenance, and retain
one final four-state recall aid.

## Applied Whisper consequence

The current X-Ray HTML, `lanes.json`, `instances.json`, `X-RAY-RESULT.md`, and
`WHISPER-RESULT.md` implement the accepted change requests. The validated
`DESIGN.md` and `GLOSSARY-CONSISTENCY.md` remain unchanged contract sources.
The live local server continues to serve the corrected HTML.

- Exact profile, catalogue, relationship, lifecycle, and release decisions

- Structural and live-server validation does not substitute for a rendered
