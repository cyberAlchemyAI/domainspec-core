# Authority Lifecycle Invariant Synthesis

This is a candidate Inventory synthesis, not a canonical definition. It is the
**normative / decision layer** over the descriptive
[`scientific-authority-lifecycle-synthesis.md`](scientific-authority-lifecycle-synthesis.md):
the descriptive synthesis says *how* CyberAlchemy promotes knowledge; this one
records the **proposed** decision to make that promotion path binding (owner-gated;
**not yet enacted**) and the candidates staged for it.

> Thesis: the promotion-lifecycle shape recurs everywhere authority is earned
> (disciplines, patterns, experience, definitions). Name it once as an
> `authority promotion lifecycle` (a **build-from-owned generalization inference**),
> and bind the open class with the invariant **closed authority-kind enumeration**
> (re-scoped per CR-1; the prior "no authority without a lifecycle" framing re-skinned
> the Authority Rule) — scoped to the kind enumeration.

**Evidence backing (per CR-3):** the descriptive SAL evidence-cards back the
*descriptive* thesis only; the *normative* load here (the closure invariant, the
generalization, the lineage, the collapse-test) is backed by
[`2026-06-23-authority-lifecycle-invariant-cards.md`](evidence-cards/2026-06-23-authority-lifecycle-invariant-cards.md).
Do not cite the SAL cards as authority for the invariant.

## Collapse-test (binds the headline)

(Re-scoped 2026-06-23 per CR-1 — now tested against the **Authority Rule +
Promotion Ladder**, not just the per-kind lifecycles.) The closure invariant
reduces to the Authority Rule **unless** (a) the authority-kind table is closed
with no catch-all row AND (b) a real unenumerated-but-governing kind exists — both
true today (OQ-2's `invariant`/`axiom`). It folds to zero if a catch-all
`default-deny` row is added to the kind table (that row *is* this rule).
