# Mint / Foundry — the two-experiment result: content-autonomy holds for ALL domain classes

Candidate Inventory synthesis (**promotes nothing**; owners = cav2 authority + sigil-development). Records the
empirical result of the **Mint** feature investigation (mint a domain repo by casting the cav2 authority spine).
**Build-from-owned REFINEMENT** of [[machine-map-and-moat-synthesis]] — whose "foundry that manufactures domain
authorities" / two-System-5 boundary it flagged as "an **analogy, not a repo-cited fact**." This arc **tested it**.

## The design (resolved by refine + review, re-grounded)
Mint = a NEW cav2-native skill that **composes** `domainspec-new-repo` (scaffold) and **casts** the cav2 authority
spine. The load-bearing invariant: **inherit the meta-machinery (kind-TYPES, lifecycle D48, closure rule D49,
non-collapse, claim≤proof), localize the CONTENT** (the domain's own rules/definitions); cav2 stays harvested
precedent, never a runtime parent.

## The two pre-registered experiments (the result)
- **Run 1 — KIND-level Obs-A → FALSIFIED.** Required ≥1 genuinely-new authority KIND per domain. process + product
  passed (new kinds: a classification kind; `Deprecation schedule`, a temporal-commitment kind cav2 lacks);
  **research (resonantos) FAILED** — its kinds are owner-route re-skins of cav2 meta-kinds (Method authority→Constitution…).
- **The correction:** new-KIND was the WRONG proxy. The design *inherits* kind-types and *localizes content*, so a
  methodological domain correctly inherits and has nothing to expand — research's FALSIFIED literally *was* the
  inheritance working.
- **Run 2 — CONTENT-level Obs-A′ → SURVIVED (all 3).** Obs-A′ = ≥1 genuinely-domain-specific RULE/DEFINITION (content
  cav2 doesn't contain). Independently adjudicated (Loregian), refutation failed: research HOLDS via **≥3 carriers**
  (REC-C5 Failure-Corpus-First, REC-C7 reputation-economy axes, ER-D1 Economy-Resilience). Obs-B (no leak) + Obs-C
  (non-circular) held on all 3 in both runs.

## Finding (refines machine-map)
**The foundry works for ALL domain classes — measure autonomy as content-localization + no-leak + non-circular, NOT
"invents a new kind."** Object domains expand (new kind); methodological domains inherit-kinds + localize-content
(narrow but robust, ≥3 carriers). The two-System-5 boundary, **empirically tested**, holds at the content level —
moving machine-map's claim from analogy toward demonstrated mechanism (still candidate, INTERNAL).

## The meta-lesson (the most robust takeaway)
Pre-registration + an independent skeptic caught the **strategist's own errors three times**: a "FALSIFY-by-technicality"
goalpost-move (Lakatos refused it), a rigged confirmation-ritual criterion (forced to operationalize willing-to-lose),
and author-marks-own-homework (an independent adjudicator re-derived SURVIVED). claim≤proof held under pressure each time.
