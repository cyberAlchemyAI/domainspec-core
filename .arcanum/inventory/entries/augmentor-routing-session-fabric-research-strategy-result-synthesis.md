# Augmentor Routing And Multi-Session Fabric Research Strategy

This is a non-authority Inventory read model of a fully gated but unconfirmed
research proposal. It does not authorize the dispatch, implement Augmentor,
modify Necronomicon or Spellcraft, accept an IDE Ergonomics product decision,
or change ResonantOS.

## Direct Strategy

The hypothesis to test is **one shell, not one global session**. Augmentor
should let the user speak naturally through one interface while project,
thread, active interaction, route decision, foreground/background run,
artifact, notification, and memory remain separate owned states.

The literal witness keeps a primary conversation active while a governed
subagent-strategy proposal and a Whisper page run in parallel, permits a thread
switch, and later exposes one success and one blocker without context bleed.

## P1 Trigger Decision

Dispatch is required on all four P1 triggers:

- synthesis across Necronomicon, Spellcraft/Dispatch Spec, IDE Ergonomics, and
  current ResonantOS;
- context protection from broad current source and design evidence;
- isolation of formal state, route choice, human experience, and consumer
  runtime;
- parallelism across four independent explorer lanes.

The live type is `research`; the sheet uses schema `0.8.0`.

## Dependency Flow

`explorers -> synthesizer <-> reviewers -> evidence closure -> writer ->
auditor -> parent`, with one bounded synthesizer-to-explorer evidence feedback
route and one bounded auditor-to-writer revision route.

Every spawned agent must be joined and closed. The strategist writes
`research.md` mechanically from explorer returns; the writer does not.

## Spellcraft And Necronomicon Boundary

Necronomicon supplies continuation, side-note, route-confidence, fallback, and
capability-update precedent. It does not become a second ResonantOS session
store.

Spellcraft is the later lifecycle owner only if the surviving behavior is a
reusable composition with explicit phases, gates, handoffs, failure policy,
observability, and experiment evidence. One-off easy and test routes should
remain lighter when reuse does not warrant a spell.
