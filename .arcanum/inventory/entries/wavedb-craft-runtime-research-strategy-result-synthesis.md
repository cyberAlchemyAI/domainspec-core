# WaveDB For Craft Runtime Research Strategy Result

This is a non-authority Inventory read model of the frozen research proposal.
The proposal was subsequently confirmed, registered, executed, and closed; its
result is indexed separately as
`wavedb-craft-runtime-research-result-synthesis`. This strategy snapshot still
does not prove WaveDB suitability, implement a Craft runtime, change
`.craft/ledger.yml` authority, mutate public Arcanum, or authorize publication,
promotion, deployment, or production use.

## Direct Strategy

The dispatch compares three distinct integration postures:

1. WaveDB as a rebuildable projection or query cache.
2. WaveDB as a transactional sidecar while `.craft/ledger.yml` remains
   authoritative.
3. WaveDB as a replacement canonical store, which remains inadmissible without
   a separately owned Craft contract and migration decision.

The required result is an exact-bound architecture, a verdict for each
posture, and a falsifiable prototype plan. Research is not implementation.

## P1 Trigger Decision

Dispatch is required by synthesis, context protection, isolation, and
parallelism. The work combines external database semantics, canonical Craft
contracts, historical runtime evidence, lifecycle and failure analysis, and a
finite witness design that one sequential reader should not collapse.

The live dispatch type is `research`; the sheet uses schema `0.8.0`.
