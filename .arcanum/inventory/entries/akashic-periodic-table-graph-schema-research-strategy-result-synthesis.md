# Akashic Periodic-Table Graph-Schema Research Strategy

This entry is a non-authority read model of a frozen research proposal. It
does not confirm or register the dispatch, establish corpus truth, change
Akashic L0, authorize an ontology, or prove ingestion and query behavior.

## P1 Trigger Decision

Synthesis, isolation, and parallelism apply. The work joins implemented
SourceRecord/ClaimRecord contracts, a real external design-principle corpus,
private CyberAlchemy candidate precedents, typed-edge rules, reproducible Git
ingestion, selector verification, and six graph queries. Corpus, formal graph,
operational provenance, and portability/collision lanes can independently
falsify unnecessary schema richness.

## Lanes, Subagents, And Expected Outputs

| Lane | Subagents | Role and expected output |
| --- | --- | --- |
| Explorers | Imieliński, Tomasz; Spivak, David; Ashby, W. Ross; Riehl, Emily | Immutable corpus/query map; smallest typed edge grammar; commit-pinned ingestion, selector, extraction, and upstream-impact contract; public-safe CyberAlchemy transfer ledger |
| Synthesizer | Noether, Emmy | Reconciled record-kind/edge/query decision, finite fixture, migration path, and kill/defer list |
| Reviewers | Russell, Bertrand; Popper, Karl; Quine, Willard Van Orman | Independent precedent, non-vacuity, and definitional-soundness gates |
| Writer | Abramsky, Samson | Cited `findings.md` with schema, graph, query, ingestion, fixture, and verdict surfaces |
| Auditor | Brandenburg, Martin | Independent approve-or-revise audit of `findings.md` |

The explorers intentionally disagree over corpus completeness, formal
minimality, and operational reproducibility. The reviewers use three
non-overlapping attack vectors.

## Required Output

The result must decide whether Principle, Group, Paper, Domain, and
ImportSnapshot are records, fields, controlled values, or projections. It must
give a closed edge catalog, six query contracts, a GitHub
URL-to-immutable-snapshot and selector-resolution flow, extraction and
upstream-change boundaries, real positive and negative fixtures, an L0
migration path, an explicit Olog borrow/avoid decision, and a CyberAlchemy
transfer ledger classifying candidate mechanics as portable-as-is, adapt,
private-only, contradicted/colliding, unproved, or reject.

Every new kind or edge must change validation or query behavior. Generic
`related_to` is presumed forbidden. Private authority kinds, owner routes, CAV2
identifiers, and workspace paths cannot enter a public Akashic contract.
Authority and promotion are outside this first working version.

## Dependency Flow

```text
four explorers in parallel
  -> synthesizer
  <-> three reviewers in parallel
  -> writer
  -> auditor
  -> one bounded writer revision if required
  -> parent final approval
```

## Inventory Preflight And Consequence

Akashic has no target-local Inventory. The parent machine index selected prior
Akashic L0 deferral evidence, the evidence-to-ontology non-collapse ladder, a
typed-edge admission precedent, finite graph-witness requirements, and the
current CyberAlchemy node/relation, closed-edge, projection, and candidate-graph
Design surfaces. Learned hierarchy, full authority lifecycle, abstract
category-theory substrate, and direct private authority-vocabulary transfer
were excluded as unnecessary or unsafe scope expansion.

The periodic-table questions satisfy the earlier requirement for a distinct
query witness, so graph semantics may now be researched. They do not
pre-authorize any record or relation. The lanes therefore require
corpus-grounded fixtures, non-redundant edge behavior, strict separation of
deterministic fetching/selector verification from heuristic extraction, and a
source-accurate portability/proof-status classification for every borrowed
CyberAlchemy mechanic.
