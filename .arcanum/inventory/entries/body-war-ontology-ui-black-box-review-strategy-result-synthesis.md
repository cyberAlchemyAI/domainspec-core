This entry is a non-authority Inventory read model of the completed review. It
does not edit the viewer or ontology, establish human comprehension, promote
ontology meaning, or admit release or production.

## P1 Trigger Decision

Dispatch is warranted by synthesis, isolation, and parallelism. Cold-reader
task behavior, perceptual accessibility, graph-navigation structure, and
semantic authority require independent attacks whose outputs must be
reconciled and skeptically checked.

## Inventory Effect

The machine-index-first lookup selected the prior Body War comprehension review
and its evidence cards. Those sources require six candidate comprehension loci,
relation-local semantics, redundant non-color authority cues, and a strict
browser-versus-human evidence boundary.

The current direct graph adds a decisive constraint: it exposes one
`branch:business` tag, while the only explicit small projection groups are five
four-node tour scenes with eleven cross-scene relations. The proposal therefore
tests **focus scene** as removable UI behavior and forbids treating it as
ontology truth. Tour scenes are the first hypothesis; one-hop neighborhoods are
the fallback hypothesis; type layers are not presumed to be branches.

## Verified Review Result

The exact frozen viewer failed the proposed focus-scene behavior: tour step 1
and non-tour Focus retained all 237 nodes and 231 edges. The joined attacks also
found invisible sampled keyboard focus, mouse-only connection rows, missing
persistent selected-relation state, stale tour selection, inconsistent search
and detail vocabulary, and loss of overview kind distinction under forced
colors.

The verified design direction is a bounded hybrid UI projection:

- use a source-derived four-node tour scene for tour members;
- use a deterministic one-hop neighborhood for non-tour nodes;
- render every boundary-crossing relation as a labeled, directed portal;
- preserve exact relation fields, endpoint provenance, candidate status,
  `authority:none`, breadcrumb/Back, and equivalent pointer, keyboard, and
  reduced-motion semantic state.

All five change requests survived opposed verification after one bounded repair
loop. No change request was dropped. Unsupported claims about contrast,
rotation, tour sufficiency, and human comprehension were removed or bounded.
