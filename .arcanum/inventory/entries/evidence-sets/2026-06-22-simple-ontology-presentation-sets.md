# EvidenceSets - Simple Ontology Presentation Corpus

EvidenceSets are candidate Inventory read models. They group evidence-card IDs
for repeated lookup and handoff assembly. They do not imply ontology,
definition, constitution, schema, ledger, presentation, Whisper, or Context
Builder authority.

## `evset-simple-ontology-whisper-brief`

- Status: candidate
- Evidence cards:
  - `simple-ontology-map-with-receipts`
  - `simple-ontology-inventory-boundary`
  - `simple-ontology-authority-caveat`
  - `simple-ontology-whisper-spine`
  - `simple-ontology-forbidden-overclaims`
- Inclusion reasons: These cards jointly preserve the accepted simple-ontology
  presentation brief: a clear thesis, inventory-vs-ontology distinction,
  CAV2 authority caveat, five-slide Whisper spine, and lint terms for avoiding
  overclaims.
- Excluded card refs:
  - `op-ontology-d19-demotion-boundary`: useful for the demoted Operational
    Ontology decision, but excluded because this set is about a general
    presentation explanation of ontology rather than the D19/D23 classification
    review.
  - `caol-lifecycle-envelope-contract`: useful authority-lifecycle context, but
    excluded because this set needs audience-simple presentation material rather
    than a PromotionRecord fixture path.
- Handoff target: Whisper, context-builder, definitions-governance, and any
  future short presentation or public-safe explanation of ontology.
- Synthesis note: Use this set when the next task is to explain ontology simply.
  It should provide the short script spine while preserving the warning that
  ontology models meaning and prepares promotion but does not promote authority
  by itself.
- Index terms: `ontology presentation`, `map of meaning with receipts`,
  `inventory finds receipts`, `ontology interprets receipts`,
  `map is not the government`, `Whisper ontology brief`, `forbidden overclaims`,
  `ontology-derived typed context`, `promotion guardrail`
- Residue: The source corpus is presentation-oriented. If the next task needs a
  canonical definition, use `CAV2-D19` through definitions-governance rather than
  promoting this EvidenceSet.
