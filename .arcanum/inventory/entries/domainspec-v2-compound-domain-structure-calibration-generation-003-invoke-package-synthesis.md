# DomainSpec v2 Compound Domain Structure Calibration Generation 3 Invoke Package

This non-authority Inventory read model records the Define, Design, and Plan
package for generation-3 discriminating evidence repair. It does not record
implementation, browser evidence, a calibration result, or authority state.

## Plan

Generation 3 protects generations 1/2, freezes six atomic targets derived only
from parent substitution text, adds isolated source-derived browser observations
and a preregistered test-impact differential, freezes a 36-cell adjudication
overlay, evaluates through unchanged v1 code, appends once, and independently
audits the result.

The plan is high complexity and split into nine serialized SWUs across L0-L3.
`SWU-CDSC3-001` is ready and owns only protected imports plus the atomic-target
contract. It cannot install browser dependencies or write observations.

## Flag

No Playwright CLI/package is installed in the current workspace.
`B-CDSC3-PLAYWRIGHT` therefore requires a Decision Gate at SWU002: approve a
pinned package-local install, bind a user-provided runtime, or defer. The flag
does not block SWU001 and does block all browser evidence.

## Boundaries

The closed UI-repair package owns portability corpus and dossier policy; its
below-threshold/missing results are imported only as stable limits. Savvy stays
read-only. No generation-3 artifact can define Page identity, a compound DS-D1
type, a DS-D8 relationship, pattern admission, candidate state, activation, or
promotion.
