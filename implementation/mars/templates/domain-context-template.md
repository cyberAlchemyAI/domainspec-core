# Domain Context

Purpose: explain the project's problem setting and prior-art context before protocol design begins.

This artifact answers: what setting is being studied, what policy or decision regimes are in scope, what prior-art sources define the external-validity frame, and which failure modes later experiments are supposed to observe.

## Why This Artifact Exists

- Protocols should not be the first place where the research setting is defined.
- Later experiment bundles need one stable explanation of the domain or decision context.
- This artifact should be written from sourced and inventoried authorities, not from operator memory alone.
