confirmation, the parent will:

1. register one schema-0.8.0 dispatch row;
2. spawn both agents once in one parallel wave;
3. join and close both;
4. preserve their raw receipts and assemble `attacks.md` and `findings.md`;
5. close `B-DESIGN-001` only if both validations pass over the exact repaired
   digest with no new CRITICAL or MAJOR finding; and
6. append exactly one close row.

The route does not mutate target planning files, select an SWU, implement the
add-on, refresh Bootstrap, run a browser, or change GitHub state.
