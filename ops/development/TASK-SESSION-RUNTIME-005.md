## Recommended Decision

Recommended profile contract:

| Profile | Writes | Default mutation mode |
| --- | --- | --- |
| `personal-codex` | `$CODEX_HOME/skills/<name>/SKILL.md` and alias packages | explicit only; never included in repo-local `all` |
| `repo-local` | `tools/arcanum` or installed equivalent, `.arcanum/runtime/config.json`, adapter profiles | explicit |
| `github-copilot` | `.github/skills/*`, `.github/instructions/*`, `.github/copilot-instructions.md`, `AGENTS.md` | explicit |
| `claude` | `.claude/skills/*`, `.claude/agents/*`, `CLAUDE.md` | explicit |
| `observability` | `.arcanum/observability` config and structure markers only; ledgers local/generated unless promoted | explicit |
| `all` | `repo-local`, `github-copilot`, `claude`, `observability`; excludes `personal-codex` | explicit |
| `none` | no writes; source-only | n/a |

This avoids silent global mutation and keeps generated native packages runtime-local.

## Decision Resolution

Resolved on 2026-05-29.

Selected option: explicit native profiles.

Decision artifact:

- `docs/decisions/install-profile-contract.md`

The selected contract is the recommended profile contract above:

- `personal-codex` is explicit only and never included in repo-local `all`.
- `repo-local` writes repository-local tool/runtime config only.
- `github-copilot` writes GitHub/Copilot-native generated packages and guidance.
- `claude` writes Claude-native generated packages and guidance.
- `observability` writes config and structure markers only by default.
- `all` includes repo-local, GitHub/Copilot, Claude, and observability, but excludes personal Codex.
- `none` writes nothing.
