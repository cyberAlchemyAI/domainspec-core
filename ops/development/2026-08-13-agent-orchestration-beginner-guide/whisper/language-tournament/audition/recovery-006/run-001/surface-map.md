# Surface map — three-route concrete teaching tournament

## State

- Transport: `interactive_guided_class` (candidate / unproven)
- Intent: volatile
- Human gate: pending
- Draft: flag
- Authority effect: none

This map separates what the learner encounters from runtime bindings and authoring evidence. A candidate may change story spine and teaching method, but it may not move control metadata into visible choices or hide a required learning moment.

## Ownership layers

| Layer | Audience sees it? | Owner | Allowed content |
| --- | --- | --- | --- |
| Problem surface | yes | transport | Actor, object, condition, consequence, responsibility, and one question worth answering. |
| Attempt surface | yes | transport plus frozen controls | Parallel ordinary-language choices or retell prompts; no formal answer token. |
| Branch surface | after its attempt | transport | Candidate-specific consequence of the submitted answer; no blame and no later-answer leak. |
| Formal reveal | after the required branch | semantic contract | Exact protected terms, state order, mapping order, and immediate non-implications. |
| Transfer surface | after reveal | transport | Changed problem requiring reconstruction rather than repetition. |
| Repository connection | after distinction | semantic contract | Exact public path plus the fact it supports and the claim it does not support. |
| Runtime controls | never as labels | implementation owner | Lesson IDs, question IDs, hidden values, expected values, field IDs/names, and local-state rules. |
| Tournament rationale | no | Whisper and Distill | Candidate design claims, objections, scores, Pareto trade-offs, and risks. |
| Jury decision | no | parent | Independent review and operator recommendation; outside helper scope. |

## Route 1 — Work Shape

Audience sequence:

1. Meet a concrete request pair whose consequences differ.
2. Answer `choose-one` and `choose-two` through two parallel visible setup choices.
3. Cross the single **Check both decisions** boundary.
4. Receive branch-specific explanations.
5. Reveal `boundary` → `bounded helper` → `governed dispatch` → `authority`.
6. Apply the distinction to a changed problem and connect it to `arcanum/arcana/subagent-strategy/SKILL.md`.
7. Retain the limit: choosing a shape grants no authority and starts no work.

Runtime-only bindings: lesson `lesson-choose`; `choose-one` values `helper`, `dispatch`, expected `helper`; `choose-two` values `helper`, `dispatch`, expected `dispatch`. The words `gate` and `receipt` remain deferred.

## Route 3 — Evidence Lifecycle

Audience sequence:

1. Encounter one concrete returned result and a later decision that needs every required result.
2. Attempt `relay-predecessor` in ordinary language before seeing the ladder.
3. Receive its branch explanation.
4. Reveal exactly: `Action persisted` → `Attempt recorded` → `Host result recorded` → `Terminally accounted` → `Receipt admitted` → `Receipt joined` → `Gate decided` → `Dependent plan persisted` → `Terminal closeout recorded`.
5. Inspect one changed fact and one immediate non-implication per state.
6. Attempt `relay-limit`, then see the dependent-work loop and terminal-closeout branch.
7. Connect to `arcanum/runtime/orchestrate/tests/evidence-order/fixtures/valid-ordered.jsonl` without treating order as truth.

Runtime-only bindings: lesson `lesson-relay`; `relay-predecessor` values `host-result`, `receipt-admitted`, `receipt-joined`, expected `receipt-joined`; `relay-limit` values `nothing`, `new-plan`, `truth`, expected `new-plan`.

## Route 7 — Transfer And Owner

Audience sequence:

1. Encounter a concrete handoff in which a decision permits planning but no next-worker input exists.
2. Draft the provisional four-link retell in fields `exit-situation`/`situation`, `exit-present`/`present`, `exit-missing`/`missing`, and `exit-human`/`human`.
3. Attempt binary question `transfer-start` with values `yes`, `no`, expected `no`.
4. Receive its branch explanation.
5. Reveal `Receipt` → `Admitted` → `Joined` → `Gate` → `Persisted action`.
6. Correct the retell and save only after the existing local presence and minimum-length rule passes.
7. Connect to `arcanum/runtime/orchestrate/scripts/native_dispatch_driver.py` and preserve human meaning review.
8. Show exactly `Exit ticket saved; this lesson is complete.` only on the successful local branch.

Controls preserve the current abstract baseline, a minimally concrete baseline, and an intentionally overstory-rich stressor.

## Analogy boundary

When present, an analogy has three visible sentences: what maps, what does not map, and when to drop it. It may illuminate a relation; it may not imply that headcount creates governance, authority, truth, evidence admission, execution, or completion. Literal state names and runtime controls always supersede the analogy.

## Shared claim ceiling

Every sample may teach inference. No sample, local answer, stored retell, repository path, author score, or Pareto position establishes comprehension, semantic truth, authority, execution, route completion, promotion, publication, deployment, production readiness, or transport proof.
