# Implementation Layering: Whisper Editorial Gate Hardening

## Target and boundary

- Target: reusable Whisper editorial admission path.
- State: brownfield public spell with partial prose contracts and structural tooling.
- Current guarantee: canonical Whisper describes candidate ceilings, volatile intent, audition separation, and human approval; current tooling does not enforce the joined result.
- Boundary heuristic: start a new layer when the next work answers a different decision rather than increasing confidence in the current one.

## Non-regression guardrails

1. Existing resonance, relevance, trajectory, and transport ownership remain intact.
2. Existing structural Markdown validation stays conservative and remains a separate axis.
3. Candidate transport status cannot be raised by local configuration or operator approval alone.
4. Later layers must preserve L0's non-substitution between evidence axes.
5. Private BTE language must never enter public Arcanum fixtures or documentation.
6. Repository-local presets must survive regeneration without becoming public canonical content.
