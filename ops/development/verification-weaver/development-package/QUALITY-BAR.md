# Quality Bar: Verification Weaver

## Pass

The package may return `pass` only when:

- target classification is deterministic and valid;
- every required owner lane has a native receipt or explicit non-required
  status;
- every obligation has evidence or a non-required explanation;
- no hard residue remains;
- public-safety scans pass;
- generated outputs are not treated as source authority;
- no parent receipt promotes owner artifacts.

## Flag

The package must return `flag` when:

- an owner lane is seed/spec-only;
- UX evidence requires human review;
- architecture mapping is incomplete but not false;
- research evidence is dry-run only;
- a mixed target decomposes successfully but one lane has residue;
- a soft anti-pattern is present but not hard-blocking.

## Block

The package must return `block` when:

- target is unsupported;
- no oracle is bound for a formal/testing claim;
- private path or copied private example would enter public package content;
- generated output or local log is used as promotion evidence;
- adapter/runtime is missing or incompatible;
- E2E evidence is flaky or environment-dependent without stabilization;
- parent receipt attempts promotion;
- a required owner lane blocks.

## Promotion Evidence Required Later

Before registry or generated runtime exposure:

- README and SKILL exist;
- output contract exists;
- quality bar exists;
- anti-patterns exist;
- positive fixtures exist;
- negative controls exist;
- validation runner exists;
- public-boundary scan passes;
- experiment-harness evidence exists;
- sigil-development review approves promotion route.
