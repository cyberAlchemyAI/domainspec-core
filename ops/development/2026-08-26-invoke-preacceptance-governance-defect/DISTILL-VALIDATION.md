## Smallest Coherent Unit

SWU-IGD-001 is the current smallest coherent implementation unit after W0. Schema-only relaxation would be
unsafe because the validator currently treats every non-proposal package as approval-
bound and emits `ready`. Validator-only behavior would remain structurally invalid.
The schema condition, validator branch, receipt outcome, and focused fixtures are
therefore one independently reviewable state/authority behavior.

It is the narrowest reversible trust-building step because it makes exact candidate
bytes representable without yet changing content parsing, request emission, stage
orchestration, generated runtimes, or Body War artifacts.

The unit is not executable until W0 inventories every consumer and freezes the exact
token/version contract. That gap is owned by Spellcraft and is the reason for the
Distill `flag` rather than `pass`.

## Closure And Recomposition Proof

The broad layer is truthful no-effect preacceptance and separately authorized
runtime packaging. It decomposes into:

```text
represent candidate
  -> understand its declared content
  -> bind the exact owner-facing effect
  -> evaluate every reachable stage truthfully
  -> prove the actual candidate crossed the actual consumer
  -> rehearse the complete canonical lifecycle
  -> separately package the reviewed canonical result
```

Each of the seven units has named inputs, outputs, failure modes, and an independent acceptance
boundary. Recomposition closes the original defect family; splitting further would
leave a schema without a producer, an invocation without receipt binding, or a
failure status without causal stage semantics.

## Deferred Complexity

- Binary postimages and arbitrary media types: no current evidence requires them.
- A general selector language: JSON Pointer plus literal text assertions is enough.
- Structural YAML: deferred unless Spellcraft owns and pins the parser, version,
  safety mode, and JSON-compatible admitted subset.
- Automatic retry/resume: forbidden because authority-bearing executable digests
  change.
- Body War WPRA, provider, privacy, deployment, geometry, and scoring contracts:
  owned by later project work.
- Parallel implementation: shared schemas/tests make serial waves safer at this
  scale.

## Premortem

Most likely failure: unit fixtures pass, but preacceptance still validates a help screen
or a different package rather than the exact staged candidate. Guard: the L2 receipt
must bind package ref, package digest, output refs, final-postimage targets, real
validator identity, and the isolated material receipt; anti-help and wrong-package
fixtures are acceptance-critical.

credentials, deployment, publication, or external effects.
