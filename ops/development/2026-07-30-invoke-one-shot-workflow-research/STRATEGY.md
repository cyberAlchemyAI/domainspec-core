# Invoke One-Shot Workflow Research Strategy

## P1 trigger

This is a governed `research` dispatch.

- **Synthesis:** the answer must join current Invoke, Task Session, readiness,
  material-admission, closeout, and observability contracts with external
  precedents.
- **Context protection:** raw local chronology and external-source returns are
  larger than the parent should carry directly.
- **Isolation:** the target architecture must survive independent precedent,
  non-vacuity, and definitional attacks before it becomes a repair proposal.
- **Parallelism:** local forensics, external precedents, and formal protocol
  design can run independently.

## Target outcome

The research will define the most complete realistic upfront Invoke artifact:
all discoverable objective, question, decision, ownership, dependency,
material-admission, validation, and closeout blockers must be explicit and
closed before the work pack is executable.

It will not claim that execution can reveal no new empirical failure. The
target is one approved **outer** work-pack run with no predictable bounce to
generic Refresh, while its inner executor still runs one bounded Task Session
per SWU and stops safely on genuine runtime evidence.

## Dependency flow

```text
explorers (parallel)
  -> synthesizer
     -> explorers feedback (only for missing exact evidence, cap 1)
     <-> skeptics (zig-zag, cap 1)
        -> evidence closure
           -> writer
              -> auditor
                 -> writer revision (cap 1)
                    -> parent final approval
```

All initial dependencies are sequential or zig-zag. Feedback edges are repair
routes only and do not make a downstream stage initially ready.

## Evidence contract

The dispatch uses `exact-binding`.

Every load-bearing local row must carry a source path, stable selector or
structured pointer, explorer return reference, evidence scope, and proof
status. Every external precedent must use a primary source with an immutable
identity where available and a source-local selector. Missing explorer-owned
evidence blocks the writer or returns through the declared explorer feedback
edge.
