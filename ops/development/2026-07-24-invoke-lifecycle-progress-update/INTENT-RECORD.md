# Intent Record: Invoke Lifecycle Progress Update

Date: 2026-07-24

Target type: public Arcanum spell and adjacent execution-sigil contracts

Authoring location: private parent repository

Requested mode: Invoke `define -> design -> plan`

## Raw intent

Turn the accepted Invoke lifecycle-churn research into a governed update that
can remove the demonstrated Plan -> Task Session -> Refresh loop without
weakening exact-digest admission or one-SWU execution.

## Interpreted objective

Define and plan a generic lifecycle-progress protocol in which:

- an authored-valid plan is not automatically execution-ready;
- one immutable execution epoch identifies one selected SWU;
- every execution mode has compatible producer, validator, and consumer roles;
- Task Session is routed only after an independent readiness verdict is ready;
- exact byte drift still blocks an obsolete join, while a separate classifier
  determines semantic impact;
- lifecycle progress is an admitted append-only transition, not a count of
  runs, Refreshes, projections, or cursor movement;
- plan repair cannot change epoch-bound control identity in place; it creates a
  successor epoch and supersedes the old one;
- legacy plans gain no inferred readiness;
- a live generic proof is required before promotion.

## Approval boundary

The direct user request approves authoring this private Define, Design, and Plan
package. It does not approve:

- mutation of canonical public Arcanum;
- mutation of generated `.agents` or `.claude` surfaces;
- Task Session execution;
- lifecycle promotion, registry release, publication, commit, or push;
- copying private project evidence into public Arcanum.
