# Invoke Define Ten-Project Laboratory

This private, no-effect laboratory recompiles ten materially established project
surfaces through the candidate Invoke Define atomic producer.

The laboratory tests the producer contract:

- exact discovery-byte binding;
- schema-valid machine sources;
- atomic nine-file bundle publication;
- digest-valid Invoke-owned stage receipts;
- byte-identical second compilation; and
- stale-discovery rejection with no output publication.

It does not prove that the compiler understands arbitrary project prose. The
case manifest contains a human-curated, deliberately narrow semantic projection
from each existing project. The compiler proves that projection was packaged
correctly and bound to the declared discovery bytes; it does not prove project
truth, completion, promotion, runtime readiness, or production behavior.

Run from the repository root:

    PYTHONDONTWRITEBYTECODE=1 python3 ops/development/2026-08-27-invoke-define-10-project-lab/run_define_lab.py

Persistent outputs are limited to this directory. Temporary second-run and
negative-control outputs are removed automatically. Nothing under public
Arcanum, the source projects, generated skill packages, Git, publication,
deployment, or external systems is mutated.
