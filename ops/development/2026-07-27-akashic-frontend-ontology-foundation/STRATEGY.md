# Akashic frontend and ontology foundation — completed private research strategy

## P1 trigger decision

Dispatch is warranted by synthesis, isolation, context protection, and
parallelism. The work must reconcile non-programmer comprehension, current
Akashic machine contracts, private ontology precedent, public/private
separation, and the smallest implementable browser architecture.

This is a `research` dispatch. It produces an evidence-backed direction; it
does not implement code because the governed `code` dispatch type is reserved.

## Intended answer

Determine the smallest useful read-only frontend and define the graph profile
it may present. The findings must recommend:

1. one primary journey, information architecture, and screen map;
2. a public-safe Akashic graph profile with node kinds, edge signatures,
   cardinalities, symmetry, evidence bindings, and cycle policy;
3. a `reuse / adapt / reject` verdict for every CyberAlchemy-derived pattern;
4. the browser/runtime adapter and digest-bound projection boundary;
5. an exact seven-principle and Q1-Q6 screen witness;
6. the smallest technology, accessibility, and Playwright testing stack;
7. implementation slices for a later Invoke run;
8. explicit deferrals for authoring, review persistence, authentication, live
   Git transport, agent execution, authority, publication, and deployment.
