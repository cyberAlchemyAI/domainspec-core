## Selected Smallest Coherent Unit

```text
closed JSON SemanticPackage
  -> five-module SchemaSuite validation
  -> OV-CANON-JSON/v1 canonicalization
  -> deterministic NormalizedSemanticModel
  -> one Markdown ProjectionDefinition
  -> byte-stable HumanView + ProjectionReceipt
  -> view selector -> SourcePatch proposal
```

The `AdmissionRecord` is included as a negative boundary witness, not as an L0
admission implementation: the same valid package must remain non-admitted until
an external owner record exists. This is necessary to prove validity does not
collapse into authority.

## Representation Selection

Closed JSON wins v1 under the selected unit because:

- it proves local closure without another grammar/compiler;
- it gives one source identity and a small deterministic byte contract;
- forms and editors can remain humane by emitting SourcePatch operations;
- long-form content remains typed through stable content blocks;
- JSON-LD remains available as a derived graph view;
- strict YAML can be tested later without making the first proof depend on a
  second compiler trust boundary.

This is a candidate design selection, not public admission.

## Non-Regression Invariants

1. One admitted semantic fact has one authored owner source.
2. Stable identity is owner-assigned and independent of content, position, or display order.
3. Exact-source, canonical-source, normalized-model, schema, compiler, definition, template, and output digests stay separate.
4. Normalized IR is disposable and never independently authored or admitted.
5. Generated views cannot write back or invent semantic claims.
6. Unknown, unsupported, contradiction, and migration residue remain typed.
7. Schema validity, admission, promotion, and operational reliance remain separate owner decisions.
8. Public schemas contain no private adopter terms, paths, prose, or fixtures.

## Split Pressure And Deferred Complexity

- Evidence and governance remain `$defs` in the record schema for v1; no
  independent lifecycle evidence currently earns two more source modules.
- Graph/query projectors are L1 after the Markdown kernel.
- Forms, semantic diff, and patch application are L1; only the SourcePatch
  contract and one correction witness belong in L0.
- Migration and AdmissionRecord implementation are L2.
- Profile adapters, lifecycle synchronization, packaging, and observability are L3.

## Recomposition Proof

The selected unit establishes the missing source/projection spine and reuses
the current entry, relation, lifecycle, confidence, evidence, governance, and
PromotionRecord boundaries. Later layers add projectors, authoring, migration,
and lifecycle integration without changing the L0 truth-source invariant.

## Rejected Alternatives

- One mega-schema: collapses independently evolving concerns.
- JSON-LD source: adds context and graph normalization choices before needed.
- Strict YAML source in v1: adds a compiler/source-identity boundary before
  form-based authoring is falsified.
- Markdown plus frontmatter: lets semantic content escape typed source fields.
- Editable generated views: creates parallel authority.
- Content-addressed semantic IDs: ordinary corrections destroy continuity.
- Aggregate build digest: hides which boundary drifted.

## Residue

- Candidate schema bytes and validators are unimplemented.
- The exact canonicalization algorithm is designed in Stage 06 but unexecuted.
- The L0 witnesses and design-selection validator remain planned.
- Public mutation and promotion remain later owner routes.
