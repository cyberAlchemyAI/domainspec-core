## Round 1

- **Proposer claim:** one HTML file should contain the event invitation,
  45-minute route, and all fourteen project opportunities so the product idea
  can be inspected in a browser before framework work.
- **Evidence/assumption:** Define and Design already require one shared
  page/presentation artifact and an accepted fourteen-project substrate.
- **Balancer objection — task shape:** visual styling, responsive layout,
  project copy, mode switching, forms, and interaction can each pass
  independently.
- **Reconciliation — revise:** retain only semantic document structure,
  inline low-fidelity presentation styling, complete bounded card content,
  anchor navigation, and responsive meaning. Exclude JavaScript, mode state,
  forms, submissions, persistence, deployment, final Whisper copy, and visual
  polish.

## Round 2

- **Proposer claim:** the HTML prototype should replace the record contract as
  the first L0 unit because it gives faster visible feedback.
- **Evidence/assumption:** the user requested the prototype “as L0,” not as a
  replacement for the selected trust proof.
- **Balancer objection — trust order:** replacing the selected unit would
  invalidate its strict pack and let a browser mockup appear to consume
  admitted truth it does not have.
- **Reconciliation — reject replacement:** keep `SWU-COOP-001` selected.
  Add `SWU-COOP-002` after its closeout and require a new explicit selection
  and strict pack before HTML mutation.

## Smallest Coherent Unit

`SWU-COOP-002` owns one primary behavior: a local browser can render one
self-contained semantic document in which a reader or facilitator can inspect
the Co-Op invitation, the 45-minute route, and exactly fourteen distinct
claim-bounded project opportunities without implying an operational exchange.

Splitting the shell from the project set loses the prototype’s only useful
question: whether the complete portfolio and meeting narrative cohere in one
artifact. Adding interaction would create independently verifiable behavior
and therefore remains outside the unit.
