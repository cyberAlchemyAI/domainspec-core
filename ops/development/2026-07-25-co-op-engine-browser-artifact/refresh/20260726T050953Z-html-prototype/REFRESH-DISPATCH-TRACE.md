## Full Dispatch

`refresh.dispatch.json` is required because the route composes Context Builder,
Distill, Invoke Refresh, private research evidence, an explicit apply
authorization, and a future Task Session handoff.

## Skipped

- subagent delegation: the accepted research fan-out is already closed and the
  refresh is serial;
- tournament: the user selected HTML and no competing target is in scope;
- Decision Gate: the safe interpretation is additive, not replacement, and
  keeps the existing selected SWU;
- public projection: every output remains private/internal.
