# Invoke Design Dispatch Technique Trace

The existing dispatch remains the route authority; Design adds this
mode-specific trace and does not introduce a new delegated dispatch.

| Technique | Activation | Design effect | Validation |
| --- | --- | --- | --- |
| `sequence` | user selected Define → decisions → Design → review → Plan | Design runs only after D-001–D-004 and D-006 close | stage status and next route are explicit |
| `artifact_contract_bridge` | approved Define records must become architecture without claim drift | every view traces to exact source digests and Concept IDs | manifest, denominator, and selection receipts |
| `owner_boundary_check` | truth, privacy, UX, validation, hosting, and publication have distinct authority | concern rows name accountable, contributing, artifact, and validator owners | validator rejects unresolved owners |
| `concrete_path_evidence` | target project does not exist yet | Design paths are exact; implementation path is named but not mutated | stale or missing selectors block |
| `validation_loop` | six views alone are not completeness evidence | deterministic extraction and selection repeat from immutable inputs | equal pass-one/pass-two digests required |
| `residue_ledger` | D-005 and executed audits remain downstream | risks and gaps retain owner, gate, and next route | Plan cannot reinterpret residue as pass |
| `handle_handoff` | accepted Design must route to acceptance review and then Plan | transport names exact receipts and evidence ceiling | normal Plan requires `design-validator-pass` |
| `observability_grouping` | Invoke, Distill, and required sigils share one lifecycle | child and parent receipts use the same session and lineage | deduplicated signal rows |

## Skipped Techniques

- `scu_swu_reduction`: deferred to Invoke Plan, which owns task/SWU creation.
- `execution_receipt_handoff`: no witness is executed during Design.
- `authority_split_gate`: ownership is explicit and no public release is
  requested; D-005 remains a later gate.
- new multi-agent dispatch: the research dispatch is already closed and Design
  has no independent parallel role whose output would change the denominator.

## Dispatch Validation

`execution.dispatch.json` remains required because the lifecycle crosses
Invoke, Distill, Context Builder, validation, and later Task Session boundaries.
Its canonical validation must remain `pass` with zero flags and blocks.
