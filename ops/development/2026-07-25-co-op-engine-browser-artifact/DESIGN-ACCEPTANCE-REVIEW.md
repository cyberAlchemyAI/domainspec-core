## Hard Acceptance Boundaries for Plan

Plan must not:

- bundle browser rendering into the first record-contract SWU;
- implement private persistence before deterministic state and visibility
  contracts exist;
- call any planned audit executed;
- substitute screenshots for DOM, keyboard, network, storage, or privacy
  evidence;
- treat automated proxies as comprehension or coherence proof;
- send Design artifacts directly to public copy;
- make the restricted deployment public without D-005 and passing audits.
