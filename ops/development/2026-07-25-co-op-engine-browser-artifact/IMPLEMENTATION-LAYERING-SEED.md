# Implementation Layering Seed

This is a Define-stage boundary seed, not the Plan-required layering artifact.

| Layer | Candidate question | Promotion evidence |
| --- | --- | --- |
| L0 | Can one admitted record preserve claim, state, and invalid-transition boundaries? | Exact Poker fixture plus known-bad transition and hidden-state fixtures |
| L1 | Can the same record drive self-guided and facilitated semantic projections? | Black-box route, DOM, keyboard, history, and screenshot agreement |
| L2 | Can privacy, reciprocal appointment, receipt, and failure states survive every observable surface? | Projection/leakage, state-machine, and persistence evidence |
| L3 | Can fourteen bounded cards, the 45-minute route, human audits, and final copy work together? | Card-ceiling audit, both cold-reader profiles, Whisper approval, publication decision |

Design may revise these boundaries. Plan must create the full artifact, waves,
tasks, SWUs, promotion rules, and closeout synchronization contracts.
