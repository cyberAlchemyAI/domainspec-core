# WaveDB source-build route

This candidate-local Invoke slice replaces no canonical source and does not
reinterpret the failed npm provenance receipt. It defines, designs, plans, and
executes one isolated build of the reviewed WaveDB source commit so the parent
Craft projection experiment can decide whether to consume a locally built
addon as experimental evidence.

The source-build route owns only its ignored local work area and filesystem
receipts. It grants no publication, package provenance, Craft authority,
deployment, or production claim.

Start with `define/SPEC.md`. Runtime execution is admitted only through the
selected SWU in `plan/WORK-PACK.md` after Design and Plan validation pass.
