# Define Template Selection

- Selected family: `domainspec-spec`
- Eligibility: the target is a capability-driven runtime update with operations,
  queries, interfaces, states, events, mappings, and a typed concept registry.
- Discovery: present through the blocked incident result plus accepted Augmentor
  routing and subagent research.
- Tie check: no tie. Generic would lose the aspect-level runtime contract;
  module-formulae and implementation-plan are deprecated.
- Standalone layering: seeded for downstream Plan in
  `planning/IMPLEMENTATION-LAYERING.md`.
- Promotion: none. Template use does not promote this package or its terms.
