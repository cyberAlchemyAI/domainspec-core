# Design Template Selection

- Selected profile: DomainSpec six-view architecture bundle.
- Selected triggered extensions: authority/trust, state/event,
  persistence/concurrency, failure/compensation, integration/versioning,
  data lifecycle, quality, and validation contracts.
- UX companion: not selected. The target has no new or changed rendered human
  semantic surface; consumer-owned presentation is a later package.
- Research companion: not selected. Current evidence is sufficient for the L0
  contract; host reservation/release remains an explicit owner gap.
- Spell/sigil companion: not selected. Orchestrate is a canonical native runtime
  package, not a sigil or spell lifecycle target.
