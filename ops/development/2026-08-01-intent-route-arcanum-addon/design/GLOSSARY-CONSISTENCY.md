# Glossary consistency

- `candidate` remains advisory; it is never called selected, approved, or
  authorized.
- `receipt_digest` remains the compatible wire name but is described only as
  disposition integrity.
- `Dispatch` refers to the existing canonical Dispatch/group/seat owner; no
  new dispatch object is defined.
- `Bootstrap` means installer/projector, not resolver or promotion authority.
- `runtime adapter` means projection/transport/rejection only.
- `reasoning-engine advance` is limited to pre-inference route reduction and
  abstention.

No public definition is changed by this candidate design.
