# Migration and rollout

1. Resolve public extraction, API, license, catalog, normalization, and ACI
   owners without code mutation.
2. Build a candidate-local public-safe sigil closure and run core/static/
   browser witnesses.
3. Obtain explicit canonical acceptance; only then update public Arcanum.
4. Generate Claude and Codex packages in isolated roots and prove parity,
   disable, failure rollback, and exact closure restoration.
5. Install in one disposable consumer and prove no product/authority effects.
6. Refresh the ResonantOS add-on plan to consume, not duplicate, dispositions.
7. Plan and execute orchestrator, Augmentor, and CAV2/ACI integrations as
   separate owner-controlled work packs.

Each stage is independently stoppable. Passing one stage does not authorize
the next, release, deployment, or production use.
