# Quality attributes

| Attribute | Contract |
|---|---|
| determinism | same canonical inputs and closure yield byte-identical outputs |
| order invariance | catalog/order permutation does not change canonical disposition |
| uncertainty monotonicity | removing evidence or restoring unresolved posture cannot improve to candidate |
| portability | core imports no Node, DOM, filesystem, network, or agent-runtime modules |
| parity | corresponding Claude/Codex wrapper cases have equal response bytes |
| bounded transport | fixed request/output/stderr ceilings and 5000 ms timeout |
| rollback | failed install restores exact pre-install closure digest |
| authority safety | zero Dispatch append, bind, authorization, spawn, persistence, and effect calls from resolver advice |

Performance beyond the closed byte/time ceilings is not a quality claim in
this plan.
