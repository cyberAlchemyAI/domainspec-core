# Plan dispatch technique trace

| Technique | Application |
|---|---|
| `sequence` | context → decision → closeout; no parallel mutation |
| `artifact_contract_bridge` | exact Design, Work Pack, gap, and profile inputs enter the gate |
| `owner_boundary_check` | public, generated, consumer, orchestrator, and private lanes remain separate |
| `authority_split_gate` | decision evidence cannot promote or implement source |
| `validation_loop` | decision/profile/digest/write inventory is checked before closeout |
| `execution_receipt_handoff` | immutable Decision Gate receipt feeds Invoke Refresh |
| `residue_ledger` | unresolved human-owner assignments block and remain explicit |

A full dispatch JSON is required because the route crosses multiple
capabilities, carries a private decision profile, and is intended as a reusable
handoff. Validation passes. `subagent_strategy` is `none`: only one sequential
no-code SWU is selected. Orchestrate is the later native executor after an
explicit request; it is not run by this Plan.
