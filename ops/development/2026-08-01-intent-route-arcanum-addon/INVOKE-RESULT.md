# Invoke result — Intent Route Arcanum Add-on

## Outcome

Define, Design, and Plan pass for a candidate future public Arcanum
`intent-route-resolver` sigil. The selected architecture is:

```text
runtime-owned intent capture
  -> thin projection/rejection adapter
  -> generated Claude or Codex package from one canonical closure
  -> candidate | ambiguous | no-match | invalid
  -> human-confirmed existing Dispatch/group/seat
  -> retained host binding, authorization, execution, and evidence owners
```

The Design denominator and fixed-point selection validators pass. Dispatch
Spec passes. Standard Distill passes after an independent read-only owner and
duplication audit.

## Clear project path

1. **L0 owner gate:** resolve public extraction, canonical API/name/license,
   catalog projector, runtime normalization, ACI fields, and disposable
   consumer in a durable Decision Gate receipt.
2. **L1 candidate:** `sigil-development` builds a sanitized candidate outside
   public `arcanum/**`, then runs core/static/Node/real-Chromium witnesses.
3. **L2 canonical and profiles:** public authority accepts source in a clean
   Arcanum worktree; Bootstrap generates isolated Claude/Codex packages and
   proves behavior parity, disable, and rollback.
4. **L3 consumers:** prove one disposable install, refresh ResonantOS to
   consume rather than duplicate the resolver, and separately implement the
   orchestrator thin adapter.
5. **L4 private admission:** CAV2/ACI admits only a private compatibility edge
   and content-addressed references under its own authority.

## Important boundary

The existing private resolver proves a bounded 34-test standalone relation. It
does not authorize copying into public Arcanum. The frozen 78-case acceptance
contract is design only. No public source, generated package, consumer,
orchestrator, ResonantOS, Augmentor, CAV2/ACI, browser, release, deployment, or
production result was implemented or claimed here.
