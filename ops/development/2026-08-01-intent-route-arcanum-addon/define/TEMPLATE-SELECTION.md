# Template selection

| Template | Use | Reason |
|---|---|---|
| `domainspec-spec` | selected | The target has a versioned request/catalog/disposition algebra, operations, mappings, and explicit state/effect boundaries. |
| `sigil` | selected | The future canonical target is one reusable Arcanum capability with generated runtime packages. |
| `implementation-layering` | selected for Plan | Public extraction, parity, consumer install, and private admission require different evidence layers. |
| `work-pack` | selected for Plan | Multiple repositories and retained owners require bounded SWUs and closeout contracts. |
| retired `implementation-plan` | rejected | Invoke Plan forbids the retired monolithic output. |

No presentation, campaign, or application template is selected. The browser
requirement belongs to acceptance runners, not a product UI.
