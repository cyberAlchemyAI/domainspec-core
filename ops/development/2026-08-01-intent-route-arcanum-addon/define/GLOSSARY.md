# Glossary

| Term | Meaning in this package | Boundary |
|---|---|---|
| public-safe resolver core | Fresh project-agnostic implementation of the deterministic route relation | Must not copy private prose, types, fixtures, authority concepts, or imports. |
| intent-route sigil | Proposed canonical Arcanum capability containing instructions and an executable support closure | Candidate until `sigil-development` and public authority accept it. |
| runtime wrapper | Generated Claude or Codex package that exposes the same canonical closure | Projection only; it gains no routing authority. |
| source adapter | Runtime-owned projector from local intent capture into `intent-route.request@1` | May project or reject; may not repair, enrich, rank, select, or execute. |
| route catalog projection | Digest-bound read-only projection of capability and confirmed Dispatch owners | Not a registry, ledger, discovery engine, or identity authority. |
| route disposition | `candidate`, `ambiguous`, `no-match`, or `invalid`, always with `authority_effect: none` when trusted | Advice, not selection, approval, authorization, or execution. |
| disposition integrity digest | Wire field `receipt_digest` over canonical disposition bytes | Not support evidence, confidence, approval, lifecycle receipt, or authority evidence. |
| human confirmation | Authorship or confirmation of the existing canonical Dispatch/group/seat | No parallel selection object or lifecycle is created. |
| Bootstrap | Installer/projector of an accepted canonical Arcanum closure | Not the semantic resolver and not a promotion authority. |
| Augmentor integration | Augmentor captures intent, displays advice, and asks exact clarification through a runtime-owned adapter | Augmentor does not become catalog, Dispatch, approval, or execution owner. |
| reasoning-engine advance | Deterministic pre-inference capability-route reduction and abstention | Does not include semantic judgment, object inference, actor protocol, memory, effects, or whole-engine proof. |
