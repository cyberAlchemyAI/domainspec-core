# Intent Route Arcanum Add-on

This package is the candidate-only Invoke Define/Design/Plan record for a
future public Arcanum `intent-route-resolver` sigil and its generated Claude
and Codex runtime packages.

It does not change public Arcanum, generated runtime packages, a consumer
repository, the private resolver, or the orchestrator. It separates five
later decisions: public-safe extraction, canonical acceptance, generated
package parity, consumer installation, and private-stack admission.
