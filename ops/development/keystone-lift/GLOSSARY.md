# Glossary: Keystone Lift

| Term | Definition | Source |
| --- | --- | --- |
| **Wedge** | The free, public open-core surface that drives adoption (validators/audits, taxonomy, spec→test method, intent sigils). Exported to public arcanum. | COMMERCIALIZATION-SYNTHESIS §2 |
| **Moat** | The paid, private surface (CyberAlchemy governance engine, Craft metering, attestation, Lean proof half). Never public. | §3 |
| **Runtime** | Product/infra/executable code; always private. | §RUNTIME |
| **DomainSpec (public brand)** | The public name for the free methodology in arcanum (template, spec pipeline). | Decision B2 |
| **CyberAlchemy** | The private moat brand (promotion DAG + KPI taxonomy + governance attenuation). | §3 |
| **Wedge subset** | DS-D1 (25 meta-types), DS-D2 (29 edges), DS-D3, DS-D7/D8, DS-D10, DS-P1..3 — canonical in arcanum. | Part C / Decision C2 |
| **Moat cluster** | DS-C3, DS-D9, DS-COR-1, DS-F1, DS-F5, DS-F6, DS-M13 — private canonical in DS. | Part C |
| **Ambiguous cluster** | DS-D4 (derivation), DS-D5 (dual-track layers), DS-D6 (L7 orchestration) — held private by default (C3). | Decision C3 |
| **Canonical home** | The single authoritative location of a definition. Wedge → arcanum; moat → DS. | Decision C2 |
| **Module Formulae** | invoke's outgoing generic spec template family (`module-formulae/`); replaced by the DomainSpec template. | invoke templates |
| **DomainSpec template** | The SPEC + aspect-doc (operations/queries/interfaces/states/events/mappings) format; invoke's new `define` baseline. | Decision B1 / spec-write |
| **Aspect docs** | The per-aspect spec files the M2 pipeline (test-derivation, doc→metrics, sync) reads. | TEST-PIPELINE.md |
| **Concept Registry** | The typed-ID table in a DomainSpec SPEC; source for sync-registry. | SPEC.md template |
| **Moat-leak audit (g05)** | Whole-diff grep gate: zero moat IDs/private paths/`ZefraHub`/PT terms/hardcoded validator names before any public push. | B-KSL-2 |
| **Discovery-existence soft gate** | invoke `define` check that halts on missing discovery unless `--skip-discovery` writes a waiver reason. | harvest (domainspec-spec-feature) |
| **Submodule-first** | Commit+push in arcanum before bumping the parent gitlink (`make bump-check`). | SUBMODULE-DISCIPLINE |
