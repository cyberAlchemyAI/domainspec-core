## Question

Do we still need more work for the repository and for new users, and is the skill-surface cleanup convergent or conflicting with `arcanum/formulae/dispatch-spec/development/ORCHESTRATION-RUNTIME-PLAN.md`?

## Short Answer

The two efforts are convergent, but not yet reconciled.

The skill-surface cleanup defines where capabilities should live and how duplicates should be pruned.

The orchestration runtime plan defines how multi-stage model-backed work should execute without nested `codex exec`, using dispatch-spec, native skill/subagent execution, receipts, and deterministic `tools/arcanum` compatibility.

They should become one migration track:

```text
canonical source
  -> runtime adapter/install surface policy
  -> native skill/subagent execution
  -> receipt/observability evidence
  -> optional legacy command compatibility
```
