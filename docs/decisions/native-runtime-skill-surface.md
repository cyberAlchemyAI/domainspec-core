# Native Runtime Skill Surface Decision

Date: 2026-05-31
Status: accepted
Decision source: `TASK-SURFACE-001 / SWU-SURFACE-001`

## Decision

Arcanum stage capabilities are selected from the active native runtime skill surface first.

This applies to stage capabilities such as:

- `context-builder`
- `invoke`
- `interrogation`
- `distill`
- `task-session`
- `refine`

`tools/arcanum` remains a deterministic support utility. It may validate handles, adapter metadata, provenance, install profiles, and receipt/handoff contracts, but it is not the default model-backed execution surface for those capabilities.

## Corrected Contract

Use this contract:

```text
Native runtime skills/packages are the primary capability discovery and execution surface.
tools/arcanum validates deterministic handles, adapters, provenance, and receipts.
```

Do not use this as an active/default contract:

```text
context-builder, invoke, interrogation, and distill resolve through tools/arcanum
```

## Runtime Implications

| Runtime | Primary surface |
| --- | --- |
| Codex | `$CODEX_HOME/skills/<name>/SKILL.md` generated by explicit `personal-codex` |
| GitHub/Copilot | `.github/skills/<name>/SKILL.md` plus `.github/instructions/*` |
| Claude | `.claude/skills/<name>/SKILL.md`, `.claude/agents/*`, and `CLAUDE.md` |
| Repo-local deterministic support | `tools/arcanum`, `.arcanum/runtime/config.json`, adapter profiles |

Native package aliases are allowed when they are thin and record `alias_of`.

## Compatibility Rule

`tools/arcanum --resolve` is compatibility/provenance support, not the primary stage-selection rule.

`tools/arcanum --exec` with native adapters prepares handoff/receipt contracts and must not spawn nested model-backed CLIs.

Model-backed CLI execution through adapters such as `codex-exec` or `codex-bypass` is explicit legacy opt-in only.

## Consequences

- Personal Codex skills should be regenerated through explicit `personal-codex` before they are treated as current.
- Root `.github/skills/arcanum-*` packages should become self-provenanced generated native packages rather than wrappers pointing at `.arcanum/runtimes/github-copilot`.
- Root `.codex/commands` and `.arcanum/runtimes/codex/commands` remain legacy command compatibility surfaces and should not be regenerated by default.
- Historical development evidence may mention old command-backed execution and should not be rewritten unless a cleanup task explicitly owns it.

## Follow-Up

- Refresh machine-global personal Codex skills only after explicit approval.
- Regenerate root GitHub/Copilot Arcanum packages with provenance.
- Decide whether `.arcanum/runtimes/github-copilot` remains a generated cache, becomes untracked, or is deleted after GitHub packages are self-provenanced.
