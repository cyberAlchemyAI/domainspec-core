# Ontology Source Digests

Ontology pack: [../README.md](../README.md)
Source ledger: [../source-ledger.md](../source-ledger.md)

## Purpose

Source digests are compiled knowledge imports.

They pull useful concepts from Arcanum, DomainSpec, and related source areas into the CyberAlchemy ontology context. They are intentionally richer than a pointer list: a future agent should be able to read a digest and understand why that source matters to the agentic system.

## How To Use

Use source digests when an ontology entry needs source evidence without forcing the agent to re-open all upstream repository files.

Use raw source files when exact wording, latest source details, or unresolved contradictions matter.
