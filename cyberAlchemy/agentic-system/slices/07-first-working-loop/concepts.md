# Concepts: First Working Loop

Work: [README.md](README.md)

## What This Slice Compiles

This slice turns the conceptual system into the first proof loop.

It arranges the scattered material from:

- synthesis;
- deep dive;
- inventory pipeline;
- ontology entry model;
- promotion governance;
- Operational Ontology;
- Context Builder;
- Observed Invocation Loop.

The first loop should prove that the system can learn from its own work.

## The Smallest Proof

The first pass should not ingest the whole repository.

It should prove one full movement:

```text
source
  -> inventory
  -> ontology
  -> context
  -> execution
  -> telemetry/reflection
  -> next knowledge state
```

Each arrow is a test.

| Arrow                    | What It Tests                                                         |
| ------------------------ | --------------------------------------------------------------------- |
| source -> inventory      | Can scattered source material become reusable evidence?               |
| inventory -> ontology    | Can selected evidence become thick meaning with scope and confidence? |
| ontology -> context      | Can a future task retrieve only the right knowledge?                  |
| context -> execution     | Does the selected context improve route and output?                   |
| execution -> reflection  | Does the work leave evidence for the next loop?                       |
| reflection -> next state | Does the system improve rather than merely finish?                    |

## First Context Builder Proof

Run Context Builder on one concrete task:

```text
prepare context to design Operational Ontology schema
```

The context pack should select:

- Operational Ontology branch definition;
- ontology entry contract;
- promotion governance;
- Business/System/Bridge ontology precedent;
- Knowledge Substrate Flow authority ladder;
- relevant Arcanum and DomainSpec source selectors.

It should exclude:

- full unrelated product pages;
- whole repository scan;
- exploration projects unless evidence is directly needed;
- implementation details that do not affect schema design.

## First Routed Task

The first routed task should be small:

```text
create the initial Operational Ontology branch entry
```

The route should:

1. use inventory evidence;
2. load the context pack;
3. create or draft a thick ontology entry;
4. mark promotion state as candidate;
5. record validation gaps;
6. emit or manually record execution evidence.

## What Success Looks Like

The first loop succeeds when:

- the agent uses less irrelevant context;
- the route decision is clearer;
- evidence is cited from inventory or sources;
- the ontology entry is thick enough to guide agents;
- memory remains candidate evidence, not authority;
- promotion state is explicit;
- execution leaves a better next state;
- at least one next improvement is visible.

## What Failure Teaches

If the loop fails, that is useful.

| Failure                        | What To Fix                                                       |
| ------------------------------ | ----------------------------------------------------------------- |
| Inventory is too vague         | Improve source manifest, entry schema, tags, or source summaries. |
| Ontology entry is pointer-only | Strengthen entry contract and require agent payload.              |
| Context pack is too large      | Improve Context Builder selectors and excluded-noise rules.       |
| Route is unclear               | Add route policy or context solution.                             |
| Evidence is missing            | Add inventory refs, source selectors, telemetry, or checkpoint.   |
| Promotion is ambiguous         | Add promotion rules and decision gate.                            |

## Expansion Rule

Do not expand the corpus until the first loop proves useful.

After success, expand in this order:

1. Necronomicon memory and repository harness material.
2. Observed Invocation Loop and workflow-reflect material.
3. Agent Execution Orchestrator lessons.
4. Residuality and drift material.
5. Concept-layer optimizer material.

The first loop is not about finishing the universe. It is about proving that the universe can teach the next run.
