CyberAlchemy v2

A project forgets which note became a rule.

Ontology is the map that keeps that failure visible: what each thing is, what supports it, and what it may safely mean.

The same word can appear in a source note, a definition, a test, a runtime signal, and a generated summary. Ontology keeps those objects from collapsing into one another.

What It Is

A governed meaning layer for the moment after discovery.

A note is found. A rule is proposed. A test appears. The project needs to know what changed, what connects, and what can be assumed.

Plain phrase: a map of meaning with receipts.

  • Typed objects: concept, rule, decision, workflow, capability, failure mode.
  • Typed relations: traced to, constrained by, tested by, realized by, drifts from.
  • Evidence and provenance: where the understanding came from.
  • Status and confidence: how mature or trustworthy the claim is.
  • Use obligations: what humans or agents may safely do with it.

What It Is Not

The map is not the government.

Ontology can preserve the trail from note to candidate rule. It can show evidence, confidence, and promotion state. It does not make the rule authoritative.

Not a glossary

A glossary defines a word. Ontology explains the thing in context: role, relation, evidence, and safe use.

Not memory

A memory dump preserves nearby text. Ontology says which text is evidence, which is claim, and which is only context.

Not authority

Definitions, constitutions, specs, runtime contracts, public claims, and owner routes still decide what counts.

Why Relations Matter

Systems fail in the gaps between nouns.

A business promise changes. The rule is partial. The test checks one behavior. The runtime signal tells a different story.

Ontology makes the gap inspectable before it becomes silent drift.

Authority Boundary

Ontology prepares promotion. It cannot promote itself.

The map can prepare a promotion request. It can show why the request exists. It cannot approve itself.
  • Ontology may classify, relate, trace, condense, and prepare promotion requests.
  • Definitions Governance owns canonical definitions.
  • Constitution Governance owns form and enforcement rules.
  • Runtime contracts and public claims still need their own owner routes.
  • Every useful map still needs receipts, confidence, and a gate.
