# L1 — Residue Map

What is *unresolved* in the tower, organized so it can be closed or explicitly deferred.
The live, itemized list lives in [../residue/open-residue.md](../residue/open-residue.md);
this file is the **map** (categories + ownership), updated at reconciliation.

## Residue categories

| Category | What lands here | Default owner | Closure path |
|---|---|---|---|
| **unread-keystone** | a keystone essay named but not yet deep-fetched | book-reader lane | fetch essay → label in claim-ledger |
| **truncation-risk** | a claim taken from a possibly-truncated WebFetch | book-reader lane | re-fetch / read full essay |
| **cross-book-attribution** | a concept appearing in ≥2 books; which book "owns" it unclear | synthesizer | resolve in distill.md spine |
| **bridge-undecided** | an Arcanum mapping not yet ruled borrow / analogy-only / block | reviewers + parent | resolve in bridge-decisions.md |
| **related-source-gap** | a related work (Kahneman, Bayes lit) that would sharpen a claim but is out of corpus | parent | explicit future-work, not closed here |
| **promotion-candidate** | vocabulary that *looks* promotable but must stay local pending a governed decision | parent | flagged only; never auto-promoted |
