# Bridge decisions

| External idea | Decision | Local use |
|---|---|---|
| Surgical restoration modules | borrow-carefully | Use only for defects heard in the source; default to the least intervention |
| Automatic leveling and loudness control | borrow-carefully | Use after restoration and retain natural dynamics |
| Adjustable ambience, reverb, and breath reduction | borrow-carefully | Preserve meaningful space and breaths; do not optimize for sterility |
| Generative bandwidth reconstruction | analogy-only for first run | Useful for damaged audio, but unnecessary reconstruction can alter identity |
| Speech-to-speech preservation of delivery | future-work | Test only after the restoration lane and after data/consent gates close |
| Marketing “studio quality” claims | block | Accept only waveform and blind-listening evidence for this narrator |
| Automatic filler/silence removal | block for first run | It can rewrite the approved rhythm and remove meaningful pauses |
| Processed output replacing raw | block | Raw remains immutable authority for performance and text fidelity |
