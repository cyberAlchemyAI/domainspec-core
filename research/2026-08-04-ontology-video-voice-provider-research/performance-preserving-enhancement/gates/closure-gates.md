# Closure gates

All gates apply to a candidate derivative.

| Gate | Pass condition |
|---|---|
| Text fidelity | No unintended addition, omission, substitution, or reorder |
| Performance fidelity | Intended pauses, emphasis, uncertainty, reassurance, and emotional turns remain audible |
| Identity preservation | Narrator and listeners judge the voice recognizably the same person |
| Artifact freedom | No robotic resonance, watery modulation, pumping, clipped consonants, or reconstructed syllables |
| Breath policy | Meaningful breaths remain; only distracting breath/noise is reduced |
| Intelligibility | Words and key distinctions are at least as understandable as the raw recording |
| Reproducibility | Input hash, tool/version, settings, output hash, and processing order are recorded |
| Data authority | Any external upload has explicit owner authorization and reviewed account-specific terms |
| Human decision | The narrator listens and records `approve`, `reject`, or `defer` |

“Cleaner” is not a standalone pass condition. A result that sounds polished but loses identity or meaning fails.
