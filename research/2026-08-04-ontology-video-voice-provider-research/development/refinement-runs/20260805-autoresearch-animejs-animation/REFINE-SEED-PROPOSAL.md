# Auto-Research Anime.js Animation Refinement Seed

## Target

Design an evidence-bound way to turn the existing ontology educational video's frozen narration, captions, still-image worlds, timing, and semantic guardrails into reviewable animation hypotheses. Adapt the candidate-learning pattern documented in AutoAds and consult the implemented Anime.js agent knowledge vault without treating either source as authority over the video.

## Intended result

This run must produce:

1. a frozen source and authority contract for the existing 12-sequence video package;
2. an `AnimationHypothesisCandidate` contract with contradiction, evidence, reduced-motion, and owner-review fields;
3. a local-only consultation flow from scene beats to Anime.js documentation evidence;
4. a tournament over bounded scene candidates, with one narrow first prototype selected by explicit criteria;
5. a non-executed, Task-Session-ready Work Pack for that prototype; and
6. explicit residue and claim ceilings.

## Non-goals and boundaries

- Do not implement animation code, render video, generate voice, upload media, call a provider, spend money, deploy, publish, or promote ontology authority.
- `projects/autoads/` is read-only design precedent. Its README says the project seed is not executed.
- `projects/animejs/ontology/agent-knowledge-vault/` is a read-only consultation source. Its operational core is transport-neutral and does not prove HTTP or runtime Anime.js behavior.
- `2026-08-03-ontology-authority-agent-context-presentation/` is the source-owned video package. This run may select and plan against it but may not edit it.
- The voice-provider research and performance-preserving voice route remain separate gates.
- All new bytes are local refinement artifacts under this run folder, except the append-only subagent dispatch ledger records required by the confirmed multi-agent route.

## Done criteria

- All ten canonical Refine stages have exact artifacts and receipts or an explicit blocked result.
- All three confirmed design roles are spawned, joined, closed, and cited by the parent synthesis.
- The design separates source facts, proposed motion, executed witnesses, subjective evaluations, and owner decisions.
- The selected scene and first prototype are justified through a finite tournament and recompose into the 12-sequence film.
- The Work Pack begins with the nearest reversible, evidence-producing unit and contains exact acceptance and stop conditions.
- No completion claim exceeds the evidence: this run designs and plans animation; it does not animate the video.
