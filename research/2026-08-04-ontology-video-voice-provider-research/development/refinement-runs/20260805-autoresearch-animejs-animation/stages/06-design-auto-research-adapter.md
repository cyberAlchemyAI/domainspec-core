# Stage 06 Lane — Auto-Research Adapter

## Adaptation decision

Reuse the AutoAds candidate discipline, not its domain or implementation status. The new object is `AnimationHypothesisCandidate.v0.1` with proof ceiling `planned_motion`.

## Kept, renamed, rejected

| AutoAds pattern | Animation adaptation |
|---|---|
| hypothesis statement and rationale | proposed motion plus expected comprehension function |
| source and evidence refs | source-package selectors plus vault consultation bindings |
| contradiction path | typed semantic, source, timing, accessibility, performance, and witness falsifiers |
| proposed allowed uses | exact local prototype scope and prohibited effects |
| owner review | source/animation owner selection; never metric-driven promotion |
| internal residue | immutable animation experiment residue and WorkEpisode lineage |
| promotion-weighted decay | optional selection-weighted diversity policy, excluded from L0 acceptance |

Rejected: predicted lift, advertising KPIs and response windows, audiences, campaigns, spend, network adapters, competitor signals, `PromotionCandidate` identity, a single `veracidade` field that hides atomic proof states, and automatic ontology-card parameterization.

## Lifecycle

```text
draft
  -> precheck_rejected | consultation_pending
  -> consultation_blocked | contradiction_quarantined | tournament_eligible
  -> owner_review_pending
  -> selected_for_plan | rejected | deferred
  -> task_session_admitted
  -> witness_executed
  -> subjectively_evaluated
  -> owner_accepted | owner_rejected | retired
```

Deterministic prechecks require current source hashes, a current successful consultation, explicit invariants and falsifiers, identical semantic end states for standard and reduced motion, finite local witness scope, and explicit layer feasibility. Hard gates never become score weights.

## Residue loop

A later Task Session may append a WorkEpisode that records inputs, version context, attempted candidate, executed evidence, outcome, failure, contradiction, evaluation, and owner decision. The episode is an observation. It does not rewrite canonical vault data, change Task state, or create a verified Lesson. A Lesson requires a separate candidate, sufficiency criteria, current non-revoked evidence, resolved contradictions, independent validation, and an explicit owner decision.

The AutoAds `60/40` exploration ratio and three-use decay threshold remain optional hypotheses. L0 must not encode them as validated animation policy.
