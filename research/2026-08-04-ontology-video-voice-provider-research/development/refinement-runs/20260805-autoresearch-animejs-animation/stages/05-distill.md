# Stage 05 — Distill

## Smallest coherent unit

The smallest unit that still recomposes into the film is:

> One frozen `SceneBeat` becomes one evidence-bound `AnimationHypothesisCandidate`, receives one bounded Anime.js consultation receipt, is accepted or rejected by explicit prechecks, and—if selected—becomes one deterministic local browser-witness task with a semantic reduced-motion equivalent.

The first implementation should narrow this further to one approximately ten-second transformation inside the selected scene. Full-scene timing and full-film assembly remain later layers.

## Required input

- exact sequence and beat selector;
- frozen voiceover and caption interval;
- source image identity and required separable layers;
- semantic invariant and negative-animation constraint;
- current version/evidence context for the Anime.js vault.

## Required output

- one complete candidate contract;
- one consultation receipt or explicit abstention/staleness result;
- one planned motion state machine;
- one reduced-motion state machine with the same semantic end states;
- one finite witness specification;
- residue for every rejection or missing premise.

## Recomposition proof

Every scene in the 12-sequence film is already expressed as ordered beats with the same five columns: time, spoken anchor, picture/motion, text, and sound. Repeating the unit can therefore build a scene plan, and ordered scene plans can build the full film without changing sequence order. Recomposition fails if the unit changes narration, lets motion cross an owner gate, drops the transition into the next scene, or relies on a scene-specific hidden field that the contract cannot represent.

## Anti-unit

“Animate all eight images with tasteful parallax” is not a coherent unit. It has no claim boundary, no contradiction path, no evidence receipt, no reduced-motion semantics, and no finite acceptance witness.

## Residue entering Design

- The still images are flattened; separable layer feasibility is untested.
- Recorded-voice timing does not exist, so text-derived timing is provisional.
- Anime.js performance and accessibility are not witnessed for this video.
- No verified Anime.js operational Lesson exists for this animation work yet.
