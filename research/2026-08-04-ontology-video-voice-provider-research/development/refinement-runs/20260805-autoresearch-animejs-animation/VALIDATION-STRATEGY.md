# Validation Strategy

1. Contract tests validate source digests, closed schemas, proof states, contradiction, reduced motion, and causal negative fixtures.
2. Consultation tests use injected host context and the existing local vault; every non-`ok` state stops eligibility.
3. Runtime tests prove exact local Anime.js identity and zero runtime network.
4. Scene/timeline tests verify DOM/SVG semantic states independently of a browser screenshot.
5. Browser tests use pinned shared Playwright and Chromium, fixed viewport, paused/seeked times, standard and reduced-motion contexts, state JSON, screenshots, and source byte-zero delta.
6. Human review records aesthetics and comprehension as subjective evidence, separate from runtime pass.
7. Episode tests prove idempotent append, projection visibility, Task state unchanged, semantic effect none, and Lesson eligibility false.

No check in this plan proves full-video timing, final voice synchronization, audience comprehension, production performance, release, or deployment.
