# Glossary

| Term | Meaning in this package | Must not be confused with |
|---|---|---|
| Audition | A bounded evidence-producing test of one exact OpenAI stock-voice configuration on the frozen excerpt. | Provider approval or full narration. |
| Admission | A recorded state showing every pre-render hard gate is closed for the exact manifest. | General API availability. |
| Audition manifest | Immutable, digest-bound configuration and owner decisions for one candidate. | An API request alone. |
| Candidate | One exact model snapshot, stock voice, accent/locale decision, instruction, format, and account configuration. | OpenAI as a whole or a voice family. |
| Frozen excerpt | The exact 237-word text in `audition-excerpt.txt`. | A paraphrase, edited script, or caption timing. |
| Raw response | Provider-returned audio bytes preserved unchanged under a unique run ID. | A normalized derivative. |
| Derivative | Locally decoded or normalized audio created from a raw response with pinned tools. | The immutable provider response. |
| Fidelity | Evidence that spoken words match the frozen excerpt and timing is internally coherent. | Voice quality or semantic preference. |
| Voice fit | Human judgment of tone, accent, warmth, pacing, naturalness, and semantic arc. | Technical validity or permission to publish. |
| Blind score | Listener evaluation attached to an opaque candidate/repetition ID. | Automatic provider selection. |
| Terminal decision | A named operator's dated `approve`, `reject`, or `defer` outcome after all gates and listening. | A weighted score or implementation receipt. |
| Disclosure | Clear notice that the heard voice is AI-generated and not human. | Attribution or generated-output ownership. |
| Unsupported/not exposed | A control absent from the documented selected route and therefore omitted. | A default value. |
| Receipt | Digest-bound evidence about an executed step. | Authority to execute another step or publish the audio. |
