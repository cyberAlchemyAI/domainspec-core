# Ternary Models Research Tower

Status: active starter tower

Promotion scope: local-research-only

Date checked: 2026-06-17

## Research Target

Study, research, and develop ternary models, with emphasis on neural networks
and language models whose weights use the ternary set `{-1, 0, +1}`.

## Source Boundary

Primary source cluster:

- BitNet b1.58, "The Era of 1-bit LLMs: All Large Language Models are in 1.58 Bits" - https://arxiv.org/abs/2402.17764

- TernaryBERT - https://arxiv.org/abs/2009.12812

Related implementation and deployment sources:

- Hugging Face BitNet model docs - https://huggingface.co/docs/transformers/en/model_doc/bitnet

## Non-Goals

- Do not claim novelty for ternary models; the tower starts from owned prior art.
- Do not promote terms into Inventory, Ontology, sigils, runtime contracts, or
  canonical definitions without a separate governed promotion decision.
- Do not treat BitNet results as proof that all hardware or all model classes
  benefit equally from ternary weights.
- Do not start empirical claims about quality, energy, latency, or compression
  without a later `research-evidence-harness` or experiment route.
