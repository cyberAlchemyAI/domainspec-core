# Cognitive Navigation Card

## Before adding a view

- What single bounded claim must every view preserve?
- What are its evidence, interpretation, authority, privacy, and causal limits?
- Which reader decision makes another view useful?

## Before climbing a layer

- What exact residue remains?
- Can it be closed by editing an existing view?
- Is vocabulary genuinely missing?
- What prior distinctions must the new layer preserve?
- How will the result return to the concrete case?

## Before claiming comprehension

- Was the task fixed before treatment?
- Are baseline and treatment evidence-equivalent?
- Was instrument contamination recorded?
- Are claim-ceiling and authority-boundary errors scored?
- Is an agent run being described only as a structural pretest?
- Is a human arm complete before stating a human result?

## Stop

Stop if the new layer adds ambiguity, the residue is acceptable, an owner boundary is reached, or evidence rather than explanation is now required.
