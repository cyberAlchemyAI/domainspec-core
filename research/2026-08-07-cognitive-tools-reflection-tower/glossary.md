# Glossary

| Term | Working meaning in this tower |
|---|---|
| Cognitive tool | A governed navigation surface that helps a reader move among representations while keeping claim and authority limits visible |
| Horizontal representation | One of several audience-specific forms of the same bounded claim at the same explanatory layer |
| Horizontal invariant | Meaning and governance information that every horizontal form must preserve |
| Residue | A typed mismatch left after a representation or task is attempted |
| Local repair | A change inside the current vocabulary or representation set that closes residue without adding a new layer |
| Vertical promotion | Creation of a richer explanatory layer because local repair cannot name a required distinction |
| Round trip | Movement from a concrete case to a richer representation and back to the concrete case |
| Return fidelity | Preservation of concrete distinctions, evidential ceiling, and authority boundary during the round trip |
| Claim ceiling | Strongest statement the available evidence supports |
| Structural pretest | Agent-based instrument hardening that may expose task ambiguity but is not human-comprehension evidence |
| Human arm | Participant study required before making human-comprehension claims |
| Cognitive residue | Observable stall, confusion, boundary loss, overclaim, or failed transfer under a defined task; it is not automatically a formal Carrier |
| Navigability | The practical capacity to select, traverse, and recombine useful representations |
| Diagonal/metacognitive axis | Conditional hypothesis about self-evaluation and nested reasoning; excluded from the first supported paper result |
