# Glossary

Quick reference. Each entry: source kind · local meaning · Arcanum reading · promotion status ·
misuse warning. **Local-only**; nothing here is promoted to Inventory/Ontology.

| Term | Source kind | Local meaning | Arcanum reading | Promotion | Misuse warning |
|---|---|---|---|---|---|
| **MTNG** | primary-source | Modal Tonal Nodal Graph — Dave Gardner's proposed engine for ResonantOS that decomposes mixed work evidence into contracted, validated artifacts. | A workflow-shaping pattern, not (yet) a runtime. | local-only | Don't call it a "system"; it is a *proposal*, Phase 0 unbuilt. |
| **Signal** | primary-source | A selected raw input/event (terminal transcript, chat, git diff, bug report, PR thread, tool failure). | ≈ a dispatch's raw source material. | local-only | A Signal is *selected*, not ambient — MTNG is not always-on. |
| **Mode** | primary-source | A proposed *kind of work* (e.g. `bug_intake.reproduction`, `provider.routing`, `ux.affordance`). | ≈ a dispatch_type / lane. | local-only | A Mode is a hypothesis until a validator confirms the artifact. |
| **Tone → Routing Signature** | primary-source | A detectable clue that a Mode may be active (substrings like "I clicked around"). Renamed in v2 to drop the metaphor. | ≈ a heuristic router; explicitly a *hint, not proof*. | local-only | Do not treat a routing signature as a classification; it is fragile (see D5). |
| **Node** | primary-source | A bounded processing unit with a contract (accepts/rejects/context/output/validator/status/merge/contribution hooks). | ≈ a single bounded task/SWU with a completion contract. | local-only | A node without a validator is not a node. |
| **Validator** | primary-source | A *structural* check: did the node produce the right *kind* of artifact? Doubles as a misrouting detector. | ≈ the check-tension / completion-criteria gate. | local-only | Not a quality score; it is a routing + structure gate. |
| **Synthesis** | primary-source | Combining validated/partial/failed nodes into a final artifact (e.g. a developer issue packet) without hiding conflict. | ≈ derived aggregation (P7): synthesize, never bare concat. | local-only | Must surface partial/failed nodes as labeled status, not drop them. |
| **Nodal Boundary** | primary-source (v1 PDF) | The point where a signal should split because a processing mode is no longer cleanly reusable by one handler. | ≈ the moment a dispatch must fan out. | local-only | v2 expresses this as the 8 binary branch triggers. |
| **Branch Pressure Score** | primary-source (v1; **deferred** in v2) | v1's weighted numeric scoring of when to split (safety=6 … contribution=3) with thresholds. | ≈ numeric escalation policy — deferred until empirical data. | local-only | Do not implement in V1; spec defers it. |
| **Branch trigger (binary)** | primary-source | V1's replacement for the score: branch when one of 8 boundaries changes (artifact/validator/tool/context/memory/contribution-type/safety/authority or explicit operator split). | ≈ a named, binary fan-out reason. | local-only | If one clear artifact + one validator, **do not branch** (fast path). |
| **Fast path** | primary-source | One dominant mode, no trigger fires, one obvious artifact, one validator, no boundary change → single node, no branching. | ≈ "work inline" when no dispatch trigger holds. | local-only | The default for simple signals; over-branching is the named risk. |
| **Memory candidate** | primary-source | A review-only proposed durable-memory item (type/content/evidence_refs/confidence/ttl/promotion_status). | ≈ a `promotion-candidate` that needs a separate governed decision. | local-only | Never auto-promoted; `promotion_status: needs_review`. |
| **Contribution record** | primary-source | Structural attribution of non-code labor (triage/reproduction/review/synthesis) linked to an artifact — **no value assigned**. | ≈ register-dispatch capturing angle/axis without scoring. | local-only | Capturing ≠ valuing; valuation is explicitly out of V1. |
| **OKF** | related-source (unverified) | "Open Knowledge Format" (spec) / "Open Knowledge Framework" (Gemini) — claimed knowledge-interchange format MTNG exports to. | ≈ an external export target; **not fetched/verified**. | local-only | Name is inconsistent; existence unverified (R-OKF). |
| **edge_case_flags** | primary-source | Explicit flags added when OKF can't carry operational meaning (partial_merge, unresolved_conflict, validator_failed, safety_boundary_present, …). | ≈ "do not flatten operational meaning into prose." | local-only | The anti-flattening safety valve; required when OKF is insufficient. |
| **Run profile** | primary-source | The explicit per-run config (run_type, operator, purpose, input_sources, enabled_modes, output_targets, persistence). | ≈ a dispatch sheet for one MTNG run. | local-only | Every run must declare one; no implicit ambient runs. |
| **Phase 0** | primary-source | A mandatory integration-mapping pass (map MTNG concepts onto ResonantOS components) **before any code integration**. | ≈ a precedent sweep / dependency map before build. | local-only | Admitted **not yet done** (`05`); a hard prerequisite, not optional. |
| **ResonantOS** | related-source (unverified) | The target host system; claimed to have Guardian Core, Blackboard, Bridge Server, Event bus, Provider fabric, Living Archive, add-on model. | the deployment substrate; **not read by this tower**. | local-only | Treat its architecture as asserted, not confirmed (R-INT). |
