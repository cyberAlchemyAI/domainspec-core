# Distill — the smallest coherent model

The corpus compressed to operator knowledge. This is the **reading layer** — labeled as such.

## One-sentence model
*Rationality: A-Z* is one escalating argument that **the quality of a mind's map of reality
bounds everything that mind can do or protect** — so the art is to make beliefs track reality
(B1), catch the algorithm that fakes it (B2), understand why evolution built the fake (B3),
accept the reductionist world the true map converges on (B4), protect fragile human value
against proxy-optimization (B5), and institutionalize the practice in error-correcting
communities (B6).

The B1 epistemic tool is *re-sharpened* by each later domain (lens-E3 recurrence matrix).

## Where the argument is load-bearing vs. an author leap (per lens-E2)

- **Backed by external literature:** evidence-as-entanglement; core K&T biases; adaptation-executors;
  the *modest* "no universally compelling arguments".
- **Author leaps the literature does not license:** Many-Worlds "wins outright" (R7);
  Solomonoff as a usable razor (R2); verificationism as fresh (R1); morality as a single
  well-defined computation (L4, R9); strong trainability of rationality (L5, R10).
- **Structural fault line:** B1's rent-criterion contradicts B4's MWI verdict (L2).
