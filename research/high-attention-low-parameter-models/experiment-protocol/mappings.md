# Mappings: High-Attention, Low-Parameter Experiment Protocol

## ResearchToProtocol

| Research surface | Protocol owner | Transform | Guardrail |
| --- | --- | --- | --- |
| Workload/content | fixture and renderer contracts | recommendations become candidate or frozen fields | licenses and semantic splits remain explicit |
| Execution-platform | model-stack and capacity contracts | dated candidates become admission requirements | support is not compatibility or capacity |
| Internal validity | analysis plan and scorer contracts | estimands become named machine fields | thresholds require approval |
| Budgeted comparison | phase and frontier contracts | staged recommendation becomes gate policy | no composite primary winner score |

## FixtureToPrompt

1. Select immutable semantic plan.
2. Select prompt arm and evidence position.
3. Render constant instructions, controlled filler, evidence, and decoys.
4. Apply admitted chat template.
5. Record bytes, token IDs, evidence spans, and hashes.
6. Fail closed if target cell does not fit.

## RunToScore

| Run field | Score field | Transform |
| --- | --- | --- |
| raw output | parse status | versioned grammar parser |
| answer payload | answer outcome | deterministic normalized comparison |
| evidence payload | evidence outcome | exact allowed evidence-ID set comparison |
| support/abstain payload | support outcome | arm-specific correct semantics |
| failure code | eligibility | frozen exclusion policy; never silent drop |

## ScoresToContrasts

- `full - compact` on paired instance/rotation becomes retention.
- `larger - smaller` on the same cell becomes direct checkpoint contrast.
- checkpoint difference of retention becomes difference-in-retention.
- `middle - mean(early, late)` becomes middle loss.
- evidence-present support and evidence-absent abstention remain a joint behavior
  report, not raw-score subtraction.

## ReceiptsToFrontier

Join score and resource receipts only by trial-cell/run identifiers. Preserve
the measured boundary and uncertainty for each axis. Mark missing or infeasible
cells; do not impute them into dominance.
