# W2 — Stack Admission And Measurement Smoke

- Layer: L1.
- Layer question: Can one exact stack execute admitted short/long cells with
  trustworthy and repeatable systems receipts?
- Entry gate: W1 pass, exact platform decision, and resource authorization.
- Tasks: [ADMISSION](../tasks/TASK-HALP-ADMISSION.md),
  [MEASURE](../tasks/TASK-HALP-MEASURE.md).
- SWUs: 009, 011.

## Order

1. Resolve immutable model/runtime/hardware identities.
2. Run template/backend compatibility smoke.
3. Produce capacity witnesses for candidate lengths.
4. Execute tiny, explicitly non-confirmatory repeated cells.

## Exit Evidence

- Model-stack manifest and hashes.
- Capacity witness with prohibited fallback assertions.
- Run/resource receipts with prefill/decode separation.
- Repeatability inside approved systems tolerance.

## Stop Conditions

Stop on unavailable checkpoint, incompatible template/backend, truncation,
offload, preemption, recomputation, OOM recovery, missing telemetry, or no
feasible long-bin cell.
