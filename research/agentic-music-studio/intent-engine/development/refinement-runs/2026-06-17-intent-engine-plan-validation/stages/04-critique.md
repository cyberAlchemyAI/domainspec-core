# Stage 4 — Adversarial Plan Critique (3 tensioned critics)

Three critics attacked the intent-engine plan on independent lenses; all read the real artifacts (and,
for the execution critic, the real studio-core source). Condensed; full reasoning drove RESULT.md.

## Critic A — execution-readiness (verdict: yes-substantial)
Checked the plan against the REAL studio-core API. Headline: `pattern`/`scale` have **no substrate** —
studio-core has no sequencer and no pitch/scale model; `spec.realize` is one mono voice. `search` tunes a
fixed 3-D GENDYN theta only (no additive/scale tuning); objectives are keyed to exactly
`spectral_centroid`/`harmonicity_match`/`dissonance_minor2`; "strangeness" is a value-reducer in the
listener harness, not a cost. Vocabulary lacks target *values* (real `FeatureTarget` requires one). Three
SWU acceptances not checkable as written (SWU-3/4/7).

## Critic B — thesis-integrity (verdict: yes-minor)
Thesis structurally honored — no model in sound path, findings.md preserved, real intelligence = the L1
search ("agentic engineering," not decoration). BUT billing inversion: the headline "agent writes the
code" (L2.3) is a trivial deterministic template with no agent; the search that earns the thesis is
undersold. `author.py` invents pattern+seed not in the Spec → the seam where an LLM silently re-enters.
"Human directs" is steering-on-rails — no SWU for the human hand-editing the code and re-rendering.

## Critic C — dependency-risk (verdict: yes-substantial)
Single riskiest assumption: "treat stochastic targets as proxies" degrades **dishonestly** — the flagship
*stochastic* violin is the one timbre O8 says the floor can't measure (8.8% drift); an additive-only demo
is green but thesis-empty. Ordering risk: L1/L2.1/L3.2 are coupled to feature *semantics* that
Spectralize-v2 re-anchors → rework risk; freeze stochastic values, make `fit.py` a thin adapter. Rule-based
parser re-raises O2 (a menu, not a parser); critique→edit is open-vocab grounding + magnitude + coupling.
"Reproducible" = Reading-A only (false confidence).

## Convergence
All three independently flag: (1) pattern/scale + search-scope are net-new, mislabeled reuse; (2) the
flagship stochastic voice isn't honestly demonstrable yet; (3) honesty-of-billing on where intelligence
lives. → RESULT.md recommends a single-voice-on-GENDYN re-scope + F3-centroid-first sequencing + honest labeling.
