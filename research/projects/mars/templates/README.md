# MARS Canonical Templates

This directory is the canonical source for reusable MARS templates.

Current template families include:

- project and foundations templates
- experiment protocol and schema templates
- inventory library templates (`inventory-schema`, `inventory-library-entry`, `raw-content-note`)
- telemetry templates
- experimental paper-design templates (`paper-spec`, `paper-stories`, `paper-test-spec`, `paper-review`)

Projection copy target:

- research/projects/mars/templates

Sync command:

```bash
./tools/sync_mars_canonical_assets.sh
```

Do not apply semantic-only updates directly in projection copies.
