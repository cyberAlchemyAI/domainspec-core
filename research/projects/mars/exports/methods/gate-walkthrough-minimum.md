# Method Export: Gate Walkthrough Minimum

Producer: mars
Version: 0.1.0

Minimum required checks before running a live experiment:

1. G1 protocol measurable and schema complete
2. G2 sources validated and pinned
3. G3 inventory readiness report generated
4. G4 integrity checks defined for expected data

Dry-run walkthrough should be recorded before first live run of each new experiment family.
