## Opening

### Projected Copy

Ontologies are knowledge spaces.

### Spoken Copy

When I say ontology, I do not mean a glossary or a graph of labels. I mean a
model of a world: the things that matter, the kinds they belong to, and how
each concept interacts with the others. It carries time and confidence too,
because meaning changes, and not every claim deserves the same trust.

## Tension

### Projected Copy

More memory can make an agent more confidently wrong.

### Spoken Copy

An agent can retrieve a thousand correct sentences and still miss which one is
current, which one contradicts another, which is only a proposal, and which it
is allowed to use. Memory gives it material. Ontology gives that material
structure, context, and limits.

## Reveal

### Projected Copy

The map is not the authority.

### Spoken Copy

This is where CyberAlchemy v2 sharpens the definition. A useful ontology links
meaning to evidence, provenance, confidence, ownership, promotion state, and
rules for use. It can help an agent build the right context. But it cannot
approve itself. That boundary is exactly what the Augmentor ontology is
designed to make visible.
