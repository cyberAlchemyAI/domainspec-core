## Retellability test

Use exactly the same wording every time:

> Find evidence. Make meaning. Bound context. Gate action.

Do not alternate this with “Find. Make meaning. Bound. Gate.” The nouns are what make the chain intelligible without the presenter.

Input, transformation, consequence, and limit are all present:

- Input: selected evidence.
- Transformation: typed meaning, relations, time, confidence, and provenance.
- Consequence: a bounded task context.
- Limit: an external authority gate determines act, ask, or stop.
