## Visual grammar

- warm grey: owned sources;
- cobalt blue: selected evidence and temporary indexes;
- cyan: typed meaning and bounded context;
- amber: candidates and unresolved state;
- green: reviewed or governed state;
- violet: external owner authority;
- red-amber: rejected or forbidden transitions.

Status is also expressed with position, form, barriers, and line style rather than color alone.

## Use boundary

These images are explanatory illustrations. They do not replace the repository sources, establish ontology authority, prove runtime conformance, or grant release admission. Add exact labels in the presentation layer rather than baking additional terminology into the bitmap.
