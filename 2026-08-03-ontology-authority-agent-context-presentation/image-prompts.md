# Ontology Presentation Image Prompts

Generation mode: built-in image generation, one call per distinct project-bound asset. Images 2 through 8 used the immediately preceding generated image as a style reference only.

## 1. The Knowledge Space

Use case: scientific-educational

Asset type: 16:9 keynote presentation illustration, image 1 of an eight-image ontology series

Primary request: Create "The Knowledge Space": a bounded world model that visibly contains concepts, classes, typed relationships, time, confidence, provenance, lifecycle, and use boundaries, while remaining only a small island inside a much larger unknown world.

Scene/backdrop: deep charcoal field fading into an undefined vast exterior; a luminous irregular bounded island occupies the center.

Subject: inside the island, a small coherent ecosystem of distinct geometric concept objects grouped by type, connected by deliberate directional relations; a horizontal time rail crosses the lower portion; confidence appears as calibrated segmented halos; provenance appears as thin threads leading back to a small source-card stack; lifecycle appears as a few ordered state markers; the island boundary is explicit and incomplete.

Style/medium: sophisticated editorial systems illustration, vector-like geometry with subtle dimensional depth, restrained soft glow, premium conference-deck aesthetic, not a generic network graph.

Composition/framing: true 16:9 landscape, stable left-to-right visual grammar, generous negative space around the bounded island, legible at projection distance.

Color palette: charcoal background; warm grey sources; cobalt-blue selected evidence; cyan semantic structures; amber uncertainty; green governed state; a small violet boundary marker.

Constraints: no words, letters, numbers, logos, trademarks, people, robots, brains, lightbulbs, watermarks, tiny decorative nodes, or illegible pseudo-text. Use shape and position as well as color. The exterior must remain clearly larger and unknown.

Add a prominent neutral no-authority symbol beside the request boundary, using a crossed key or powerless seal with no text.

Style/medium: sophisticated editorial systems illustration, vector-like geometry, subtle dimensional depth, restrained glow, precise and source-bound.

Composition/framing: true 16:9 landscape, two horizontal lanes with strong separation, left-to-right order, external gate clearly beyond the system boundary, generous upper-left negative space for slide title.

Color palette: charcoal; warm grey owned sources; cobalt disposable index; cyan bounded context; amber intake and candidate; violet external owner gate; restrained green only for successful review handoff.

The request arrow must not pass through the owner gate. The candidate must not transform into a decision. The temporary index must look disposable while the source remains stable.

## 8. The Map and the Gate

Use case: stylized-concept

Asset type: 16:9 keynote closing illustration, image 8 of the same eight-image ontology series

Primary request: Create "The Map and the Gate": a memorable closing metaphor in which a luminous ontology map accurately reveals a route across a bounded knowledge landscape, but the route ends at a closed authority gate that only an external owner can unlock.

Scene/backdrop: deep charcoal world with a bounded island-like knowledge landscape, visually echoing the first image in the series.

Subject: warm-grey owned source cards at the left feed blue evidence points; cyan typed paths and geometric semantic landmarks form a clear map across the center; an amber candidate waypoint sits near the far edge. The route reaches a monumental violet gate outside the mapped boundary and stops exactly at the threshold. A separate simple key rests with a small abstract owner pedestal beyond and to the side of the map, never inside the ontology. The gate remains closed. A subtle time rail and confidence markers remain visible in the landscape so the final image recalls the whole mechanism.

Style/medium: sophisticated editorial systems illustration, vector-like geometry with subtle cinematic depth, restrained atmospheric glow, premium conference-deck finale, elegant rather than dramatic fantasy.

Composition/framing: true 16:9 landscape, stable left-to-right journey, gate as strong right-side focal point, generous dark negative space in upper-left and lower-right for closing copy.

Color palette: charcoal; warm grey sources; cobalt evidence; cyan map; amber candidate; restrained green governed landmarks; violet authority gate and owner key.

Constraints: no words, letters, numbers, logos, trademarks, people, robots, brains, watermarks, pseudo-text, magical portal, open gate, or route continuing beyond the threshold. The map must be useful and precise, but physically incapable of opening the gate.
