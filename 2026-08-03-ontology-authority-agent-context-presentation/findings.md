## Direct thesis and definition boundary

**Author’s accessible opening, voice-approved:**

> Ontologies are knowledge spaces: bounded models of the part of a world a domain cares about. They contain selected concepts and typed relations—including interactions where those are evidenced—and carry time, confidence, provenance, lifecycle, and rules for use. That is my accessible framing; CyberAlchemy v2 adds the governed meaning contract.

Immediately add:

> Neither framing makes an ontology a complete truth model or an authority owner.

CyberAlchemy v2 supplies the governed refinement: selected evidence becomes typed knowledge objects and typed relations carrying ownership or role context, provenance, confidence, promotion posture, contradiction or drift routes, and downstream-use obligations. “World model” therefore means a bounded, purpose-specific model of a selected domain—not total reality and not a truth machine.

State the adjacent structures positively:

> An ontology can include a glossary and taxonomy and can be represented in a database or graph. None of those structures alone supplies the governed meaning contract.

This opening is author voice plus a source-bound synthesis. The normative private definition remains CAV2-D19.

## Retellable mechanism, with actors named

Use exactly the same four beats at every reveal:

> **Find candidate evidence. Type meaning. Bound context. Gate use.**

The speaker-notes expansion is:

> owned source or event → Inventory or retrieval makes candidate evidence and selectors findable → explicit evidence selection → ontology-governed typed meaning, relations, time, confidence, and provenance → a context builder packages a bounded task view with warnings → a named authority owner permits or denies reliance → a separate workflow or runtime acts, asks, or stops

The nouns are artifacts or meaning contracts; the verbs belong to named people or processes:

| Artifact or contract | Responsible actor or process | Boundary |
|---|---|---|
| Owned source/event | Source owner or producing event | Presence is not selected meaning. |
| Inventory evidence card or retrieval result | Inventory/retrieval process, followed by explicit evidence selection | Findability is not promotion. |
| Ontology-governed meaning | Ontology owner and review route establish the meaning contract | The ontology does not interpret at runtime or approve itself. |
| Bounded context packet | A context builder selects and packages the task view | A packet is not durable memory or authority. |
| Reliance decision | A named authority owner | Confidence does not impersonate permission. |
| Effect | A separate workflow or runtime | It must produce its own execution evidence. |

Memory may retain candidate material. A context builder selects a task-scoped packet. The ontology supplies the typed meaning and use contract for interpreting that packet. A named authority owner decides permitted reliance. A workflow or runtime separately attempts any authorized action and must produce its own evidence.

## Definition ladder and authority ladder

The minimum teaching compression is:

> typed thing + typed relationship + time + evidence confidence + provenance + lifecycle posture + use/stop rule

This is presentation shorthand, not a canonical schema.

Build the definition in this order:

1. A typed object gives a thing identity, kind, scoped meaning, and role/owner context.
2. A typed relation uses a named verb; adjacency alone explains nothing.
3. Temporal meaning separates observation time, validity interval, expiry, and supersession.
4. Confidence carries a basis and scope. Evidence confidence does not equal owner commitment or a universal probability of truth.
5. Provenance retains the selected source selector so the interpretation can be inspected or invalidated.
6. Lifecycle posture distinguishes candidate, reviewed, promoted, demoted, and deferred meaning, with contradiction/drift routes.
7. Use rules carry permitted use, warnings, and a condition to ask, abstain, or stop.
8. Authority remains owner-controlled and external to the ontology’s self-claims.

Use the complete ladder exactly:

> **source selector → Inventory evidence card or EvidenceSet → ontology candidate → owner-gated PromotionRecord → governed ontology node or artifact → projection or generated read model**

Each arrow is an owned review or handoff, not automatic ingestion. A projection does not stand in for promoted ontology authority.

## Agent context contract

An ontology-derived context may carry selected typed objects and relations; source references; validity, expiry, and freshness; confidence with its rationale; contradictions; omissions and exclusions; lifecycle posture; warnings; permitted use; and a stop condition.

The agent must not infer that:

- retrieved means true, current, complete, canonical, or approved;
- high evidence confidence means owner commitment;
- a context snapshot is durable memory;
- a memory intake request is provider acceptance or a write;
- an ontology candidate is an authority decision;
- traversal is reasoning;
- validation proves runtime behavior;
- absence from the selected context means absence from the source corpus.

Operative rule:

> Give the agent the smallest evidence-bound view needed for its task, including warnings; when validity, evidence, or authority is insufficient, it must abstain or route to the owner.

## Forbidden overclaims

Reject wording that implies any of the following:

- the world model is complete or universally true;
- ontology collapses into a glossary, taxonomy, database, graph shape, memory store, or context window;
- source, index, selected context, and projection are the same artifact;
- confidence equals probability of truth, commitment, permission, promotion, or approval;
- newest means currently valid;
- a memory intake request is accepted or persisted memory;
- an ontology candidate is an authority decision;
- graph traversal is reasoning;
- semantic or structural validation proves runtime behavior;
- a generated read model is governed ontology authority;
- candidate-local means implemented, released, production-ready, or public.
