# Stage 9 — Invoke Plan (non-executed MVP plan)

- **Capability:** `invoke` · mode `plan` · **verdict: pass** · **NON-EXECUTED**

A layered plan from minimum-working-unit proof to progressive hardening. Nothing here is executed; this
is the seed handoff for a future Task Session.

## Layer 0 — MWU proof (the thin slice)

**Goal:** one complete Creative Learning Cycle with a stub network adapter (fixture outcomes).
**Acceptance gates:**
- G0.1 One ontology card exists (audience × family × objective) and configures generation vocab + outcome schema.
- G0.2 Generator emits ≥2 variants (control + challenger) with lineage + `hypothesis_ref`.
- G0.3 Network Adapter stub returns fixture outcomes; **no live calls, no PII, no credentials**.
- G0.4 Outcome Measurement normalizes to a KPI carrying `veracidade` + `evidence_refs` + response window.
- G0.5 Grader blocks promotion when confound/min-confidence gates fail (metric≠authority test passes).
- G0.6 A cycle reaches an **owner decision** node (promote/retire) — owner boundary proven.
- G0.7 Feedback loop writes residue + re-parameterizes the card for the next generation.

## Layer 1 — Governance hardening

- L1.1 Field→authority-class register installed; PII rejected at boundary, spend private, aggregates shareable.
- L1.2 Promotion DAG review gates encoded as deterministic rules (reuse ontologize 11-rule pattern).
- L1.3 Auto-research candidates routed through review gates before entering the hypothesis pool.

## Layer 2 — Live single-network pilot

- L2.1 **(needs H1)** Replace stub with one real Network Adapter after `bounded-research` on that network.
- L2.2 **(needs H2)** Tune confound thresholds on real traffic.
- L2.3 Validate H4 (ontologize loop generalizes to ads) on real outcomes.

## Layer 3 — Auto-research closed loop + multi-network

- L3.1 Auto-research memory loop with exploration/exploitation quota (resolve [H] numbers).
- L3.2 **(needs H3)** Candidate→card-vocabulary update contract.
- L3.3 Generalize Network Adapter to a second network.

## Dependencies / ordering

L0 → L1 → L2 → L3. L2 is gated on a bounded-research pass (recommended next route). Each layer's gates
must pass before the next begins.

## Explicitly out of scope

Live ad spend, model training, pricing/contracts/named clients, and any promotion to canonical Arcanum
vocabulary. autoads outputs remain candidates pending owner decision.
