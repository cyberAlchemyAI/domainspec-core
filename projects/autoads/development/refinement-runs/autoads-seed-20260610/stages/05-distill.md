# Stage 5 — Distill (coherent unit + x-ray)

- **Capability:** `distill` · mode `standard` · receipt: native-stage · **verdict: pass**

## Smallest coherent unit that recomposes into ontologize

**The Creative Learning Cycle (CLC):** one closed loop —

```
generate(candidate) -> dispatch(network) -> measure(outcome, window)
   -> grade(veracidade, evidence_refs) -> DAG review gates -> owner decision
   -> {promote recommendation | retire} -> residue -> feeds next generate() + auto-research pool
```

This is the minimum unit because it (a) produces value alone (one governed cycle yields one
evidence-backed verdict), and (b) recomposes directly onto ontologize's Execution→Promotion DAG.

## X-ray: pipeline components (the hidden structure)

| Component | Role | Ontologize anchor |
|-----------|------|-------------------|
| **Creative Generator** | Produces creative variants from an ontology card + candidate hypothesis. | ontology cards configure vocabulary [adapt] |
| **Network Adapter** | System-agnostic contract: dispatch a variant, pull outcomes. | data-governance register at the edge [adapt] |
| **Outcome Measurement** | Normalizes network metrics into KPI families over a response window. | evidence-linked KPIs, response windows [SB] |
| **Grader** | Assigns `veracidade` + `evidence_refs`; flags confounds/low confidence. | veracidade grade [SB], metric≠authority [SB] |
| **Promotion DAG** | Routes graded cycles through review gates to an owner decision. | promotion DAG, 11-rule validator [SB] |
| **Auto-Research** | Mines residue + external signals into governed creative candidates. | candidate→review→owner flow [adapt] |
| **Feedback Loop** | Promoted patterns + residue re-parameterize the Generator. | optimization-chain method [SB] |

## Open design tensions (routed to tournament in Design)

- **T1 ontology granularity:** one card per (audience × creative-family × objective) vs per-network cards.
- **T2 generation strategy:** LLM-gen vs template/asset-library vs hybrid.
- **T3 promotion cadence:** online bandit (continuous) vs batch (windowed review gates).

## Residue

- The "better creative" claim is only as strong as confound control + response window (carry into Design).
- Cross-vertical generalization of ontologize to ads remains [H] until the MVP pilot.
