Layered from minimum-working-unit proof to progressive hardening. Each layer's gates must pass before
the next begins: **L0 → L1 → L2 → L3**.

## Layer 0 — MWU proof (the thin slice)

One complete Creative Learning Cycle with a **stub** network adapter (fixture outcomes — no live calls,
no PII, no credentials). Acceptance gates:

- **G0.1** One ontology card (audience × family × objective) configures generation vocab + outcome schema.
- **G0.2** Generator emits ≥2 variants (control + challenger) with lineage + `hypothesis_ref`.
- **G0.3** Network Adapter stub returns fixture outcomes.
- **G0.4** Measurement normalizes to a KPI with `veracidade` + `evidence_refs` + response window.
- **G0.5** Grader blocks promotion when confound/min-confidence gates fail (metric≠authority proven).
- **G0.6** A cycle reaches an **owner decision** node (owner boundary proven).
- **G0.7** Feedback loop writes residue + re-parameterizes the card.

## Layer 1 — Governance hardening

- **L1.1** Field→authority-class register; PII rejected, spend private, aggregates shareable.
- **L1.2** Promotion-DAG review gates as deterministic rules (reuse ontologize 11-rule pattern).
- **L1.3** Auto-research candidates routed through review gates before the hypothesis pool.

## Layer 2 — Live single-network pilot

- **L2.1** (needs **H1**) Replace stub with one real Network Adapter after a `bounded-research` pass.
- **L2.2** (needs **H2**) Tune confound thresholds on real traffic.
- **L2.3** Validate **H4** (ontologize loop generalizes to ads) on real outcomes.

## Layer 3 — Auto-research closed loop + multi-network

- **L3.1** Auto-research memory loop with exploration/exploitation quota.
- **L3.2** (needs **H3**) Candidate→card-vocabulary update contract.
- **L3.3** Generalize Network Adapter to a second network.

## Out of scope

Live ad spend, model training, pricing/contracts/named clients, canonical Arcanum promotion. autoads
outputs remain candidates pending owner decision.
