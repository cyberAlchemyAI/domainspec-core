Owner-directed candidate for the existing pilot; authority effect none.

## Product construction

Frontier: shared compiler, atomic persistence and nineteen-stage local campaign.
1. Author typed text normalization and positive integer rules; generate them in
   the shared compiler and remove equivalent handwritten HTTP rules.
2. Close public track, evidence, redacted activity and import-receipt nested records.
3. Prove changed authored rules affect live behavior; reject nested private fields,
   wrong nested types and invalid normalization declarations.
4. Run the full current campaign including TDE, EVF, ORODI and integrity checks.

D65: existing pilot definitions -> typed candidate declarations -> shared compiler
and explicit IO adapters -> exact tested candidate -> current evidence for review.
No ontology runtime selectors or authority promotion are dependencies.
