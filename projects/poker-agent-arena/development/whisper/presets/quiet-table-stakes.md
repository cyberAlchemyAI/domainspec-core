# Whisper Preset - Quiet Table Stakes

Preset ID: `poker_agent_arena_quiet_table_stakes`
Transport: project documentation
Status: active draft preset
Target project: `projects/poker-agent-arena`

## Purpose

Create public-facing and contributor-facing documentation for Poker Agent Arena with a tone that is inviting, quietly competitive, and technically honest.

The text should make the reader feel that the table is worth sitting at, without using boastful challenge language or direct self-testing slogans.

## Resonance Core

- Voice: crisp, calm, lightly witty.
- Energy: competitive, but not breathless.
- Emotional residue: "this is a clean table; I want to see how an agent holds up here."
- Value signal: fairness, replayability, discipline under imperfect information.
- Humor level: one dry turn of phrase per major section at most.
- Forbidden feel: hype launch, casino promotion, leaderboard theater, try-hard provocation, swagger.

## Relevance Core

- Primary readers: agent authors, evaluator builders, AI competition organizers, poker-curious engineers.
- Reader state: curious, technical, skeptical of fuzzy benchmarks, interested in clean competitive pressure.
- Authority mode: transparent contract, not grand promise.
- Assumptions: readers understand agents, CLI tools, and benchmark discipline; they may not know poker edge cases.
- Objections to answer: hidden-information leaks, flaky timing, benchmark gaming, premature leaderboard claims.

## Trajectory Core

- Objective: introduce the project, orient first contributors, and make the L0 contract route legible.
- Structure: start with the table, explain what is measured, separate current stage from future ambition, point to the rule surfaces.
- Opening policy: lead with the experience and constraints, not internal Arcanum workflow vocabulary.
- Ending policy: point to the next concrete route without sounding like a launch countdown.
- CTA policy: use restrained action phrases such as "start here", "read next", "prepare an agent", or "follow the L0 contract".

## Diction

Prefer:

- table, seat, hand, decision, transcript, clean play, legal action, hidden information, replay, diagnostics, pressure
- local arena, toy table, sharp edge, small game, disciplined benchmark
- "bring an agent that can act cleanly under pressure"

Avoid:

- boastful self-testing slogans,
- conquest verbs,
- inflated benchmark claims,
- casino or real-money language,
- moonshot launch phrasing,
- revolution framing.
- anything that implies a hosted public tournament already exists

## Style Rules

- Keep sentences medium-short.
- Use concrete nouns before abstractions.
- Mention current stage early: L0 contract and documentation, not a complete runtime.
- Keep internal artifact names out of the opening paragraph unless the document is for contributors.
- Use links to `RULES.md`, `AGENT-RULES.md`, `SPEC.md`, and `WORK-PACK.md` when relevant.
- Let wit come from precision and poker texture, not jokes.

## Validation Checklist

- The copy is inviting without sounding needy.
- Competitive pressure is present but not shouted.
- No direct self-testing slogan appears.
- No public hosted or real-money claims appear.
- L0/M0 status is clear.
- Human-facing and engineer-facing rule surfaces stay distinct.
- Technical claims trace back to existing project artifacts.
