# Decisions And Gaps

## Decisions

| ID | Decision | Rationale |
| --- | --- | --- |
| D-01 | Open a new interface-rework cycle. | The prior GSP frontier is receipt-complete and terminal; the new verified audit is not a successor already captured by that chain. |
| D-02 | Repair continuity before information architecture. | A workbench that destroys task context every poll cannot support trustworthy hierarchy or visual polish. |
| D-03 | Make the server own one opaque update identity. | Client-side coercion of absent values caused the verified mismatch. |
| D-04 | Use a stable shell with keyed projection updates. | Whole-document reload is incompatible with preserving target, draft, focus, and scroll context. |
| D-05 | Preserve the application-owned governance invariants unchanged. | The audit found interaction defects, not authority to replace admission or handoff semantics. |
| D-06 | Make history secondary. | Historical variants are evidence inputs, not the current task or current head. |
| D-07 | Bind accessibility fixes to exact elements and event scopes. | The audit supports named frames and three bounded live regions, not universal claims. |
| D-08 | Keep framework choice open. | The contract is stable-shell behavior, not adoption of a specific frontend stack. |
| D-09 | End Invoke with no selected SWU. | Plan readiness is not execution authorization. |

## Rejected Collapses

- Audit approval is not Plan approval.
- Plan approval is not SWU selection.
- The first candidate is not the selected unit.
- Implementation evidence is not human-study evidence.
- Bounded accessibility witnesses are not certification.
- Export confirmation is not evidence completeness or readiness.
- Local completion is not release authorization.
