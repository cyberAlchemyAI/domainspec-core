# Design Distill Review Strategy

## P1 Trigger

Dispatch is warranted by synthesis, isolation, and parallelism. The Design
combines more than three governing/evidence sources and ten selected concern
outputs. A mechanics falsifier and a contract/UX falsifier can independently
attack the same authored package before synthesis and literal verification.

## Type

- Dispatch type: `review`
- Deliverable: verified Design change requests and a Design Distill gate
- Not included: Studio implementation, Plan authoring, Craft mutation, SWU
  selection, human study, or release

| Group | Mode | Purpose | Subagents |

### Anti-Bias Axis

`methodology`

Predicted disagreement: Hewitt runs computational transition and context-loss
falsification while Alexander runs formal interaction-contract and governance
reconciliation on the methodology axis; Hewitt’s patch-local bias would be
exposed by Alexander’s whole-system contract review, while Alexander’s
structural-design bias would be exposed by Hewitt’s executable counterexamples.
