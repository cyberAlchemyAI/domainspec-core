## Inventory Use

The run’s existing machine-index-first
`strategy-inventory-packet.json` supplied the verified Studio audit, prior
architecture/deep-spec review, prior UX research, and Invoke Design-coverage
precedent. The concrete Plan effect is:

- continuity mechanics precede hierarchy work;
- current audit selectors become source anchors;
- each semantic region is a separate SWU rather than a task-shaped UI bundle;
- human, cross-browser, broad-accessibility, and release evidence remain
  separate routes.

Unregistered strategy candidates, other-product frontend plans, and archived
full-vision ambitions remain excluded. Inventory is discovery-only.

The shared Inventory projections contain concurrent uncommitted edits, so this
Plan records template selection locally and does not rewrite the shared index
or log.
