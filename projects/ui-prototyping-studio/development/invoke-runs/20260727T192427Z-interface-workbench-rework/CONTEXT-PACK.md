## Inference

- Continuity is a trust boundary, not a polish concern.
- A server-computed update identity must be canonical at the HTTP seam; the
  browser should not reassemble identity with JavaScript coercion.
- A stable page shell can keep browser-local interaction state while keyed
  projections update after a genuine server transition.
- The interface should behave as a stateful workbench: lifecycle/action spine,
  primary canvas, state-specific inspector/review, then secondary history.
- Accessibility repairs should be attached to exact elements and event scopes,
  with positive and negative fixtures.
