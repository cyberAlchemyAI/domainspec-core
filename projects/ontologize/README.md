# ontologize

Research project for **CyberAlchemy's** first product: consulting on how to use
**ontology + DAG** to improve a company's **business intelligence** and **agent work**.

## Status

- Phase: research dispatch authored and validated. Not yet executed.
- Route: [ontologize-research.dispatch.json](ontologize-research.dispatch.json) — `dispatch_id: ontologize-research-20260608`, mode `research`, validated `pass` by `dispatch-spec`.

## What this route does

1. **Recover source** — ingest the GoldenQuill client-package worktree and the
   `codex/goldenquill-client-package` branch (promotion record DAG, ontology/governance
   substrate, client-sendable packages, agent skills) as read-only evidence.
2. **Scaffold tower** — build the research tower (corpus, pattern map, product closure plan).
3. **Extract patterns** — role-bound fanout across ontology, DAG/governance, BI value,
   agent-work, client-packaging, and productization lanes.
4. **Glossary + definitions** — stabilize client-facing terms.
5. **Synthesize product** — distill a candidate CyberAlchemy consulting offer in
   [PRODUCT.md](PRODUCT.md) (generated by execution).
6. **Validate + handoff** — record open residue, NEXT actions, and a validation handoff.

## Guardrails

- GoldenQuill is **read-only** source evidence; this project does not modify it.
- Outputs are **candidates**: no canonical Arcanum promotion, no committed pricing,
  contracts, or named client engagements without owner review.
- The role-bound research fanout (step `extract-ontology-dag-patterns`) is **recommended**
  and **requires operator approval** before delegated subagents run.
