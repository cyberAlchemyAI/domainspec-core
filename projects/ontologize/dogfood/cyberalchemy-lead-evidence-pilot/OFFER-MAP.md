# Offer Map

Status: draft
Pilot: CyberAlchemy Lead Evidence Dogfood Pilot

## Offer Under Test

CyberAlchemy AI-dev governance / readiness sprint.

Working offer sentence:

> We help teams make AI-assisted development inspectable by turning intent, agent work, evidence, and owner decisions into a governed execution trail.

This sentence is a hypothesis. It should be tested against CyberAlchemy source material and revised before any public campaign.

## Buyer Hypothesis

Candidate buyer:

- technical founder, CTO, or engineering leader;
- team already using AI-assisted development;
- pain around review burden, unclear intent, agent drift, auditability, or trust in generated work;
- budget category may be consulting, AI enablement, dev platform governance, or audit/readiness.

This is not yet an ICP. Treat it as an internal dogfood assumption.

- diagnostic call request;

- waitlist/signup;
- reply to outbound message;

## Lead Quality Rubric

Minimum lead-quality fields:

- role and authority;
- current AI-dev usage;
- stated pain;
- urgency;
- budget category or buying path;
- willingness to share workflow evidence;
- next action accepted.

Lead quality states:

- `qualified`
- `maybe`
- `unqualified`
- `inconclusive`

## Page Surfaces

Candidate surfaces:

- `cyberAlchemy/main.html`
- `cyberAlchemy/cyberalchemy-shareable.html`
- relevant lead/contact page, if present or created later
- related CyberAlchemy system docs used as source material, not public copy

## Message Hypotheses

Prepare 3-6 variants before execution:

1. Intent-to-evidence governance.
2. AI-dev readiness / audit trail.
3. Agent work review burden.
4. Spec-to-test governed execution.
5. Vendor-neutral trust layer.
6. CyberAlchemy as operating system for governed AI work.

Each variant needs:

- source reference;
- target buyer;
- promise;
- conversion action;
- risk/overclaim note;
- expected evidence signal.

## Evidence Rules

Before interpreting results, define:

- response window;
- channel;
- traffic or exposure source;
- denominator;
- minimum evidence needed;
- confound notes;
- inconclusive criteria;
- owner decision.

## Owner Decision

The dogfood pilot should end with one decision:

- keep message;
- revise message;
- pause message;
- retest with another channel;
- mark inconclusive.
