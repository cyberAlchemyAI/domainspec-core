# L1 — Authority map

Step `scaffold-operational-tower`. Maps where axioms, constitutions, and disciplines sit so the
adjudication can resolve H0 on evidence. Tags: **[SB]**, **[H]**, **[T]**.

## The L0–L7 ladder [SB ONTOLOGY-ARCHITECTURE.md §Authority Levels]

```
L7  Axiom          load-bearing invariant; downstream governance depends on it
L6  Constitution   enforceable form/model/transformation governance that PRESERVES axioms
L5  Promoted policy approved knowledge within a use scope (rollback path)
L4  Reviewed premise falsifiable working bet (contradiction path)
L3  Ontology candidate  thick draft: branch, scope, evidence, confidence
L2  Reviewable signal   lifecycle envelope, provenance, route identity
L1  Cataloged evidence  inventory / source selector  (support only)
L0  Raw observation     run, note, log, memory       (no authority)
```

Ladder relation [SB]: `axiom > constitution > policy > entry > candidate`.

## Definitions [SB BUSINESS-ONTOLOGY.md]

- **Axiom** = load-bearing truth / epistemic foundation; the *why* (e.g. "docs before code");
  indisputable until overwhelming evidence forces revision.
- **Constitution** = codified governance *derived from* axioms; the *how* for humans + agents
  (e.g. Schema Constitution, Artifact Constitution).

## Where disciplines sit today [SB DISCIPLINES.md]

- The catalog itself is **`Status: candidate`**.
- Discipline statuses span `candidate → active-pattern → implemented → canonical`.
- **Already canonical, steward = Constitution Governance:** `schema`, `artifact-constitution`,
  `quality-bar`, `validation-experiment`. → a discipline can be *backed by* a constitution.
- **Growth Rule:** discipline evidence *can recommend a route* but **cannot directly promote**
  registry / ontology / glossary / sigil / spell knowledge.
- **Boundary:** disciplines *must not claim promotion authority* and *must not treat execution
  evidence as canonical without owner review*.

## The tension, stated precisely [T]

| | Axiom / Constitution (L6–L7) | Discipline |
| --- | --- | --- |
| Authority | load-bearing; others depend on it | **forbidden** from claiming promotion authority |
| Evidence bar | strong evidence + dependency/contradiction review + commitment | "useful practice exists" |
| Lifecycle | promoted, with rollback path | catalog entry with a "next hardening move" |
| Position in ladder | top two rungs | not on the ladder; a discovery/evidence layer beside it |

**Therefore H0 ("disciplines = axioms") is not literally true under current definitions.** The
question the verdict must settle: is there a *coherent reframing* that honors the user's intent
("highest category of knowledge for the operational branch") without violating the boundary?
