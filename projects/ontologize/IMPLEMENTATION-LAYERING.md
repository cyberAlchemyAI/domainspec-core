# IMPLEMENTATION-LAYERING — CyberAlchemy engagement

Required plan companion. Bounds the work by explicit value/cost layer boundaries. Promotion between
layers requires evidence from the prior layer, not preference (invoke global gate).

## Layer decisions

### L0 — Minimum working unit (prove the assessment produces value)

- **Scope:** Build the assessment instrument; run it end-to-end on **one** vertical (logistics —
  lowest design risk).
- **Value:** A filled `ontology-map` + `data-inventory` + `agent-inventory` + `maturity-score` that
  a client recognizes as accurate. Proves the intake works before any method install.
- **Promotion evidence to L1:** one completed, client-validated assessment.
- **Cost boundary:** no method install, no second vertical, no deliverable yet.

### L1 — First instantiated method + deliverable (prove one vertical's value loop)

- **Scope:** Install the four-layer method for the logistics pilot; build the deliverable template v1;
  stand up the proof harness; produce the logistics client package.
- **Value:** One vertical with evidence-linked KPIs + a moved metric + a sendable package.
- **Promotion evidence to L2:** logistics proof harness shows one evidence-linked metric with a
  baseline and a measured movement; deliverable reused without structural change.
- **Cost boundary:** cap factory not yet installed; gap-closing sections may be stubs.

### L2 — Parallel second vertical (prove generalization)

- **Scope:** Run assessment + method install + proof harness for the cap factory (resolving the
  run-boundary risk); instantiate the deliverable for cap factory.
- **Value:** Two independent per-vertical proofs → cross-vertical comparison → generalization verdict (R1).
- **Promotion evidence to L3:** both verticals report independent metric movement; comparison written.
- **Cost boundary:** hardening/gap-closing deferred.

### L3 — Hardening (make it a repeatable product)

- **Scope:** Close the five inherited GoldenQuill gaps (meta-metrics on the governance layer, buyer
  readiness, consequence/cost per decision, current→target transition plan, failure modes);
  generalize the template; write the cross-vertical generalization report.
- **Value:** A repeatable, sellable engagement, not a one-off.
- **Promotion evidence:** template + method reusable for a third vertical without rework.
