## Current Read

Best first wedge: a narrow, security-aware **Physical AI Lifecycle Intelligence Pilot**. The strongest
entry points are EOL QA/calibration, DFM/DVT learning, and field-performance feedback into sustaining
engineering. The pilot should rebuild one priority metric from source events, install a data boundary
register, and create an owner-reviewed promotion graph for reusable manufacturing, engineering, or
CVaaS knowledge.

Recommended delivery lane: Hybrid. Keep operational data and BI surfaces in Hellbender-owned tools,
and use the Ontologize/Arcanum layer for governance receipts, ontology cards, evidence-linked metric
definitions, and promotion decisions.
