# Source Note: TROQAR Visual Identity

## Source

- Source: images supplied in the conversation.
- Type: visual brand and app-positioning evidence.
- Status: seed evidence.

## Observed Claims

- Product brand is TROQAR.
- Tagline is "Corra. Conecte. Conquiste."
- Visual language combines running, territory, and connection.
- Primary palette includes orange/fire and green/territory, with dark and light variants.
- Typography references include Bebas Neue for titles/highlights and DM Sans for body/reading.
- App concepts shown in the image include:
  - weekly distance summary,
  - active challenge,
  - featured route,
  - route map card,
  - bottom navigation for home, routes, challenges, community, and profile.
- Positioning copy frames TROQAR as more than a running app: performance meets territory, people, and challenges.

## Domain Implications

- Territory and community are first-class product concepts, not cosmetic layers.
- UI should eventually make current territory, active challenge, and next run action immediately visible.
- Branding should remain TROQAR even while the repository project id is `body-war`.
