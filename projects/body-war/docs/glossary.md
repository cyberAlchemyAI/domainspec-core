# Glossary

| Term            | Definition                                                                | Status     |
| --------------- | ------------------------------------------------------------------------- | ---------- |
| TROQAR          | Product brand for the running territory game.                             | selected   |
| Body-War        | Internal project id for this workspace.                                   | selected   |
| Runner          | Player who records real-world runs to affect game state.                  | draft      |
| Hex Zone        | Hexagonal territory unit on the city map.                                 | draft      |
| Zone Score      | Composite score for control strength in a zone.                           | draft      |
| Reference Time  | Fastest or owner-held time used by the GDD as invasion target.            | unresolved |
| Invasion        | Attempt to take another runner's zone.                                    | draft      |
| Defense Window  | Time allowed for owner or clan response after invasion.                   | draft      |
| Reconquest      | Successful owner response to keep or retake a zone.                       | draft      |
| Clan            | Group of runners that can coordinate defenses, attacks, and wars.         | draft      |
| XP              | Permanent profile progression.                                            | draft      |
| RunCoins        | Virtual currency used for items, clans, and monetization.                 | draft      |
| League          | Monthly tier based mainly on active zone count.                           | draft      |
| Season          | Multi-week or quarterly competition cycle.                                | draft      |
| Sponsored Zone  | Brand-linked territory with rewards or vouchers.                          | draft      |
| Anti-Cheat Gate | Validation process that prevents suspicious runs from affecting the game. | draft      |
