# Glossary — Body War Business Ontology View Atlas

| Term | Meaning in this run | Forbidden collapse |
| --- | --- | --- |
| Business ontology | The candidate-local nodes, admitted relations, lifecycle policies, profile, residue, and branch declaration under `projects/body-war/ontology/business/`. | Not promoted canon or application runtime. |
| Business meaning branch | The declared interpretive business view in `views/business.json`. | Not a node type, owner route, or promotion state. |
| Editorial lens | A removable UI grouping over a closed catalog that assigns every observed literal `business_kind` to exactly one reader-facing view. | Not a semantic ontology branch, new kind, or ontology concept. |
| Kind group | The nodes of one literal `business_kind` shown as a subgroup inside their assigned editorial lens. | Does not change the node's kind. |
| Core node | A node displayed once in the editorial lens assigned to its literal `business_kind`. | Portal indexes do not create additional core memberships. |
| Internal relation | An admitted relation whose source and target are core nodes of the same lens. | Not an inferred causal or ownership meaning. |
| Portal relation | One admitted relation whose endpoints belong to different editorial lenses. It is rendered once and referenced by source/outbound and target/inbound indexes. | Not a duplicated relation record or reversed relation. |
| Direction | The exact admitted `source_concept -> target_concept` orientation. | Navigating from the target lens does not reverse the relation. |
| Zero-degree node | A node absent from all admitted relation endpoints. | Not meaningless, invalid, or permission to fabricate an edge. |
| Unrelated cue | The literal UI statement “No admitted explicit relation” for a zero-degree node. | Not a claim that no provenance, lifecycle, branch, residue, or source relationship exists. |
| Atlas | The generated local HTML projection containing overview, lenses, nodes, relations, navigation, and claim ceiling. | Not an authority source or replacement for node JSON. |
| Coverage receipt | Deterministic evidence that current source bytes satisfy declared atlas cardinality and integrity invariants. | Not human-comprehension or release evidence. |
| Structural browser receipt | Exact-runtime evidence for navigation, keyboard, no-JS fallback, responsive structure, and visible claim boundaries. | Not a usability-study result. |
