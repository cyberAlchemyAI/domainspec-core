# Implementation Layering — Body War Business Ontology View Atlas

Status: `plan-ready`

## Boundary heuristic

Each layer ends when it unlocks one independently reviewable decision. Later
layers consume earlier projection and generated-byte contracts; they do not
reimplement relation or lens classification.

| Layer | Decision question | Minimum working unit | Included | Deferred | Exit evidence |
| --- | --- | --- | --- | --- | --- |
| L0 | Can a pure contract conserve every current node/relation and classify all current isolates without ontology mutation? | `SWU-BWVA-001` | six-lens catalog, exact research-disposition registry, pure ID-index projection, negative fixtures, coverage validator/receipt | HTML, browser, human study | unit tests and exact coverage receipt |
| L1 | Can the existing generator render that projection as complete static-first HTML while preserving current view outputs? | `SWU-BWVA-002` | additive generator integration, atlas HTML, current-view link, HTML semantics/freshness tests | browser-runtime receipt, application integration | generated bytes and deterministic HTML tests |
| L2 | Does the exact atlas operate structurally in pinned Chromium across keyboard, no-JS, narrow, reduced-motion, and print conditions? | `SWU-BWVA-003` | browser harness, exact runtime receipt, overview/lens screenshots | human comprehension, accessibility conformance, release/deployment | browser receipt and screenshots |

## Value/cost

| Layer | Value unlocked | Main cost |
| --- | --- | --- |
| L0 | falsifies conservation and authority mistakes before rendering | one pure module, catalogs, unit fixtures, receipt validator |
| L1 | gives the user a complete inspectable atlas | one generated HTML projection and renderer tests |
| L2 | proves the exact local artifact is navigable under named structural conditions | shared-browser harness and durable evidence |

## Non-regression guardrails

- L0 returns source IDs and indexes, not mutated node/relation records.
- L1 resolves literals from original maps and renders each concept/relation once.
- L2 consumes exact generated bytes and cannot repair them.
- All layers preserve the pinned node, relation, lifecycle, profile, residue,
  and business-branch digests.
- No layer grants ontology promotion, human-comprehension, release, deployment,
  or production readiness.
