# Design Distill Validation — Atlas Arrow Restoration

## Intent and budget

- seed: restore the lost graphical arrow representation
- target context: the complete current Body War business ontology atlas
- output: one coherent design bundle and plan-ready boundary
- optimization goal: visual direction without a graph hairball or semantic duplication
- mode: `Standard`
- budget assumption: user did not select a Distill budget; Standard applies
- proposal tracks: one
- recursive rounds: two
- role path: one true read-only helper as Proposer; parent as Balancer and reconciler

## Role conversation

### Round 1

Proposer claim:

> Use three levels: whole-ontology directed lens lanes, exact arrows inside
> each canonical relation card, and unchanged metadata.

Evidence:

- 109 portals reduce to 13 ordered lens pairs;
- 231 exact relation cards already exist;
- the curated gallery proves the source → phrase → target grammar.

Balancer objections:

| Category | Objection | Decision |
| --- | --- | --- |
| cognitive load | one 231-edge canvas would be unusable | accept; aggregate only the overview |
| semantic duplication | a separate arrow list could duplicate relation identities | accept; arrows live inside canonical relation articles |
| accessibility | fixed SVG text shrinks and duplicates assistive content | accept; HTML owns meaning, SVG owns geometry |
| authority | aggregate lanes may look like new ontology edges | accept; explicit navigation-summary boundary and exact counts |

### Round 2

Proposer revision:

> Keep a six-node desktop map for immediate visual orientation, pair it with 13
> semantic lanes, and switch relation arrows to a vertical layout on mobile.

Balancer objections:

| Category | Objection | Decision |
| --- | --- | --- |
| responsive semantics | scaling the desktop map is not readable at 390 pixels | accept; retain lanes and hide only the compressed map |
| requisite variety | portal and authority effects are independent dimensions | accept; separate badge and line-style vocabularies |
| implementation boundary | overview aggregation and exact arrow rendering can fail independently | accept; split their SWUs |
| future scale | a general graph-layout engine is premature | accept; fixed six-lens layout with fail-closed completeness guard |

## Technique trace

| Technique | Result |
| --- | --- |
| abstraction-level guard | presentation projection remains separate from ontology meaning |
| recomposition proof | lens-flow groups + exact arrow cards + media validation recompose into the approved progressive design |
| cognitive-load check | 231-edge overview rejected; 13-group overview accepted |
| requisite-variety check | direction, portal status, and authority effect remain separate visual/text dimensions |

| frame-expiry | redesign if lens count changes materially or if a dynamic ontology editor replaces the static atlas |

## Closure

Current coherent design unit: `Arrow presentation projection`.

It owns:

- ordered, non-semantic lens-flow summaries;
- exact relation arrow presentation;
- static and responsive meaning contract;
- deterministic validation boundaries.

Splitting the design into only “SVG styling” loses aggregation, accessible
meaning, and tuple preservation. Combining it with ontology semantics would
violate authority. The implementation may split into independent SWUs without
splitting the design contract.
