## Implementation Detail

Inputs are the existing projected nodes and relations, six lens records,
predicate projection phrases, and exact incoming/outgoing relation incidence.
Output is one reusable escaped semantic disclosure at each reference surface.

Rendering algorithm:

```text
build exact relation incidence by canonical source and target IDs

for each node:
  require label and canonical definition
  render definition, kind/role, status, and owner/resolution gate
  render every blocking question and residue item
  if status is blocked and questions are empty:
    render "No blocking question recorded"
  render exact outgoing/incoming counts and relation links
  if total incidence is zero:
    render "No admitted explicit relation"

for each relation:
  render source -> projection wording -> target
  label the phrase "Projection wording", never "Definition"
  render predicate, direction, authority/value effects, relation ID,
    and forbidden-collapse text

for each lens:
  render title, question, description, exact counts, and directed flows

for each predicate token:
  render token, projection wording, exact usage count, and bounded examples
  do not invent or claim a canonical predicate definition

emit one native semantic disclosure for pointer hover/focus preview,
  keyboard or touch/click persistence, no-JavaScript presence, and print
escape every source value before placing it in HTML
```

Empty residue may be omitted or explicitly rendered as `No residue recorded`.
Blocked status, recorded questions, and effects may never be removed by
truncation. A `title` attribute, SVG text, color, or opaque `data-*` attribute
cannot be the sole content carrier.

Failure modes:

- source definition or required tuple field is missing;
- a projection phrase is labelled as a definition;
- blocked status/question/effect is filtered out;
- an absent question, residue item, relation, or definition is invented;
- related counts or links diverge from exact canonical incidence;
- source text is inserted without HTML escaping;
- a brief is available only on hover or only with JavaScript;
- reference markup creates a duplicate canonical node/relation anchor;
- generated bytes are non-deterministic.

Every failure blocks closeout.
