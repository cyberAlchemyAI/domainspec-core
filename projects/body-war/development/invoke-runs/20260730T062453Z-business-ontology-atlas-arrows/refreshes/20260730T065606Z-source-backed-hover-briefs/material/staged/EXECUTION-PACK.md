## Execution Rules

1. The user selects exactly one dependency-ready SWU.
2. Context Builder binds only its task file, linked source anchors,
   predecessor receipts, current digests, and shared execution control.
3. Task Session performs preflight and obtains mutation admission before writes.
4. Only declared paths may change.
5. The unit runs its exact positive and negative checks.
6. A terminal receipt is written and Invoke Refresh synchronizes status.
7. The successor remains unselected.
