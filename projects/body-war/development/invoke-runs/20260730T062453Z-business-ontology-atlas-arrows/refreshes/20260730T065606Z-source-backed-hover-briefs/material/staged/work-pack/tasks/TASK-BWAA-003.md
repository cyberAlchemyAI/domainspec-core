## Implementation Detail

Inputs are the fixed six-lens catalog, 001 `lens_flows`, the 002 exact-arrow
component, the 005 reference-brief component, and existing atlas counts.
Output is one overview section followed by the six detailed lens sections with
exact arrows and source-backed briefs.

Rendering algorithm:

```text
assert lens IDs exactly match the designed six-lens coordinate table
render six real HTML lens links/nodes
for each of 13 lens_flows in deterministic order:
  calculate an SVG path from fixed source/target anchors
  render a geometry-only arrow path
  render a real HTML lane sentence and relation_count
  link the sentence endpoints to their detailed lens sections
assert the lane counts total 109
render all detailed lens sections, 231 exact relation arrows, and all
  237/231/6/23 source-backed briefs
generate BUSINESS-VIEW-ATLAS.html through generate-views.mjs
assert a second generation is byte-identical
```

Desktop uses the bounded spatial map and semantic lane list. Mobile suppresses
only the spatial compression and retains all lane sentences. Print/no-JS retain
the lane list and detailed relation arrows.

Failure modes:

- a seventh, missing, renamed, or duplicate lens;
- missing/extra flow or flow total mismatch;
- layout path without matching semantic lane;
- overview relation IDs that diverge from `lens_flows`;
- non-deterministic generated bytes;
- loss of any exact relation arrow or coverage count.

Each failure blocks generation/closeout.

## Acceptance

- desktop overview contains exactly six named/linkable lens nodes and 13
  source-to-target arrow lanes;
- each lane exposes a real HTML sentence, count, source link, and target link;
- all lane counts sum to 109 and retain the underlying relation IDs;
- mobile hides only the compressed spatial map and preserves all 13 semantic
  arrow lanes;
- no-JS and print retain readable direction;
- fixed coordinates fail closed if the six-lens set changes;

- reference-brief counts remain 237 nodes, 231 relations, six lenses, and 23
  predicates, with blockers and exact incidence preserved;
- node/relation/portal/isolate counts remain 237/231/109/44;
- generation is deterministic.
