# Glossary — Body War Ontology Atlas Arrows

Status: `invoke-local`  
Promotion: `not-requested`

| Term | Definition | Status |
| --- | --- | --- |
| Arrow sentence | A visual and textual reading of one existing directed relation as source → plain-language phrase → target. It does not create a relation. | linked |
| Relation arrow | The graphical line and arrowhead for one canonical relation occurrence. Its accessible sentence retains the exact relation tuple. | linked |
| Portal arrow | A relation arrow whose endpoints belong to different editorial lenses. It retains the original source and target even when entered from the target lens. | linked |
| Lens flow | A projection-local summary of admitted portals between two editorial lenses. It is not an ontology relation between lenses. | linked |
| Aggregated lens edge | One directed overview arrow for one ordered source-lens/target-lens pair, labelled with the number of canonical portal relations represented. | linked |
| Arrow parity | The condition that the atlas exposes the same source → phrase → target visual grammar already present in the Body War relation gallery. | linked |
| Direction preservation | The source and target shown by every arrow equal the canonical relation source and target; navigation context never reverses them. | linked |
| Progressive graph | A view that begins with bounded aggregate direction and lets the reader descend into exact relation arrows and metadata. | no-match; invoke-local projection term |
| Hairball | An unreadable graph caused by drawing too many nodes and edges on one canvas. This plan prevents it by aggregating only the overview. | no-match; explanatory term |
| Visual-only aggregation | Derived count and routing metadata used for overview presentation; it carries `authority_effect: none` and cannot replace canonical relation rows. | no-match; invoke-local projection term |
| Reference brief | A concise semantic HTML disclosure that presents only the ontology or projection data admitted for the referenced node, relation, lens, or predicate. | invoke-local interface term |
| Projection wording | Plain-language phrase owned by the atlas projection for reading a relation or predicate. It is presentation wording, not a canonical relation definition. | invoke-local projection term |
| Related incidence | The exact existing incoming and outgoing relation references attached to a node for navigation. It does not create or infer a relation. | invoke-local projection term |
| Missing-data statement | Explicit text such as `No blocking question recorded` or `No admitted explicit relation` used when the source has no corresponding value. | invoke-local interface term |

## Forbidden collapses

- An aggregated lens edge is not an admitted ontology relation.
- Arrow position, curvature, or proximity does not imply sequence, causality,
  importance, lifecycle, ownership, or promotion.
- A dotted arrow does not remove or weaken the canonical relation; it exposes
  blocked, projection-only, or explicit non-promotion meaning.
- Visual arrow evidence is not human-comprehension or accessibility-conformance
  evidence.
- A reference brief is not a second ontology record, and hover state is not
  authority.
- Projection wording is not a relation or predicate definition.
- An absent blocker question, residue item, or relation is not permission to
  invent one.
- A `title` attribute, SVG label, color, or opaque `data-*` field is not a
  sufficient reference brief.
