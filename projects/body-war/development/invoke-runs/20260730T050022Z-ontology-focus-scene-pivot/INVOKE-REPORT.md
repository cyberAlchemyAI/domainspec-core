## Architecture Decision

The first draft assumption was corrected:

- the reviewed Body War UI is the native Understand Anything dashboard;
- the checked-in `upstream/overlay/.../oew/**` sources own a separate `?oew=1`
  workspace;
- native changes therefore require a new, digest-bound successor overlay and
  repaired build route over the pinned upstream archive;
- generated archives, dashboard bundles, historical locks, receipts, and
  `package.json` remain immutable.

The feature uses a pure scene projector, explicit scene-session reducer,
pre-layout native renderer bridge, semantic portal controls, named detail
landmark, exact source literals, and independent build/browser receipts.
