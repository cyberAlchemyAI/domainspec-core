# Implementation Layering

| Layer | Owner | Inputs | Outputs | Forbidden responsibility |
| --- | --- | --- | --- | --- |
| Learner task authoring | `authoring/comprehension-task-catalog.mjs` | learner-visible task/loci/prompt/stimulus references | immutable learner task data | reviewer keys, rubric, stalls, results |
| Learner projection | `scripts/generate-comprehension-task.mjs` | learner catalog only | `BUSINESS-COMPREHENSION-TASK.html` | importing or reading reviewer protocol |
| Reviewer protocol | `review/comprehension-protocol.json` | accepted review findings | keys, allow/deny rules, coverage and stall contract | learner rendering |
| Journey authoring | `authoring/view-catalog.mjs` | existing typed relation IDs | relation-local story annotations | new ontology relations or decisions |
| Journey projection | `scripts/generate-views.mjs` | catalog, nodes, relations, lifecycle, profile, residue | generated journey HTML | ontology mutation, gate acceptance |
| Deterministic tests | `tests/*.test.mjs` | source and generated bytes | pass/fail assertions | browser or human comprehension claims |
| Browser evidence | `scripts/validate-comprehension-browser.mjs` | exact generated stimulus/task bytes and shared Playwright runtime | pinned receipt and screenshots | comprehension, release, production claims |

## Dependency direction

```text
learner catalog -> learner generator -> learner HTML
reviewer protocol ---------------------> reviewer-side tests only

view catalog + ontology + profile + residue
  -> view generator
    -> journey HTML

generated task + generated journey + runtime identity
  -> browser validator
    -> structural browser receipt
```

The learner generator has no edge to the reviewer protocol. Profile and residue
are removable projection inputs: removing them disables annotations but does
not alter ontology meaning.
