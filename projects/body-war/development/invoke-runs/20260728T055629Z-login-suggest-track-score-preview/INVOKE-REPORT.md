## Prototype Meaning

The first selectable implementation route can let a user log in through the
fixture/session path, choose a non-first SuggestedTrack, affirm exact consent,
derive private candidate geometry, assemble a canonical complete-window
`ScoreInputSnapshot`, and see an explained `preview_only` score in the web
page. That is local fixture evidence only.

Real Strava code, hosted admission, and a participant witness are later,
separate lanes. A real comparable score requires the ratified history/consent
contract and a complete canonical snapshot; one geometry-seeding activity
cannot manufacture a 14-day score.
