## Unresolved Gaps And Residue

- `branch` is not a current semantic partition in the graph; `branch:business`
  names only the single business branch.
- The 17 layers are type groupings, not necessarily reader journeys.
- The five existing tour scenes are the only explicit small, ordered projection
  groups in the admitted graph and therefore the safest first branch
  hypothesis, but the review must try to falsify that choice.
- Nodes outside all tour scenes need a deterministic fallback focus rule.
- No current evidence proves that edge clicking can pivot the view, preserve
  backtracking, or expose a keyboard-equivalent interaction.
- No current evidence proves that type, selection, direction, status, or
  authority meaning survives grayscale, high contrast, or reduced motion.
- Agent browser attacks remain structural black-box pretests. A later human
  witness is required for a human-comprehension claim.
- This strategy does not authorize source edits, an interaction prototype,
  ontology mutation, release, deployment, or production.

## Design Consequences

1. The review will call the proposed unit a **focus scene**, not a semantic
   ontology branch.
2. The first hypothesis is to use the existing tour `nodeIds` as explicit focus
   scenes. A clicked relation that crosses to another tour scene should pivot to
   that destination scene.
3. For nodes outside tour scenes, the candidate fallback is a one-hop focus
   neighborhood with outbound relations rendered as portals. This remains a
   hypothesis until the review accepts or rejects it.
4. Layer filtering is not accepted as the branch definition because it groups
   by node type and can still produce large, low-comprehension views.
5. Color may encode node kind or status only when text, icon/shape, border
   treatment, and accessible names provide redundant meaning.
6. Rotation or reorientation may indicate a focus transition, but it must not
   imply causal, temporal, promotion, or execution semantics. Reduced-motion
   mode must use an immediate pivot.
7. The branch pivot must retain an explicit breadcrumb/back stack, the selected
   relation label and direction, source references, and the candidate-local
   authority ceiling.
