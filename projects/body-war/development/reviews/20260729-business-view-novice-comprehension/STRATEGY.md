## Required review decisions

The review must decide, from current evidence:

1. whether the learner prompt belongs in
   `BUSINESS-JOURNEY-EXPERIMENT.html`, `BUSINESS-VIEWS.html`, a separate
   generated projection, or no learner-visible HTML;
2. which fixed tasks measure locate, trace, retell, branching, vocabulary, and
   authority-boundary comprehension without embedding answers;
3. whether the authoring-oriented stall classes can be adapted or require a
   reading-specific taxonomy;
4. how learner-visible content stays separate from the reviewer answer key,
   coverage audit, scoring rubric, and run dataset;
5. which catalog, generator, unit, browser, keyboard, responsive,
   reduced-motion, print, and no-JavaScript checks a later implementation needs;
6. where the agent structural pre-test ends and a separately authorized human
   witness begins.
