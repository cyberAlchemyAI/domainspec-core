# Body-War

Body-War is the project container for TROQAR, a GPS-based territorial running game.

TROQAR turns real-world running routes into a competitive map: runners conquer hex zones, defend territory, join clans, earn XP, and progress through leagues and seasons.

This project starts as a DomainSpec and Arcanum discovery baseline. No application prototype is included in this first pass.

## Project Structure

- `docs/PROJECT-OVERVIEW.md` - discovery summary and scope.
- `docs/INITIAL-DEFINITIONS.md` - glossary, bounded contexts, concepts, rules, and interfaces.
- `docs/PROJECT-DECISIONS.md` - selected and unresolved project-level decisions.
- `docs/HYPOTHESES.md` - falsifiable product and game-design hypotheses.
- `docs/EXPERIMENT-CANDIDATES.md` - early validation experiments.
- `docs/features/game-rules/SPEC.md` - first DomainSpec feature slice.
- `docs/features/park-track-pilot/` - first candidate distill and implementation layering.
- `docs/research/source-notes/` - curated notes from supplied source evidence.
- `domainspec/` - local DomainSpec runtime reference bundle.
- `.arcanum/` - Arcanum observability and Necronomicon harness state.
- `.codex/commands/` - local Arcanum command surface.
