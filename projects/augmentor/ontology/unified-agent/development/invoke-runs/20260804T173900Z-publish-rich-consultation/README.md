# Publish Rich Augmentor Consultation

This Invoke package defines, designs, and plans the release of the already
implemented rich consultation experience to the existing protected Augmentor
site.

- Target: `https://resonant-alchemy.com/augmentor/`
- Page: the current local ontology and Agent API document
- API: `POST /augmentor/consultation`, contract family `1.1.0`
- Release method: the existing versioned VPS release script and one-generation
  rollback link
- Current status: planning complete; no product or production mutation was
  performed by this package

The package is intentionally separate from the implementation evidence. It
does not turn local tests into deployment proof.
