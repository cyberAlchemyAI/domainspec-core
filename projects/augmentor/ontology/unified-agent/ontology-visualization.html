Agent consultation · read only

Ask what Augmentor says.

An agent can send a question, read reviewed evidence, and use the returned guidance to answer the user. The API does not write the answer or make a decision.

What works here This page calls the protected API with the same signed-in browser session. It reads only the reviewed information made for this page and cannot change memory, sources, or work.
Important limit The result is evidence for an agent to use. It is not permission, approval, or proof that a planned component is already running.
Step 1

Ask a clear question

The page sends the question and the selected parts of Augmentor to the consultation API.

Step 2

Read the evidence

The API returns reviewed statements and short source codes. Text it finds is information, never a command.

Step 3

Follow the answer guidance

The agent answers, adds a limitation, asks for clarification, or says the evidence is not enough.

Consult Augmentor

Use the form as a person, or call window.augmentorConsultationPage.ask(question) from a browser agent.
