## Status meanings

| Status | Meaning |
| --- | --- |
| `candidate` | Useful practice exists, but authority + validation still being proven. |
| `active-pattern` | Used by active artifacts, but its discipline-level contract is not canonical. |
| `canonical` | Accepted authority with validator or constitution support. |
| `deprecated` | Superseded or withdrawn. |

## Growth Rule

Promote a discipline only when the next route names owner, evidence, validation
surface, and mutation boundary. Discipline evidence can recommend a route, but it
cannot directly promote ontology, definitions, constitutions, spells, sigils,
coordinates, or implementation work.
