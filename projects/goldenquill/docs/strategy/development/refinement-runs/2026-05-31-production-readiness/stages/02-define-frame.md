# Stage 02 - Define Frame

Production-readiness means the next implementation agent can answer four questions before touching code:

1. Which artifact is authoritative?
2. Which surface is production target, prototype, archive, demo, generated, or draft?
3. Which verification command proves the claim?
4. Which gate path governs mutation?

This frame narrows the problem from "make GoldenQuill production-ready" to "build the readiness spine that lets production work start safely."
