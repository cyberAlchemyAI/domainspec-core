# cyberAlchemy Website

Private project space for turning dispersed CyberAlchemy, Arcanum, and foundry
knowledge into a curated website plan.

This project is not the website implementation yet. It is the intake and
selection surface: collect the source material, decide what is public-ready,
adapt what needs translation, and reject what should remain internal.

## Boundary

The website may use concept-level and public-safe CyberAlchemy language. It must
not publish private parent paths, private submodule paths, workspace-only
evidence, owner handoffs, private research residue, or claims that outrun proof.
