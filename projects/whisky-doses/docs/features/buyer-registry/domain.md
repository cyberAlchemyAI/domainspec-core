# Domain: Buyer Registry

This file is the structural source of truth for Buyer Registry entities, value objects, and types.

## Entities

### Buyer

A [Buyer](#buyer) is a WhatsApp group participant whose identity is managed by the [group operator](../../PROJECT-OVERVIEW.md#actors-and-stakeholders) so later features can safely reserve doses and ship packages.

| Field                           | Type                                  | Required                  | Description                                                              |
| ------------------------------- | ------------------------------------- | ------------------------- | ------------------------------------------------------------------------ |
| [Buyer](#buyer).id              | [BuyerId](#buyerid)                   | yes                       | Stable system identity for the buyer                                     |
| [Buyer](#buyer).name            | string                                | yes before reservation    | Operator-maintained human name for buyer lookup and shipping preparation |
| [Buyer](#buyer).whatsAppMention | [WhatsApp Mention](#whatsapp-mention) | yes before reservation    | Group-visible buyer identifier used by listing and reminder features     |
| [Buyer](#buyer).cpf             | [CPF](#cpf)                           | yes before reservation    | Brazilian taxpayer identifier required before dose reservation           |
| [Buyer](#buyer).shippingAddress | [Shipping Address](#shipping-address) | yes before first shipment | Address collected only when shipping readiness is needed                 |
| [Buyer](#buyer).status          | [Buyer Status](#buyer-status)         | yes                       | Lifecycle state used for active use and retention handling               |
| [Buyer](#buyer).createdAt       | timestamp                             | yes                       | Time the buyer record was registered                                     |
| [Buyer](#buyer).updatedAt       | timestamp                             | yes                       | Time the buyer record last changed                                       |
| [Buyer](#buyer).inactiveAt      | timestamp                             | no                        | Time the operator manually marked the buyer inactive                     |
| [Buyer](#buyer).retentionAction | [Retention Action](#retention-action) | no                        | Operator-selected deletion or anonymization outcome for inactive data    |

**Lifecycle:** See [BuyerLifecycle](states.md#buyerlifecycle).

**Operations:** [RegisterBuyer](operations.md#registerbuyer), [UpdateBuyerIdentity](operations.md#updatebuyeridentity), [SetBuyerShippingAddress](operations.md#setbuyershippingaddress), [MarkBuyerInactive](operations.md#markbuyerinactive), [DeleteOrAnonymizeBuyer](operations.md#deleteoranonymizebuyer).

## Value Objects

### BuyerId

| Field | Type   | Constraint                                        |
| ----- | ------ | ------------------------------------------------- |
| value | string | Stable, opaque identifier generated by the system |

**Equality:** Two [BuyerId](#buyerid) values are equal when their `value` fields match exactly.

### CPF

| Field | Type   | Constraint                                                                                      |
| ----- | ------ | ----------------------------------------------------------------------------------------------- |
| value | string | Normalized CPF digits; required before reservation; unique among active [Buyer](#buyer) records |

**Equality:** Two [CPF](#cpf) values are equal when their normalized digit strings match.

### WhatsApp Mention

| Field | Type   | Constraint                                                                                                |
| ----- | ------ | --------------------------------------------------------------------------------------------------------- |
| value | string | Group-visible mention or handle; required before reservation; unique among active [Buyer](#buyer) records |

**Equality:** Two [WhatsApp Mention](#whatsapp-mention) values are equal when their normalized mention values match.

### Shipping Address

| Field         | Type   | Constraint                                               |
| ------------- | ------ | -------------------------------------------------------- |
| recipientName | string | Required before first shipment                           |
| streetLine1   | string | Required before first shipment                           |
| streetLine2   | string | Optional complement                                      |
| city          | string | Required before first shipment                           |
| state         | string | Required before first shipment                           |
| postalCode    | string | Required before first shipment                           |
| country       | string | Required before first shipment; defaults to Brazil in v1 |

**Equality:** Two [Shipping Address](#shipping-address) values are equal when all normalized address fields match.

## Enums

### Buyer Status

| Value      | Description                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------- |
| active     | Buyer can be used by downstream reservation and messaging features when other rules are satisfied             |
| inactive   | Operator has manually marked the buyer inactive, but data remains retained until a retention action is chosen |
| anonymized | Buyer PII has been anonymized after inactive marking                                                          |
| deleted    | Buyer PII record has been removed after inactive marking                                                      |

### Retention Action

| Value     | Description                                             |
| --------- | ------------------------------------------------------- |
| none      | No deletion or anonymization action has been applied    |
| anonymize | Operator selected anonymization for inactive buyer data |
| delete    | Operator selected deletion for inactive buyer data      |
