Canvas guide

Navigate the ontology

An ontology is a shared vocabulary: it defines which kinds of things exist, which properties can describe them, and which relationships can connect them.

DomainSpec says what a concept means. The architecture ontology says what can be inspected in code. A profile says what TypeScript, Python, Rust, or a project expects. An observation supplies typed facts from an adapter or fixture. A finding explains where expectation and observation differ.

Each node gives you the plain-language meaning first. Click it to open the exact contract and its authority boundary. Drag nodes to explore relationships, drag empty space to pan, and use the wheel to zoom.
