## Lanes And Subagents

One `reviewers` group runs two read-only skeptics in parallel on the
`attack-vector` axis:

- `query-contract-critic` — definitional attack on every QRY-003 terminal path;
  returns a closed-code path matrix, a selected normalize-versus-add-code
  repair, rejected alternative, fixtures, and verified change requests.
- `relation-witness-falsifier` — counter-example attack on all 25 relation
  candidates; returns exactly 25 planned baseline-versus-mutant rows and
  `KILL`, `MERGE`, or `DEFER` recommendations where a behavior-changing
  witness cannot be specified.

The sheet deliberately uses `agent_name: null` for both agents: no pooled
historical persona is being presented as a semantic owner. The native runtime
agent IDs will be preserved only in execution receipts.

## Dependency Flow

The reviewers are independent and have no inter-group connections. The parent
joins both receipts and uses them as advisory inputs to Interrogation and
Distill. They do not replace native Refine stage receipts and cannot authorize
ontology mutation.
