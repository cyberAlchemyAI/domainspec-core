# Template Selection

- Define: `invoke.domainspec-spec`
- Design: `invoke.architecture`
- Plan: `invoke.work-pack` plus `implementation-layering`
- Complexity: medium
- Output mode: split

The DomainSpec spec family is eligible because this package defines a typed deterministic contract, not a prose-only research note. The architecture template is mandatory for normal Design. The work-pack template is mandatory because the future material package contains more than two outputs and needs exact Task Session closeout bindings.

No equal-scoring template tie exists. Selection is invoke-local and does not promote a template, Inventory entry, term, ontology, or implementation.
