# Workbench UI V1 Glossary

| Term | Meaning | Status |
| --- | --- | --- |
| Agent task | A schema-v2 request with a required requested skill and approval-gated bridge lifecycle. | linked |
| Dry run | A legacy local no-op proposal used for diagnostics; it completes on approval. | linked |
| Run | The user-facing projection of one envelope, approval, claim, result, receipts, and linked Canvas output. | new-local |
| Run timeline | Ordered display of preparation, approval, availability, claim, result, and receipt stages. | new-local |
| Work rail | Compact surface for creating work and selecting active or historical runs. | new-local |
| Inspector | Contextual surface for actions, details, grants, identifiers, and evidence. | new-local |
| Evidence drawer | Expandable receipt, context, validation, and diagnostics view. | new-local |
| Canvas workspace | Primary area that displays the current retained HTML artifact and interactions. | linked |
| Craft source | A pending Craft item selected as input to a new agent task; selection does not mutate Craft. | new-local |

No term is promoted to global Arcanum authority by this package.
