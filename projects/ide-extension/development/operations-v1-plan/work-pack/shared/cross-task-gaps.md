# Cross-Task Gaps

| Gap | Status | Owner | Route |
| --- | --- | --- | --- |
| Browser execution of trusted-local scripts | accepted limitation | product boundary | Preserve server-side inert transformation; do not claim hostile HTML safety. |
| Refresh acknowledgement after restart | accepted transient loss | navigation task | Recover the durable target and expire unknown command status. |
| Historical body after intentional prune | accepted unavailable state | retention task | Stable tombstone metadata, `410`, and retry unavailable-body response. |
| Per-browser or per-tab targets | deferred | future navigation design | Reopen only with a concrete multi-workbench value witness. |
| Region mutation/scaffolding | deferred L3 | future design | Separate Decision Gate and Invoke plan. |
| Automatic merge/collaboration | excluded | future architecture | Keep stale operation fail-closed. |
| Remote browser/editor control | excluded | separate integration lifecycle | Operations V1 is a local HTML workbench protocol only. |
| Dirty worktree | active constraint | every Task Session | Preserve unrelated changes and validate scoped paths. |
