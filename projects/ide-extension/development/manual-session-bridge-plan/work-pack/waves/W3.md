## Exit Gate

- Full schema, project, bridge, and browser suites pass.
- Automated tests prove secrecy, singleton claim, actor separation, bindings,
  atomicity, restart, and v1 compatibility.
- The real session learns the private request only from successful claim and
  returns an admitted result with separate authorization/execution receipts.
- Closure matrix resolves all obligations and reports residue without widening L0.

## Promotion Evidence

Task Session receipts for 009-010, manual witness report/receipt/artifacts for
011, browser screenshots/traces, and a closure report with exact scoped claims.

## Stop Conditions

Automated or browser proof fails; the live server/session is unavailable; the
skill was disclosed before claim; the chosen task needs non-L0 effects; result
remains chat-only; or any readiness claim exceeds the evidence.
