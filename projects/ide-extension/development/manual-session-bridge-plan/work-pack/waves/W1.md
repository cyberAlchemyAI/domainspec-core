# Wave W1: Kernel Authority

| Field | Value |
| --- | --- |
| Layer / slice | L0 / S-002 |
| Tasks | `TASK-BRIDGE-KERNEL` |
| SWUs | `SWU-MSB-003` -> `SWU-MSB-004` -> `SWU-MSB-005` |
| Entry gate | W0 exit gate passes. |
| Parallelism | None; all units share projector/server authority and bindings. |

## Execution Order

1. 003: authorization receipt plus singleton ready/unready/revoke.
2. 004: atomic late-disclosure claim, interruption, operator release/requeue.
3. 005: bound terminal result, execution receipt, and evidence artifacts.

## Exit Gate

- Approval has one durable authorization receipt and no execution claim.
- Pre-claim and failed-claim responses contain no skill/task packet.
- One concurrent claimant wins; actor separation and restart behavior pass.
- Every terminal result has one resolvable execution receipt with full bindings.

## Promotion Evidence

API/contract/concurrency/recovery/artifact tests and Task Session result receipts
for 003-005. W2 receives stable kernel interfaces, not partial shared-state edits.

## Stop Conditions

Multiple ready targets survive; failed claim leaks payload; session can perform
operator actions; result can terminalize without durable execution evidence; or
atomic append/projection cannot be guaranteed by the local mutation boundary.
