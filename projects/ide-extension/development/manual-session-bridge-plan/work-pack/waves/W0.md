# Wave W0: Contract And Replay Baseline

| Field | Value |
| --- | --- |
| Layer / slice | L0 / S-001 |
| Tasks | `TASK-CONTRACT-MIGRATION` |
| SWUs | `SWU-MSB-001` -> `SWU-MSB-002` |
| Entry gate | Approved design, five passed decisions, and no-op refresh. |
| Parallelism | None; 002 consumes the contract oracle from 001. |

## Execution Order

1. `SWU-MSB-001`: spec, grants, schemas, fixtures, and typed receipt union.
2. `SWU-MSB-002`: version-aware v1/v2 replay and bridge typestate.

## Exit Gate

- v1 fixtures replay without mutation or changed projection.
- v2 schemas distinguish authorization, execution, and legacy receipts.
- Legal/illegal bridge transitions and singleton-ready replay tests pass.
- No behavior endpoint has been exposed prematurely.

## Promotion Evidence

Task Session results for 001/002, schema output, replay/transition tests, and
scoped diff evidence. Only then may W1 begin.

## Stop Conditions

Receipt branches overlap; historical logs require rewriting; v1 replay drifts;
or L0 grants require write/network effects.
