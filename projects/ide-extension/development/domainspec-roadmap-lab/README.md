# DomainSpec v2 Roadmap Lab

This package designs and plans a proposal-first interactive roadmap inside the
existing trusted-local ide-extension Canvas. It is meant to let a newcomer such
as Victor understand one production-roadmap node and submit a real, reviewable
improvement without turning the browser into DomainSpec authority.

## What The First Proof Answers

Can a newcomer learn FPR-01, explain it, inspect its evidence trail, and submit
one durable proposal bound to the exact roadmap they saw? Later waves test
repeatability, governance, Victor's real experience, and one accepted copy
round trip. They do not silently widen into authentication, collaboration,
general source browsing, or direct lifecycle automation.
