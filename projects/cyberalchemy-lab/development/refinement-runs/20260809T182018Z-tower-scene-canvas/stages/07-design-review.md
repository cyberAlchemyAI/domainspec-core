# 07 — Interrogation design review

## Accepted repair conditions

- Never expose a bare numeric layer label in a control, deep link, or test selector.
- A system architecture panel needs `implementation_status` and `unavailable_reason`; evidence-scene labels need `evidence_state` and locked `source_refs`.
- Decorative asset containers are `aria-hidden`, including the mini laboratory.
- The mobile layout keeps the tower/scene controls above the detail dock; decorative canvas elements may disappear.
- URL restoration is optional until the first descriptor contract passes; invalid input returns to overview and visibly explains refusal.

## Design verdict

The plan survives if implementation stays HTML/CSS/JS and begins with one synthetic tower. It does not justify an engine or a second runtime.
