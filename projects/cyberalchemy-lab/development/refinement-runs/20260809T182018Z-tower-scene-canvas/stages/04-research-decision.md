# 04 — Research decision

## Decision: no new external research in this Refine run

The selected route is `research-if-gap-appears`. Local sources are enough to establish:

- the current synthetic witness and its claim ceiling;
- the Tower System layer/evidence state distinctions;
- the existing page’s navigation and motion implementation boundaries; and
- a first plan’s local browser-test requirements.

The engine question is not a blocking semantic gap for this plan. The current product is an HTML/CSS/JS page, and the proposed work pack can keep that implementation style. Any later request to adopt a game or animation runtime is a new dependency/implementation decision and needs its own bounded investigation and confirmation.

## Refusal condition

Stop and ask the operator before external browsing if implementation planning cannot decide one of these from local evidence:

1. a required rendering or interaction capability unavailable to the existing page/runtime;
2. a package license/security/runtime choice; or
3. a claim about usability, accessibility, or real-tower data that requires external or human evidence.
