# 01 — Context Builder baseline

## Frame

The current implementation is one read-only synthetic witness, not a multi-tower runtime. Its loader accepts only `tower:toy`, verifies locked synthetic inputs, and returns a candidate-local L0 projection. The existing page is already spatial and animated, but it displays source orbit, relations, a candidate meaning panel, and an open residue rather than selectable tower levels.

There are two incompatible-looking numeric vocabularies that must remain separate:

1. The fixture's evidence progression is `L0 corpus`, `L1 residue map`, `L2 closure plan`.
2. The Tower System's architectural stack is `L1 substrate`, `L2 construction`, `L3 application`, `Lphi decision policy`, `L4 adjudication`.

The first must become the first three interactive scenes. The second is a future architecture map whose elements need their own evidence-state labels; it cannot be rendered as a functioning persona/decision/verdict runtime.

## Direct evidence

- `synthetic-one-tower.json`: `fixture_class: synthetic-contract-fixture`, `authority_effect: none`, one `tower:toy`, `ordered_artifacts` for L0/L1/L2, and one open representative-selection residue.
- `l0-witness.mjs`: a fail-closed synthetic L0 read model with a claim ceiling that excludes a representative tower, IDE, and authority claims.
- `SYSTEM-VIEW.md`: calls runtime-queryable graph, persona-as-artifact, ELO/oracle-consensus net-new; MOGT is design-stage/unproven.
- `research-tower.html`: has a local candidate spatial canvas, pause motion control, and reduced-motion CSS; narrow viewports suppress decorative mini-lab/robot layers.

## Context-builder decision

Plan the first vertical slice as a **Tower Scene Manifest** that projects evidence-level scenes from the existing read model. It is not a graph, persona, or autonomous navigation engine. A later multi-tower manifest can add tower descriptors only when each descriptor has its own locked read-model projection.

## Open evidence needed from review

The semantic mapper must state the exact allowable content and labels per scene before any design/plan artifact treats the scene names as stable.
