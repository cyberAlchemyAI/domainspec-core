## `all research` Gate

The phrase **all research must not appear as an affirmative result**. Available evidence supports only a frozen `TOWER.md` occurrence census.

Any later completeness assertion must define:

```text
snapshot universe U
eligible set E = {x in U | eligibility(x)}
explicit exclusions X
duplicate equivalence relation ~
included eligible identities I
unresolved eligibility or identity set Q

coverage_occurrence = |I_occurrences| / |E_occurrences|
coverage_identity = |I / ~| / |E / ~|
```

It must report snapshot time and repository boundary, enumeration method, eligibility rule, exclusions and reasons, duplicate-collapse policy, missing required artifacts, and the unknown count or an explicit statement that it is not established.
