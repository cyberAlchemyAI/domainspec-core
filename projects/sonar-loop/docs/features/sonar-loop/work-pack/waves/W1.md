# W1: Layer 0 POC Build

## Objective

Deliver the smallest governed pass that proves Sonar Loop can turn quality evidence into one actionable local remediation task and telemetry event.

## Entry Gate

- W0 exit gate accepted.
- Local module/source paths selected during execution.

## Exit Gate

- One parent cycle and one child pass are recorded.
- At least one finding bundle and one local remediation task exist.
- Checkpoint outcome is recorded as `continue`, `pause`, `halt`, or `complete`.
- L0 does not require GitHub/Jira export per D-001.
