Harden the single-repo loop with bounded retry, skill-bundle reuse/recompose, three candidate solutions, abstraction scoring, and learning writeback.

- Sonar retry is bounded to one remediation-evidenced retry.
- Exactly one skill-bundle branch is selected per pass.
- Every task has exactly three candidates.
- Learning update includes selected candidate, rationale, observed outcome, and quality delta.
