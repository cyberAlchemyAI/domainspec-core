## Commercialization Throughline

- Entry narrative: engineering leadership buyer, low Sonar maturity evaluator onboarding, and day-1 value from actionable finding bundles.
- Pilot narrative: assisted-first operating mode with dual-repo pilot qualification and week-1 governance proof.
- Scale narrative: single-team multi-repo replication, governance proof package, and GitHub-first integration posture for initial scale.
- Commercial model: docs/spec product as primary packaging, guided accelerator as secondary intent, and one-time per-repository purchase framing.
