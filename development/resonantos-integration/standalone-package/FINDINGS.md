# Findings

## One-Line Finding

The host archive owns the read map and fact-over-time substrate; CyberAlchemy plugs into the
write/decision seam: intake, Review Queue, decision, and trusted promotion.

## What Is Already Host-Owned

- Read/search.
- Intake and Review Queue surface.
- Decide vocabulary: approve, reject, escalate.
- Promotion seam name and host-mediated trusted-write boundary.
- Recall importance and temporal fact governance.

## What This Package Supplies

- Evidence-card and EvidenceSet candidate contracts.
- Promotion owner and default-deny vocabulary.
- Scope-tag mapping.
- No-promotion policy.
- Receipt-debt expectations.
- Host-side trusted-write provider body contract.

## Honest Gaps

- The trusted-write provider body is specified here but not implemented.
- No end-to-end host promotion run is included.
- External repository mutation is deferred.

## Non-Overlap Rule

Do not rebuild host validity windows, supersession, confidence, utility, contradiction resolution, or
recall ranking. CyberAlchemy reads those signals and writes a separate authority/promotion decision
dimension.
