# W1 - Auth Behavior

Layer: L1
SWUs: `SWU-AUTH-002`, `SWU-AUTH-003`, `SWU-AUTH-004`, `SWU-AUTH-005`

## Goal

Implement reusable auth and Strava behavior in TypeScript, behind DomainSpec layers.

## Promotion Evidence

- domain tests for sessions, tokens, permissions, OAuth state
- application tests for authenticate/authorize/logout/Strava flows with mocked ports
- interface tests for cookie/CSRF denial matrix
- mocked Strava gateway contract tests

## Gate

Provider tokens must never appear in public responses or tracked data fixtures.
