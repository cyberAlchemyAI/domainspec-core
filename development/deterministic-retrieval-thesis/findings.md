# findings.md — deterministic-retrieval thesis, synthesized (post-narrowing)

## 1. One-line answer

The thesis holds in a *corrected and narrowed* form. After Lane-Z (deepen) and Lane-A (non-vacuity + precedent), the surviving irreducible object is **a stable, citable, typed referent + a recorded gate over it, with the query arriving already-typed** — available to graph-only, hybrid, OR separate-artifact encodings alike. A quarantined non-deterministic generator (write-time, model-driven extraction) feeds the recorded gate; bounded agents then get cheap, governable reads — but only within a stable schema epoch, only under a node-contract boundary on cross-feature edges, and only if you also own (and price) the ingest bet and the ontology-maintenance treadmill. Two Lane-A demotions are load-bearing: **(1) unification ("same object in two forms") is NOT the keystone** — the typed seed is, encodable as a unified graph or (dominantly) a drift-checked bidirectional mapping; **(2) determinism is NOT a governance requirement** — provenance + a citable referent is, and determinism is a cost-dominance optimization over it. The genuine contribution is the **governance + typed-intent provenance wrapper around three established patterns** (GraphRAG-style traversal, CQRS-style ingest relocation, VSM-S5/symbolic-IR governance) — not a novel retrieval algorithm. "Deterministic retrieval enables governance" is a marketing name that overclaims on both counts.

## 2. Per-leg deep synthesis

### Leg 1 — typed-intent → discrete vector (Z1)

**Deepened claim.** In RAG the query is an untyped string and the system must guess its neighborhood; in DomainSpec the query *arrives as a node already sitting in a typed graph* (node→code-pattern, edge→composition-rule, `SEED.md:16-22`). The agent is *handed* its start point — a small enumerable subgraph (node + typed in/out edges), not a continuous embedding to denoise. That handed-over subgraph *is* the "discrete vector" and *is* the ephemeral agent's context (`SEED.md:23-27`). Z1 argues this is the keystone: strip it and legs 2/3 have no discrete substrate to act on (Z1 §"Why keystone").

**Where it HOLDS.** The leak is bounded *iff* cross-feature edges are typed, named, single-target, and the foreign node is referenced by its **contract, not its body**. v1 evidence supports this: every cross-feature edge resolves to exactly one foreign node via a registry query (`produces-for`/`triggers-cross`/`enforces-cross`, `RELATIONSHIPS.md:82,91,100`). Under that discipline the seed = own node + N typed edges + the *contracts* of ≤N foreign nodes. Stays discrete and enumerable; a one-hop typed lookup that genuinely beats embedding search (Z1).

**Where it BREAKS (the counterexample).** Following `GenerateSettlement produces-for Player` then `enforces-cross` into a foreign Rule pulls a node with its own edges, whose targets have edges — **transitive closure over cross-feature edges does not obviously terminate before pulling in a large fraction of the graph** (Z1 counterexample). When the foreign contract is *insufficient* (hidden invariants enforced inside the foreign operation; multi-hop `calculates` chains; ordering over shared mutable state — the `dcb-correctness` seam, `SEED.md:71-72`), the closure re-expands and the discrete seed becomes discrete-in-name-only — re-importing the exact RAG/grounding cost the leg claims to delete.

**Narrowing carried (claim≤proof).** **Build-from-owned** of `spec-ontology-unification` over v1's real typed graph (`TAXONOMY.md:11-23`, `RELATIONSHIPS.md`). Novelty is demoted to the **reframing** — "the already-typed query is the discrete retrieval seed" — *not* a new mechanism. Discreteness is **conditional on contract-completeness of nodes**, which is unproven (the seed's own open residue, `SEED.md:68-70`).

### Leg 2 — ingest-time cost relocation (Z2)

**Deepened claim.** The cheap deterministic read is **purchased, not free**: comprehension cost is *relocated* from query-time to a slow, model-heavy, governed write loop. The PDF's two-loop split makes this structural — read is "no neural models, CPU/disk only" precisely because the write was all-LLM (v7.1 p.1-7). Z2 names the five write-time line items: (1) neural extraction into typed edges, (2) scope-tagging, (3) promotion/governance metadata (the CAV2 b2 overlay the substrate has *no column for*), (4) provenance stamping (the cheapest item), (5) ongoing ontology maintenance. The bet: items 1-4 amortize — pay once at write, read free thereafter.

**Where it HOLDS.** The relocation is a genuine win, not a shell game, on three conditions the corpus supports: high read/write ratio; comprehension stable once paid (RAG re-pays on *every* query — this is the clean structural edge); and **authority is the cleanest win** — the substrate has no field for it at all, so a deterministic read of `promotion_stage` is a column lookup, because authority is a *decision* (a fact-about-a-fact) and decisions, once made, are static (Z2 §2).

**Where it BREAKS (the counterexample).** "True within a stable schema epoch for clean inputs; FALSE as an unconditional claim" (Z2 §4). Three seams: **(3a)** messy real input (PDF §10.3 synthetic-vs-real caveat) makes extraction fail or mis-type — the read then deterministically returns *nothing* or *wrong*: **determinism ≠ correctness**; failures are silent at read-time. **(3b)** non-1:1 reconciliation: each new ingest can contradict an old fact, so write cost of fact N is O(its interactions with the graph), not O(1) — **super-linear**, amortization leaks. **(3d)** the unbounded tail: an ontology/schema epoch change forces **full-corpus re-tagging/re-extraction**, paid in full, scaling with the *whole accumulated corpus* — and CAV2's authority overlay has **no utility-threshold/sampling bound named in the corpus** (unlike the PDF's dream-state re-scoring).

**Narrowing carried.** The bet is genuine; it pays cleanly on the AUTHORITY dimension + stable-schema/high-read-ratio regimes; it is FALSE as unconditional. Whoever sells "cheap deterministic reads" must also own and price the ingest bet and the ontology-maintenance treadmill.

### Leg 3 — governance needs determinism (Z3)

**Deepened claim.** You cannot attest, authorize, or promote a cosine similarity — a ranked neighborhood is fuzzy, threshold-dependent, non-reproducible across index/model rebuilds; it has no stable referent for an owner/decision-id/promotion-stage to attach to. A typed edge with provenance *is* a nameable object (`e/{edge_id}`). The chain: **determinism-at-read → stable referent → reproducible gate → authority-at-read**. Mapped onto VSM: the substrate is a strong **S4+S2** organ **missing its S5**; **cav2 is the missing S5**, and it must attach to the *deterministic typed ontology, not the vectors*, because **structural attenuation (typing) preserves the referent while statistical attenuation (thresholding) dissolves it** (`machine-map/findings.md §1,§5`). Default-deny closure (`AUTHORITY-MODEL.md §Closure`, CAV2-D49) is only *decidable* over a finite enumerable referent space. Causal order: **govern → make read deterministic → incidentally fast** — efficiency is the by-product, not the point.

**Where it BREAKS (its own two counterexamples).** **(a)** Provenance, not determinism, is the real precondition: auditors attest non-deterministic processes all the time (SOC2 attests *that a reviewer approved at T against V*, not reproducibility). A logged vector pipeline is attestable. Z3 **withdraws the strong "determinism is THE precondition."** The corrected claim: the true precondition is a **reproducible-citable REFERENT**, satisfiable by provenance-logging *or* determinism. Determinism's real status = **COST-DOMINANCE** — it collapses the attestation/provenance surface to ~0 — *not* logical necessity. **(b)** The ontology is itself **non-deterministic** (model-driven GLiNER2/JEPA/Bonsai extraction at write-time): run it twice and you can get different edges. "Deterministic ontology" is a **misnomer** — only the *post-promotion referent identity* and the *gate over it* are deterministic; the content is non-deterministically authored.

**Narrowing carried.** The honest thesis is **"a quarantined non-deterministic GENERATOR + a deterministic GATE over typed referents enables governance."** Determinism is a property of the *gate and the snapshot*, not of the retrieval or the meaning — the leg's name slightly misnames its own strongest claim. Survives in corrected form: non-deterministic extraction is admitted as a *candidate* and frozen into a typed referent by a recorded promotion decision (`AUTHORITY-MODEL.md §Core Flow`); content non-deterministically proposed, authority deterministically conferred.

## 4. Lane-A adjudication (filled — zig-zag pass)

Both Lane-A skeptics returned and **converged on one irreducible core**: strip the in-house vocabulary and the surviving load-bearing object is **a stable, citable, typed referent + a recorded gate over it, with the query arriving already-typed** — an object available to graph-only, hybrid, OR separate-artifact encodings alike. A1 (non-vacuity) reached it by building the strongest genuinely-different witness for each leg; A2 (definitional-soundness/precedent) reached it by stripping the vocabulary to find the prior-art owner. Neither emitted a terminal KILL of the *object*; both forced demotions of the *leg framings*. The adjudication below carries those demotions verbatim into the spine.

### A1(a) — HYBRID: the "drop semantic search" slogan is an over-reach CORRECTION, not a leg-kill

A1 built "mostly-graph + thin-vector-margin": typed traversal does the deterministic, governable work; a *thin, logged, typed-terminating* vector step is consulted only at the residual grounding margin (locate an untyped NL intent at a typed entry node, or find the relevant internal pattern when a foreign contract is insufficient). Vectors never carry authority — they nominate a candidate that is resolved to a typed referent *before any gate runs* (A1 §a). The thesis already stands on this: Z1 concedes an **unproven residual grounding margin** (research.md:142-144) and Z3 concedes a `query → vector-recall → typed-rerank → gate` pipeline is **fully attestable if you log model-version/index-hash/k/threshold/returned-IDs** (research.md:393-397). So the hybrid is not a different architecture — it is the *honest version of the thesis's own architecture*, with the residual margin priced in.

**Adjudication: adopt the corrected framing explicitly.** "Drop semantic search" is a marketing SLOGAN the synthesis **never adopted** (this draft never carried a leg by that name). A1 therefore banks **no typed negative** here — only a TYPED CORRECTION. The defensible claim is **reduce, not eliminate; reduce to the margin**: vectors are demoted to a thin, logged, authority-free margin that terminates in a typed referent on every path. Carried into §1 and §3.

### A1(b) — TYPED NEGATIVE: the *unification* ("same object in two forms") is NOT load-bearing

A1's strongest witness is **not its invention — it is `spec-ontology-unification`'s OWN pre-registered Lane A** (`SEED.md:48-53`, verbatim): keep spec and ontology as **two artifacts**, joined by a **generated bidirectional mapping** (codegen + drift-check, the v1 direction). The bounded agent still receives the identical discrete typed seed — `node + N typed edges + foreign contracts` — plus the generated mapping row telling it which code pattern realizes the node. Spec and code are **never forced into one artifact**.

This separates two things Z1's keystone conflated: (i) "the agent receives a discrete typed seed" (the benefit) vs. (ii) "spec and ontology are the same object in two forms" (`SEED.md:16`, the *unification* claim). The witness delivers (i) **without** (ii) — and is **strictly stronger** on the held-fixed problem (drift-prone-ness): the drift-check is a *detector* for exactly the contract-completeness / 1:1 node→pattern condition Z1 left **"unproven"** (research.md:142-144), whereas unify-into-one-graph merely *assumes* 1:1 and has no detector.

**Adjudication: demote the keystone.** "Unify into one typed graph" is load-bearing only for Z1's *novelty framing* — which Z1 already withdrew (research.md:80-85) — not for cheap, non-drifting bounded agents. The keystone moves from **"unification"** to **"the typed SEED + a recorded gate over a citable referent,"** with unification recast as *one of two equivalent encodings* (unified graph OR drift-checked bidirectional mapping), the **separate-artifact encoding dominant** because it makes the unproven condition checkable. (A1 phrased this as a "terminal KILL of the keystone *unification* claim"; it is not a kill of the discrete-seed *object*.)

### A1(c) — TYPED NEGATIVE: governance-needs-determinism is NOT a requirement

A1 built provenance+attestation over a fuzzy pipeline: attest *the recorded execution* (WHAT ran + model/version/config hash, on WHICH inputs + content/index hash + k + threshold, producing WHICH output-IDs) — **not** that it was deterministic. This is the ordinary auditor's object (SOC2/ITGC attests *that a reviewer approved at T against version V*, never reproducibility). Z3 **itself withdrew** the strong form: "*determinism is THE precondition* is too strong and I withdraw it… determinism as the **dominant cost-structure** for governance, not logical necessity" (research.md:397).

**Adjudication: restate leg 3 as cost-dominance, not necessity.** The answer to "is determinism a governance *requirement*?" is **NO** — **provenance + a stable citable referent IS the requirement**; determinism is a **cost-dominance optimization** over it (it collapses the provenance/attestation surface to ~0). The one genuine residue — the attestable pipeline still needs a *fixed citable output referent* (research.md:395) — does **not** rescue determinism; it rescues *typed-referents*, which is leg 1, available to any architecture including the fuzzy pipeline. Leg 3 is therefore demoted from "load-bearing leg (renamed)" to "cost-dominance optimization over the real provenance requirement."

## 5. Relate-to-CyberAlchemy-as-a-whole (the unifying synthesis)

The three narrowed legs are not three theses — they are three faces of one machine, and after Lane-A that machine has a sharper, more honest name. **CyberAlchemy's defensible object is not a novel retrieval algorithm — it is a governed typed-referent + recorded-gate WRAPPER, seeded by DomainSpec typed intent (build-from-owned, not-yet-proven), with cav2 as the S5 gate.** Tie that to the whole — claim ≤ proof, no novelty inflation:

- **The defensible object is the WRAPPER, not the patterns.** Lane-A established that the three legs are build-from-owned of **GraphRAG** (typed traversal), **CQRS / materialized-view** (ingest relocation), and **VSM-S5 / symbolic-IR-auditability** (the gate) — all prior art to be cited, not claimed. What is genuinely CyberAlchemy's is the **governance + typed-intent provenance wrapped around those three**: a governed-provenance graph (not GraphRAG's LLM-guessed one), an already-typed query seed (which GraphRAG lacks — it still embeds the query to find its entry node), a write-time-materialized *non-derivable authority decision* (which a materialized view never holds — views cache derivations), and a recorded gate over a citable referent (not a reproducible function). The moat is the *wrapper's combination*, demonstrated; the engine algorithm stays proprietary.
- **Saturn = the loop.** Saturn closes intent↔reality with evidence. The two-loop substrate (Z2: model-heavy governed *write* loop + cheap *read* loop) is the mechanical realization: the write loop turns reality into typed, governed evidence; the read loop serves it back to intent. Saturn is the *temporal* frame; Z2 is its *cost accounting* — and that relocation is CQRS, cited as such.
- **DomainSpec / typed-intent = the discrete typed seed (Z1, build-from-owned, NOT proven).** The query that arrives *already a node in the graph* (`spec-ontology-unification`) is what makes the read cheap. Build-from-owned of v1's real typed graph — but the owning tower is **unexecuted** (`SEED.md:1-6`) and its central 1:1 node→pattern assumption is **open** (`SEED.md:68`). The moat is not "we invented typed seeds," it is "our existing governed spec graph, read as a retrieval substrate, hands each bounded agent a discrete typed seed instead of an embedding neighborhood." Claim≤proof: market the *cross-artifact lens over an unproven seed*, never a new mechanism, never a proven one. The seed can be encoded as a unified graph OR (dominantly) a separate-artifact + drift-checked bidirectional mapping — unification is a free encoding choice, not the asset.
- **Arcanum = the how.** The sigils/spells (public) are the bounded ephemeral agents whose "context is the spec subgraph" (`SEED.md:23-27`). Arcanum is the execution layer that *consumes* the discrete typed seed under the gate.
- **cav2 = the missing S5 = the recorded GATE over a citable typed referent (Z3, corrected and demoted).** The substrate is S4+S2 with no S5; cav2 supplies the policy organ. The model-driven extraction is the **quarantined non-deterministic generator**; cav2 confers authority via a **recorded gate** (candidate → owner-routed promotion → `decision_id`/`owner` on a frozen typed referent). Content non-deterministically proposed; authority conferred and *recorded*. The asset is the **citable referent + recorded provenance**, NOT the gate's determinism — determinism is a cost-dominance optimization (it collapses the attestation surface to ~0), not a governance requirement (A1(c)). cav2-as-S5 must attach to the typed ontology (structural attenuation preserves the referent) and never to vectors (statistical attenuation dissolves it); vectors, if present, are reduced to a thin governable margin that always terminates in a typed referent.
- **The machine-map = why the read substrate must be typed-ontology, not vectors.** Conant-Ashby: a regulator must contain a model of the regulated system addressable 1:1. The typed graph is such a model (finite, enumerable, decidable membership → default-deny is checkable); the vector space is not. So the substrate choice is forced by the governance requirement, not by latency — latency is the by-product (Z3 causal order). VSM-S5 / Conant-Ashby are cited prior-art lenses, not inventions.

**The honest unifying claim (corrected after Lane-A):** CyberAlchemy is **a governed typed-referent + recorded-gate wrapper — a stable, citable, typed referent with the query arriving already-typed (DomainSpec, build-from-owned and not-yet-proven), plus a recorded gate over it (cav2-as-S5) fed by a quarantined non-deterministic generator — built on top of GraphRAG-style traversal, CQRS-style ingest relocation, and VSM-S5/symbolic-IR governance, inside a closed loop (Saturn) executed by bounded agents (Arcanum).** NOT "deterministic retrieval enables governance" (that misnames the gate as the retrieval and overclaims the ontology as deterministic) and NOT a novel retrieval algorithm (the patterns are prior art; the wrapper is the contribution).
